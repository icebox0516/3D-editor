# 三维园区可视化编辑器

组件化、可拓展的三维园区编辑器：Scene 唯一数据源 + Command 全量可撤销 + 六层单向依赖架构。一期三阶段（①数据架构与样式系统 ②资产库与编辑交互 ③点线面绘制闭环）+ 收编批次交付完毕；**UI 重构四阶段（5–8）全部交付**——阶段 5 布局与交互基座、阶段 6 形状驱动创建与插件化样式引擎（七形状三步流、21 套预设、顶点编辑、场景格式 v2）、阶段 7 成熟编辑器能力（工作模式、工作区布局、纯三维模式、批量编辑、对齐/阵列/道路几何、导航小地图）、阶段 8 高级能力（高级吸附与自动对齐、场景模板与批量导入、多对象分节批量编辑、诊断渲染模式、场景树分组与层级拖拽），各阶段均通过 GUI 验收；**阶段 9 体验修补（2026-09-15 收官）**——UI 弹层层叠治理（七弹层 portal 逃逸 + z 刻度规范）与贴地共面 z-fighting 消除（模型底面微抬 + 地面深度偏置双保险）。

## 功能清单

### 场景与数据

- **形状驱动创建**：七形状绘制工具（多边形/矩形/圆/椭圆/自由/路径/点）产出 RegionObject（形状 / 语义 / 样式三层解耦），十类语义类型（水面/绿地/广场/停车/裸地/道路/建筑/POI/未分类/自定义）注册制接入，新增类型不改核心代码
- **样式引擎**：21 套插件化预设（形状 × 语义双维过滤，含水面波纹、建筑挤出、Shader 效果），切换预设 + 参数覆写（颜色/透明度/发光等），作用域批量应用（当前对象 / 同类型 / 当前图层 / 同预设）
- **图层**：11 个默认图层（十类语义图层 + 模型层），显示 / 锁定 / 透明度（松手提交）/ 拖拽排序 / 重命名 / **合并**（行尾「合并」选目标——成员迁移 + 删源一条可撤销历史，undo 完整复原；空层合并 = 删除）
- **撤销重做**：一切可见修改经 Command 入历史；连续放置与连续点绘制按段合并为一条（一次 Ctrl+Z 撤整段）
- **场景文件**：版本化 JSON 保存 / 打开（**格式 v2**——region 三层结构 + model 资产引用；v1 旧格式停止支持），环境预设与网格设置随场景持久化
- **场景模板**（阶段 8 · T8.2）：菜单「文件 → 新建场景 ▾」——空场景 / 内置模板（空园区 · 示例园区）/ 个人模板（「另存为模板…」存本浏览器，最多 20 套）四区；实例化 = 深拷贝 + 全量 id 重生成（模板只读、实例全新）；当前场景有未保存修改时先弹三行摘要确认；「管理模板…」支持重命名 / 删除
- **JSON 导入**：映射配置化（v2 映射，`assets/mappings/`），**支持一次多选批量导入**——预览弹层逐文件列出拟导入对象数 / 告警数（未闭合环等简单错误自动修复并告警），失败文件置灰不阻断其余，确认后全部对象一条历史入库（一次 Ctrl+Z 全部撤销）；点分路径定位数组、`xy/xyz/ring` 三种几何格式、`floors*3` 表达式字段映射

### 资产与放置

- **资产库**：启动读 `assets/manifest.json`，分类 / 搜索 / 收藏（localStorage）；展开态**标签芯片**筛选（manifest tags 聚合，与分类 / 搜索叠加）+ **排序**（默认 / 名称 / 分类，面板会话态）；GLB/GLTF 占位资产生成（`scripts/generate-assets.mjs`）
- **放置工具**：Ghost 半透明预览跟随鼠标、连续放置、滚轮缩放、R 旋转、随机旋转/缩放；同资产多实例 InstancedMesh 合并渲染

### 编辑交互

- **选择**：点选 / Shift·Ctrl 多选 / 空白拖拽框选；场景树同步选中与定位
- **场景树分组与层级拖拽**（阶段 8 · T8.5）：Outliner 默认层级树——**Ctrl+G 建组 / Ctrl+Shift+G 解散**（右键菜单同源）；组为**纯组织节点**（不参与渲染与拾取，序列化 `type: 'group'` + `parentId` 嵌套往返无损，删组仅删壳、成员上提不删）；行拖拽三形态（挂入组 / 同级排序 / 根区上提）+ drop indicator 三态（合法琥珀 / 插入线 / 禁止）+ 折叠组悬停 800ms 自动展开 + 环拒绝提示；双击组行选中全部成员、单击选壳走只读检查器；分类视图与层级树并列切换
- **变换**：Gizmo（移动 / 旋转 / 缩放，W/E/R 切换）或属性面板数值输入；复制粘贴（Ctrl+C/V，粘贴偏移 1m 换新 id）与 Delete 删除
- **对象吸附与网格吸附（移动工具）**：拖 Gizmo 移动时对其他对象包围盒做 X/Z 边对齐（两轴同命中即面对齐，容差默认 0.5m，设置面板可调）；网格吸附按网格间距取整（与绘制同源开关）；开关与容差统一在「全局设置 → 吸附」
- **高级吸附与自动对齐**（阶段 8 · T8.1）：移动拖拽实时**对齐参考线**（候选对象边缘 / 中心线 1px 琥珀细线 + 端点方块，松手即逝）；**高度层吸附**（地面 y=0 与建筑顶面层，网格关闭时仍生效）；**道路边缘候选**（条带足迹边缘）；旋转**角度步进**（默认 15° 相对步进，档位 15/30/45/90 可调）；顶点编辑 A 键 45° 锁定；拖拽中按住 **Ctrl 临时反转**吸附（松开恢复）；**贴地 End**——选中对象落到下方最近高度层（多选批量一条历史）；「工具 → 吸附」**总开关分级**（总开关压下不改五分项记忆：对象 / 网格 / 参考线 / 高度 / 角度 + 容差与步长档）
- **对齐 / 阵列**：多选 ≥2 → Context Toolbar「对齐」弹层八项（X/Z 最小·居中·最大 + 均布；悬停菜单项实时预览目标位置足迹框），一条历史；任意选中 → 「阵列」popover（数量 + 间距 + 八方向，参数实时足迹预览），确认后选集中每个对象按步距复制 N 份、一条历史并选中副本
- **道路分割 / 合并**：单选道路 → 「分割」激活节点拾取（顶点句柄显示，点击转角节点一分为二，语义/样式保留，单命令单历史）；恰选两条端点相邻道路（≤0.5m）→ 「合并」拼接为一条（保留前者），单命令单历史
- **顶点编辑**：双击面对象或检查器「编辑顶点」进入——拖动顶点句柄改形状、Alt+点击边中点插入新顶点、Delete 删除选中顶点；全程仅重建几何（材质 / 类型 / 样式不动），shape-only 一条历史可撤销；再点按钮 / Esc / 双击同一对象退出
- **检查器**：region 对象四分组（基础信息 / 几何 / 业务类型 / 表现样式），形状参数与语义参数（道路宽度、建筑高度等）按注册定义自动生成；model 对象含资产引用只读行
- **多选批量编辑**（T7.5/T8.3）：通用组（图层 / 可见 / 锁定）对全量选中生效；全 region 异类型多选按语义类型**分节**（「建筑 ×2」「道路 ×1」各自节头），节内类型切换 / 参数 / 预设 / 基准高度独立提交——改节 A 不动节 B，各一条历史；异值字段显示 Mixed 占位，提交写入节内全部对象
- **批量重命名**（阶段 8 · T8.3）：多选右键「批量重命名…」弹层双模式——**前缀 + 序号**（起始 / 步长 / 1–3 位填充）或**查找替换**（「楼1」→「宿舍楼1」式清理），实时预览前 8 条 + 共 N 项，确认一条历史（一次 Ctrl+Z 全部复原）
- **垂直工具条**：左缘 48px 常驻列四分组——变换组 Q/W/E/R（选择/移动/旋转/缩放）· 绘制组 **1 区域**（分裂按钮：多边形/矩形/圆形/椭圆/自由五子工具，⇧1–5 直切、1 记忆上次）/ **2 路径** / **3 点** · 资产组 **4 放置**；激活琥珀高亮，再次点击退出绘制；随工作模式置顶本模式分组、其余入口折叠进「更多」抽屉（见「工作模式」节；数字键 1–4 随时直达）

### 工作模式（阶段 7 · T7.1 UE 式聚焦模式体系）

- **六个显式工作模式**：场景 / 建造 / 道路 / 地形 / 装饰 / 标注——模式是「工作域焦点」而非权限闸门：**全部工具在任何模式可用**，阶段 6 三步流（画形状 → 自由赋类型）完全不变；测量 / 分析为禁用占位（后续版本）。模式为会话内存态（随布局持久化归 T7.3）
- **三路切换（同源一致）**：Context Toolbar `Scene ▼` 选择器 ｜ **Alt+1..6** 直切（表序：场景/建造/道路/地形/装饰/标注；Alt+7/8 预留不绑定）｜ 菜单「视图 → 工作模式」八项子菜单；切换时若在绘制/放置中先自动取消（Esc 同路，零历史记录）
- **徽标与显示模式**：徽标/HUD 显示「合成模式」——显式模式全名 + 模式专属色；绘制/放置激活期间临时显示派生态（面→地形、路径→道路、点→标注、放置→装饰），退出工具恢复显式模式
- **六联动**：① Context Toolbar 徽标/引导随模式更新 ② 工具无禁用 ③ 垂直条本模式分组置顶、其余进「更多」抽屉（抽屉内可正常激活）④ Inspector 无选中时显示**模式引导卡**（模式说明 + 快速开始，随模式切换）⑤⑥ HUD 徽标全名 + 专属色 + 一行操作引导（场景内渲染零改动）
- **上下文工具矩阵**（选中对象时 Context Toolbar 中段）：单选**建筑** → 复制 / 轮廓编辑 / **楼层步进器**（±1）/ 阵列；单选**道路** → 复制 / 节点编辑 / **宽度步进器**（±0.5m）/ **分割** / 阵列；其他单选 → 复制 / 阵列；多选 → **对齐**（悬停预览）/ 阵列 / **合并**（恰选 2 条相邻道路）。步进器每次步进一条历史可撤销（长按连续）；对齐 / 阵列 / 分割 / 合并均一条历史（详见「编辑交互」节）

### 工作区布局（阶段 7 · T7.3）

- **四布局预设**：顶栏「布局」按钮弹层一键切换——**默认**（四区齐备）/ **极简**（仅视口，三面板区收起）/ **搭建**（底部浏览器展开 280 + 大纲，右面板收起）/ **分析**（强化视口 + 检查器 360，左栏与浏览器收起）；当前布局与某预设一致时该项高亮，否则显示「自定义」
- **个人布局**：「保存当前布局…」命名保存当前面板尺寸 / 显隐 / 折叠 / 标签与浏览器状态（存本浏览器 localStorage，重名覆盖有提示）；列表点击应用、行尾**重命名 / 导出（JSON 文件）/ 删除**；「导入布局…」从导出文件恢复（非法文件拒收提示，往返无损）
- **恢复默认**：默认布局 + 工作模式回「场景」一步复位
- **自动持久化**：布局与上次工作模式自动记忆（防抖 300ms 写入 localStorage），刷新 / 重新进入编辑器后自动恢复（禁用的测量 / 分析模式不可恢复，回落场景模式）；布局数据与场景文件完全解耦——清场景 / 新建场景不影响布局

### 绘制模式（阶段 6 · 形状驱动三步流）

- **七形状绘制工具**：多边形（点击顶点双击闭合）、矩形（拖两角）、圆形（中心拖半径）、椭圆（两段拖拽定半轴）、自由形状（按住跟踪松手简化）、路径（双击结束）、点（点击即成、连续放置）——全部产出「未分类区域」（RegionObject：形状 / 语义 / 样式三层解耦）
- **三步创建流**：①绘形状 → ②生成未分类区域（完成即自动选中并回选择工具）→ ③上下文工具条浮出**类型芯片**（水面/绿地/广场/停车/裸地/道路/建筑/POI + 更多）与**样式色样快选条**，一步点击同时赋类型（自动迁入类型默认图层）与样式预设，恰一条历史可撤销
- **绘制入口**：垂直工具条 / 数字键（1 区域记忆子工具、⇧1–5 直切、2 路径、3 点、4 放置）/ 大纲「创建 ▾」/ 视口右键空白「创建 ▾」（七形状同源）；绘制中 Context Toolbar 面类五形状芯片即切
- **绘制辅助**：状态栏实时长度 / 面积 / 顶点计数 / 顶点坐标；Shift 正交锁定、A 键 45° 方向锁定、G 键网格吸附开关
- **几何校验**：自相交 / 顶点不足拦截并提示（状态栏红色附注）；多边形 / 自由形状草稿保留可修正；参数化形状（矩形/圆/椭圆）天然合法
- **网格与视图**：进入绘制自动顶视 + 限制旋转（透视绘制开关保留）；网格显示 / 间距 / 尺寸可配（间距即吸附步长）；HUD 右上 Perspective ▼ 四机位切换（F 聚焦、Home 全景在上下文条）

### 视口 HUD 与状态栏（阶段 5 · T5.7）

- **四角 HUD**：左上 = 工作模式徽标（合成模式全名 + 专属色，其下一行操作引导）· 机位 · 场景名芯片；右上 = `Perspective ▼`（四机位）/ `Shaded ▼`（渲染模式下拉：**常规** 着色 / 线框 / X-Ray ｜ **诊断** 灰模 / 法线 / 孤岛高亮两组分隔呈现，与主菜单「视图」/ 视口右键三路同源 checked）/ 齿轮 Viewport Options（网格、坐标轴开关；小地图占位）；左下 = 三维坐标轴指示器（随相机姿态实时联动）；右下 = 小地图占位。HUD 绝对定位四角、不遮挡中心
- **诊断渲染模式**（阶段 8 · T8.4）：**灰模（Clay）**统一中性灰单色 / **法线（Normals）**世界空间 RGB 编码 / **孤岛高亮**——未归类对象（layerId 为空）高亮、其余降暗，HUD 实时计数角标「未归类对象：N / 全部已归类」，改图层归属即时收敛（数据卫生档）；混合实例池精确拆分（部分归类只换归类网格，其余共享不变）；辅助层豁免（gizmo / 网格 / 轴指示器原样渲染）；切换一次性遍历不增逐帧成本；**会话级**——保存场景自动剥离诊断档，重开回常规
- **状态栏读数**：左段绘制读数（长度 / 面积 / 吸附后坐标 / 拦截提示）+ 游标地面坐标 X/Y/Z（定宽两位小数；离开画布显示 —）；右段 Objects · Triangles（K/M 缩写）· FPS（1Hz）· Unit: m
- **坐标一致性**：绘制中状态栏「坐标 X·Z」为吸附 / 正交 / 角度锁定后的落点；游标 X/Y/Z 为射线地面原值——无吸附修正时两者一致（几何真值口径）

## 操作指南（速查）

### 视口手势（阶段 5 · T5.8 迁移，UE/Unity 行业惯例）

| 手势 | 功能 |
|---|---|
| 左键 | 选择对象 / 确认操作（绘制顶点、放置） |
| 右键拖拽 | 旋转视角 |
| 中键拖拽 | 平移视图 |
| 滚轮 | 缩放 |
| 右键点按（无拖拽） | 上下文菜单（视口对象 / 空白 / 大纲行 / 资产卡片四类） |
| Esc | 取消当前操作——**唯一退出手势** |

> **破坏性变更（自 T5.8 起）**：右键不再退出工具（已迁移为「拖拽旋转 + 点按菜单」）。
> 退出绘制 / 放置请用 **Esc**，或 Context Toolbar「退出」按钮 / 再点垂直条同项。

| 操作 | 方式 |
|---|---|
| 画区域 | 垂直工具条「绘制区域」（或按 1；⇧1–5 直切多边形/矩形/圆形/椭圆/自由）→ 按对应手势绘形状 → 双击闭合 / 松手完成 → 生成未分类区域并自动选中 |
| 赋类型与样式 | 绘制完成后上下文工具条点**类型芯片**（水面/绿地/道路/建筑…）→ 点**样式色样**一步应用（自动迁入类型默认图层，一条 Ctrl+Z 可整体撤销）；完整参数在右侧检查器 |
| 画路径 / 点 | 按 2 画路径（点击折点双击结束）；按 3 画点（点击即成、连续放置，每段合并为一条历史） |
| 切换形状 | 绘制面类中 Context Toolbar 中段点形状芯片（多边形/矩形/圆形/椭圆/自由即切重绘） |
| 退出绘制 | **Esc** / 再点垂直条同项 / Context Toolbar「退出」（右键已迁移为菜单/旋转） |
| 放模型 | 内容浏览器点卡片 → 视口左键连续放置 → **Esc** 退出；按 4 重放最近资产 |
