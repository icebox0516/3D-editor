# Reference Spec 模板

> 用途：复制本结构到 `docs/research/<asset>-reference.md` 后按当前资产需要填写。
>
> **本模板是可裁剪的事实结构，不是强制全量问卷。** 不相关章节可省略；关键但无法确认的事实保留 `Unknown`。
> 域扩展字段按 `references/<domain>-schema.md` 定义；只填写当前资产实际需要的字段，**内联标注于正文各节**，不设独立复述节。
>
> **两层结构与内容资格线（D38）**：头部「消费摘要」区供 Step 1–4 默认只读；后部为压缩证据层。只有「被 Step 1–4 消费的现实事实 + 其承重证据锚」有资格入 Spec——检索可达性、下载重试、槽位落空、工具误触等会话日志归任务完成记录，不入本文件。

---

```md
# <asset> Reference Spec

Spec Version: 1.0        ← 修订内容时递增（1.0 → 1.1）；任务书执行快照锚定此字段
Domain: plant            ← 所属域，对应 references/<domain>-schema.md
Asset: tree3a            ← 资产 id 或暂用名
Updated: 2026-09-18      ← 最后修订日期

## 消费摘要（Step 1–4 默认只读本节）

← 几百字：本次生产直接消费的全部现实事实，一条一行（事实 + Evidence Status，来源编号可追溯）。
← 本节同时是主代理终审的抽样框（D38）：终审抽查 = 本节内直接进参数面的承重锚 + 整树/冠形槽照片。
← 终审修正直接改写本节与正文对应条目，不在文末追加附录。

## Research Scope
← 本次生产实际需要确认的现实事实范围。
← 只列真正会影响当前资产身份、结构、材质、变体或核心视觉的事项。

- <需要确认的事实>
- <需要确认的事实>

## 1. 身份
← 按需填写：是什么、具体种/型号/品种/亚型、使用语境、与近似对象的区分。
← 无身份问题时保持简短；近缘差分压至 2–3 条决定性判据（属内首例建档全链，后续同属引用）。

## 2. 主要尺度
← 按需填写核心尺寸、范围或相对尺度。
← 不强制统一为高/宽/深，按对象选择真正影响生产的尺度。
← 无可靠数据但该事实关键时明确写 Unknown。

## 3. 轮廓与比例
← 按需填写整体形态、关键数量关系、相对比例。
← 例如冠幅/树高、杆高/悬挑长、灯臂/杆高等。

## 4. 结构层级
← 按需填写部件树、部件形态、连接/着生关系。
← 例如干→枝→叶、杆→臂→灯头、座板→靠背→支腿。

## 5. 材质与表面
← 按需填写颜色域、粗糙度、透光、反射、表面结构等现实可观察特征。
← 只写到现实事实层，不写 Shader 实现参数。

## 6. 变体范围
← 仅在真实对象存在、且会影响当前资产生成时填写。
← 描述主要变化维度、范围及联动关系。

## 7. 远近景保留优先级
← 仅在远近景差异对当前资产生产有实际意义时填写。
← 写到视觉显著性为止；面数、切换距离等工程映射归任务书/工程规范。

## 8. 来源证据

| # | 来源 | 类型 | URL/文献 | 检索日期 | 覆盖面 |
|---|------|------|----------|----------|--------|
| 1 |      | 论文/官方/产品页/技术手册/百科/图片/用户提供 |  |  |  |

← 只留锚句与端点信息：正文已逐句引用原文 + 编号即完成溯源，**不整段重贴原文**。
← 来源数量按当前事实重要性与对象复杂度决定，不设固定数量。
← 核心承重事实必须可追溯到来源表；用户提供的内容标注「用户提供」。

### 照片来源明细（一行化）

| 槽位 | 文件 | 来源/许可 | 承重结论（一行） | 分歧记档 |
|------|------|-----------|------------------|----------|
← 每张照片一行：承重结论 + 双问是否一致；分歧即标「不承重该主张」。
← 照片体量按 D38 封顶：承重槽 8–10 张双问，其余快筛不双问。

## 终审记录（一行）

终审：通过｜修正项列表｜日期    ← 主代理采样终审（D38）结论；详细双问过程归任务完成记录。

## 关键事实统一写法（各节内联）

← 对真正影响当前生产的事实逐条给出（内联于上述各节，不设独立节）：
← Value / Range / Relative / Qualitative
← Evidence Status: Verified / Inferred / Unknown
← Source: 来源编号

示例：

- 树高：7–9m
  - Form: Range
  - Evidence Status: Verified
  - Source: [1]
```
