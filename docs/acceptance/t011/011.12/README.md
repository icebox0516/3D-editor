## 缺口与观察项（归 011.13 族级验收门）

- **垂枝域实证（应力位收口输入）**：①档表达成立——upturn 强负链（L3/L4/L5）+ 喷泉骨架（scaffoldAngle 20–36° 窄带）+ 末级 lengthRatio 加长垂帘 + 末端细化（L5 实起径 ~1.6mm——**地板负锥度记档**）+ 簇沿切向垂帘；六轮探针回调记档（3a：中断会话终测记档大面积失实——注释声称 wh≈1.15 实测 1.359、rawMinY 穿地 -1.30——**流程教训归完成记录**）

- **观察项②**：两面色差弱档帧依赖（el20 双问确认 / el0 平视不显）——弱色差档固有，族门横向（vs fraxinus 弱档先例）复核
- **观察项③**：垂帘体积密度定量带（绿覆盖 6.9% / 天光隙 80.6% @M25 同法）——族门混植一致性输入

- **几何侧记档（3a/3c 交付）**：Mid L4 段数账目勘误（4514→5648）；「互生不成对」断言移除（黄金角 4 步系统对小簇本征成对率 0.57 与 decussate 不可区分——测试回路记档）；SLOTS spacing 11→12（防交叠判据：半幅和实测最大 11.78 > 11——SOP §3 P42 括注 spacing 11 为先例默认值非硬约束，本树按判据定 12 记档）；asset 头卡数低端笔误修正（3768→3894 slot-6 实测）
- **材质侧记档（3b 交付）**：树高锚同步轮 10.0→9.8306（Stage 实测 slot-0 High maxY，三处同步）；残桩椭圆轴向翻转修正（纵向→横向短椭圆，**画面双机位验证成立**）；SDF 齿谷注释 2× 偏差纠错；透射 0.44 家族链上沿试探（B25 黄绿光晕读出 ✓）
