## 材质校准记档（Step 4b，革质光泽一轮）

1. **Step 4 首判**：三帧独立判读（3.5m 叶特写 / 2.8m 宏观 / 25m 中景）一致读作「叶面偏哑光、干燥感，革质光泽不足」——Spec §5「上面绿色或黄绿色，**有光泽**」+「近革质至革质」Verified，属身份特征表达不足。
2. **Step 4b**（park-shader-agent 新实例，2026-09-20）：叶 front roughness **0.62 → 0.50**（背面 +0.16 哑光差注入不变——革质两面差语义保持；vs 朴树 0.72 差距拉大到明确可辨一档）；常量级单杠杆，零新增指令，roughness 走 uniform 不触 program 键（9 键契约不动），叶 High 成本账不变；测试常量断言同步（精确 0.62→0.50 + 带宽 0.5–0.7→0.4–0.6）。
3. **终测**：探针正面叶肉亮度 66→68（specular 展宽可测）；视觉复核「多数叶片革质质感可辨（温和）、无干燥纸片感、形状色彩真实、中脉背面灰绿可辨」——**温和可辨但无锐高光**（宏观中性读光泽 2.5–3/10，距革质健康读向 6–7 有差距）。
4. **根治路径记档归 011.5（家族共性缺口，非香樟特有）**：分析光照（无 envMap）下 MeshStandardMaterial 的 specular 表达有结构上限——锐利革质高光需叶族公共 specular/envMap 方案（夏栎/朴树/香樟同体系受益），超出本任务常量级校准边界与成本契约不变约束。

## 观察项（记档不返工，异议窗口覆盖）

1. 革质光泽温和可辨但无锐高光：见 Step 4b 记档——结构上限归 011.5 叶族公共方案
2. 背面灰绿粉感（glaucous）偏弱：探针 RGB 冷灰偏移实证方向正确，幅度温和——与 011.1 两面区分「faint but present」同档
3. 树皮上段偏光滑 + 沟内无暗层次：上段平滑 = 起伏幅度∝半径机制的涌现行为（家族设计，011.1 契约缺口清单「起伏∝半径挂钩」已有升级线索）；沟内层次为树皮材质候选微调归 011.5
4. Low 档 50m 冠缘细碎团块感：壳卡纹理 = 牺牲顺序正确（见 LOD 节）
5. 8 槽「一致偏侧」视觉观察被几何解析否证（leanprobe 方位全圆散布）——记为引导性视觉读数 + 透视偏置的误读案例，机器判定优先
6. 25m 中景叶色读「中绿」、宏观读「深绿基调」：宏观/特写口径浓绿成立；中景亚像素聚合读向偏亮——方向正确，混植语境下与夏栎/朴树差异明确
