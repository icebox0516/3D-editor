## 异常与处置（如实记档）

- **首轮取证批次全废 + 6 条真实 GLSL 编译错误**：`vec3 bisBarkMul = bisRidge * (...)` 三档注入块（High/Mid/Low）将 domainVars 顶层预声明的 `float bisRidge`（bischofiaMaterials.ts:466）赋给 vec3 —— dimension mismatch、Fragment shader not compiled、树皮三档全部不渲染（**非 X4000 FXC 误报**，真编译失败）。来源：上一会话材质代理 19:31 修改（风动锚 10m→9.896m 同步）后中断、未跑视觉验证。**与 011.7 triBarkSmooth 跨 include 作用域事故同型**（连续两树同族事故——开发代理中断即未验证是共同根因）。处置：park-shader-agent 修复（三处 `vec3(bisRidge)` 显式广播，声明保持 float——全文 60 条 vec/float 声明逐条核对无其他维度错误）+ 回归守卫用例（三档 toContain 修复形态 + not.toMatch 裸标量模式，011.7 守卫同款）+ CDP mountLevels 三档真实编译验证 console `[]` + **首轮 25 帧全废重跑**。既有 45 条测试未拦截原因如实记：源码字符串断言不编译 GLSL、既有作用域守卫只验可见性不验类型——维度错误只有编译器能裁决。
- **零校准轮**：全部疑点单帧读数均被交叉机位/近距机位仲裁解决，无形态问题触发校准。
