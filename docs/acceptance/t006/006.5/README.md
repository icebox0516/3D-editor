## ③ 换档序列机器 diff + 人工复核窗口收口（D27.10）

场景：2 万夏栎，推拉 d=60→600m 步长 30（19 帧序列 `seq-d*.png`，穿越 high→mid→low→culled
全档边界；overlay 分布数字随帧入画）。

- **选档迁移单调无震荡**（seq-log.json）：H 109→0 单调、M 417→212、L 恒 2,800–3,100、
  C 13,463→13,683 递增；drawCalls 305→237、triangles 8.8M→2.5M 平滑收敛——迟滞带宽下
  无档位抖动（迟滞零 churn 的运行时表现，与 006.3 单测一致）。
- **帧间 diff 不超运动基线**（18 对相邻帧 pixel-diff + LOD off 同款 3 对基线）：
  on 侧 diff 严格单调递减（gt8 像素 25.97%→6.25%，随视差物理衰减，无尖峰）；对照
  off 基线：60→90m on 25.97% vs off 27.44%、270→300m 14.70% vs 21.16%、570→600m
  6.25% vs 13.64%——**换档增量不超纯运动视差**（远处降档反而柔化边缘，on 侧更稳）。
  判「无 pop / 无闪烁 / 无整屏突变」（D27.10 口径：不判两档图像一致——轮廓差客观存在）。
- **视觉核验**（视觉模型，三关键帧）：近景 d60 近树完整枝干/树冠 + 远景剪影平滑降档；

  连续树林非碎片、**无空洞带/无突然消失裁剪线**。
- **人工复核窗口**：006.3 起开放的换档点前后帧复核窗口（D27.10）随本验收门收口——

## ⑤ 范围门判定（D27.3）——**三项全达标，Impostor 不立项**

判定口径：城市档（10 万实例压力）triangles / draw calls / frame time p95 对照预算。

| 指标 | 实测峰值 | 预算 | 判定 |
|---|---|---|---|
| draw calls | 531（near-mixed） | 650（BATCH_POLICY.drawCallBudget） | ✓ ≤81.7% |
| triangles | 584,356 | ——（无预算常量；30fps 口径见下行） | ✓（0.6M @ 175fps） |
| frame time p95 | 7.3ms | 33.3ms（≥30fps 换算） | ✓ 22% 用量 |

**结论：三项全绿，Impostor 升级（D27.3 范围门）不触发、不立项**。Proxy/Impostor 维持
规范预留位（lod-spec §3）。若未来实例量级再上一个数量级（≥50 万），重开范围门。

核显复验遗留（园区档保守外推判读）：树 near-mixed 机位 GPU-bound 风险最高——2080 Ti
off 对照 184M tris 17fps 线性外推 GPU 帧时，8.2M tris ≈ 2.6ms/帧；UHD 730 光栅吞吐
约为 2080 Ti 的 1/8–1/15 → GPU 21–39ms + CPU 提交 2–3ms → **24–42fps，30fps 线临界**。
若核显复验不过：治理面 = LOD_THRESHOLDS 更保守（highToMid 6→4 一档即大幅削减近景
High 量）或 levelInstanceKeep.low 下调——均为常量级调整（评估器/抽稀与数值解耦，锁定
值重开实测记档即可），无架构改动。
