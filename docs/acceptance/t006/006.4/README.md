## ① draw call 预算标定（候选 400 → **650**）

近景混合机位（90m / 仰角 14°）实测峰值 **531**——超首版候选 400。构成分解
（`diag-drawcalls.mjs`，同场 90m / 仰角 18°）：

| 状态 | drawCalls | triangles |
|---|---|---|
| 基线（主遍 + 影遍） | 507 | 566,228 |
| 太阳影关（仅主遍） | 183 | 196,484 |
| 影遍贡献 | **324** | 369,744 |

构成解释：draw call ≈ **内容桶数 × 材质组数（路灯 6）× 遍数（主 + 影）**——该机位
92 内容桶（6 high + 86 low 合并桶），影相机（±160m 覆盖域）内的桶双遍提交。结论：
预算必须按「桶 × 组 × 遍」口径标定，不能按桶数。**BATCH_POLICY.drawCallBudget 候选
定为 650**（峰值 531 + ~20% 余量；数值状态 = 候选，006.5 验收门实测复核锁定——
BATCH_POLICY 模块头注与锁值测试已同步标注标定依据）。
