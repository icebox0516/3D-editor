## 偏差与补充（优先级高于上方提示词）

- 实现放 `src/runtime/instancing/InstancedAssetPool.ts`：每 assetId 一个池；业务层仍逐个 ModelObject 调 attach，runtime 内部检测同 assetId ≥2 实例时切换 InstancedMesh 路径（重建矩阵缓冲而非重建对象）；单实例退化普通 Mesh。选中高亮与 Ghost 预览不走实例池。
- 附带空间索引接口占位：`src/runtime/spatial/SpatialIndex.ts`（`interface SpatialIndex { insert(id, aabb); remove(id); query(aabb): ID[] }` + 线性暴力实现），规模上升后换 BVH/四叉树不改业务代码（需求文档「预留空间索引接口」）。

## 验收标准（node 下统计，无需 WebGL）

- 同 assetId 500 实例：THREE 场景对象数为 1 个 InstancedMesh 而非 500 Group；每实例世界矩阵与其 transform 一致。
- 删除中间一实例：其余矩阵不变、count 减一；undo 恢复后 count 与矩阵复原。
- 更新单实例 transform 只写对应矩阵槽（spy 断言 setMatrixAt 调用次数 =1）。
- 业务层无感：`tests/app/phase1.acceptance.test.ts` 不改一行仍全绿。
