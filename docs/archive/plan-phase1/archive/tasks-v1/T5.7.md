## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### EditorHandle 超集：getViewportStats（零契约变更）

- bootstrap 增 `getViewportStats(): { fps: number; triangles: number; drawCalls: number }`：fps 由 RenderLoop 维护的 1s 滑动窗口帧计数（纯计数模块 `src/runtime/renderLoopStats.ts`，node 可测）；triangles/drawCalls 读 `renderer.info.render`（每帧重置口径注意 info.autoReset 语义）。
- UI 1Hz 轮询（setInterval，组件卸载清理；不进 React 渲染热路径）。

### HUD 左上 / 右上

- 左上芯片行：`模式徽标（toolIA 派生 mode 中文）+ 机位（camera.getMode 首字母大写）+ 场景名`。场景名经 EditorHandle 超集 `getSceneName()`（app 层在 openScene/新建时记录，零契约）。
- 右上：`Perspective ▼`（四机位，checked=getMode，切某机位时**不抢工具**——与绘制工具的 orthoLock 并存语义回归）+ `Shaded ▼`（Shaded/Wireframe/X-Ray → `setEnvironment({ renderMode })`）+ 齿轮（Viewport Options：网格 toggle/坐标轴 toggle/小地图 disabled 占位）。
- HUD 定位：绝对定位于视口容器四角，`pointer-events: none`（下拉容器除外），不遮挡中心场景。

### 渲染模式消费（runtime，environment 通道）

- `Renderer.applyEnvironment` 增 `renderMode` 键消费：`shaded`（默认，材质按样式解析重算）/ `wireframe`（遍历场景材质置 wireframe=true，恢复时按 ResolvedStyle 重算）/ `xray`（半透明化：opacity 折减 + depthWrite=false 的简化实现，恢复同上）。
- 切换时机：仅环境变更时一次遍历，不进每帧路径（性能要求 37.1/37.4）；InstancedMesh 与预览/辅助对象的处理在实现中一并明确并测试。

### 左下坐标轴指示器（runtime 二视图）

- 角落 88×88 独立 canvas overlay，第二 Scene（三轴 + X/Y/Z 字符 sprite 或 canvas 贴图）+ 正交相机，每帧将主相机四元数（仅旋转分量）同步给指示器相机；render 于主渲染后（同一 rAF，第二个小 render call，draw call 增量 ≤3）。
- 开关经 Viewport Options（env 通道 `axesHelper.visible` 类扩展键）；颜色遵守 UI 令牌之外的视口内约定（X 红 / Y 绿 / Z 蓝 行业惯例——视口内 3D 内容不受 UI 色板约束，DESIGN.md 已有此条）。

### 状态栏增强（ui）

- 左段：绘制读数（现有 drawStatus 呈现**原样保留**）；游标读数 `X/Y/Z`（世界坐标，Y 恒 0.00 显示三位或按需）——canvas pointermove 节流 30ms → `groundPoint` → store.cursorPos；离开画布清空显示 `—`。
- 右段：`Objects N（sceneVersion 派生重读）· Triangles X.Xk/M（1Hz 轮询 getViewportStats）· FPS 60 · Unit: m`。等宽 tabular 数字（`.ed-readout`）。
