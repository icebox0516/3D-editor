## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### 双态结构

- 紧凑态（默认 60px，`--browser-h-compact`）：`Content Browser 标题 ｜ 分类芯片行（全部分类动态取 manifest categories）｜ 搜索框 ｜ 展开按钮`；点击芯片 = 选定分类并**同时展开**。
- 展开态（280px，`--browser-h-expanded`）：左侧分类纵栏（含计数）+ 右侧资产网格（卡片 = 缩略图 + 名称 + 分类色标，沿用 `.ed-asset` 语言升级为网格卡片）；顶部行同紧凑态 + 收起按钮。
- 态与选中分类存 workspaceStore（`browser: { expanded, category, search }`）；高度过渡 150–300ms（transform/height 二选一，避免布局抖动——用 grid 行高过渡 + `prefers-reduced-motion` 降级）。

### 拖拽放置（P0 核心新增）

- 卡片 `draggable`，`dragstart` 写 `dataTransfer`（自定义 mime `application/x-asset-id` + 兜底 text）。
- Viewport 容器：`dragover`（仅含资产 mime 时 `preventDefault` + 落点高亮描边 `--accent-line`）/ `drop` → **canvas 内坐标换算**（drop 事件 clientXY − canvas boundingRect）→ 经注入的 `groundPoint(x, y)` 解析世界坐标 → 创建对象。
- 创建路径：抽取 PlacementTool 的 ModelObject 构建逻辑为 app 层共享工厂 `createModelObjectAt({ asset, layerId, position })`（新 id / defaultScale / defaultRotation，**无随机采样**——拖放语义确定性放置；点击放置路径的随机语义不变，两路径各自测试锁定）→ `history.execute(new CreateObjectCommand(obj))` → `selection.select(obj.id)`。
- 「Inspector 自动打开」联动：右面板隐藏时显示之并切「对象属性」标签（workspaceStore 写入；复用 T5.2 action `asset.focusBrowser` 反向同构）。
- 落点无效（groundPoint null，如拖到地平线外）：轻提示「无效放置位置」（notice/Toast 通道），不清拖拽状态。

### 点击放置（等价迁移）

现有 `onPickAsset` → `tools.activate('placement', …)` 路径原样保留；缩略图懒加载（首次交互触发离屏快照替换 SVG 占位）链路不动。

## 验收标准

- 紧凑 60px / 展开 280px 双态切换；分类筛选 + 搜索即时过滤；缩略图懒加载与收藏（如现有）等价保留。
- 拖拽链路（43.3）：拖卡片入视口 → 落点出现对象 → 自动选中 → 右面板「对象属性」刷新（隐藏时自动展开）；一条 CreateObjectCommand 可撤销。
- 点击放置路径行为不变（含随机采样语义与 mergeBatch 连续放置历史）。
- 无效落点有提示且不产生命令/历史。
- browserModel / modelFactory 纯逻辑全覆盖；PlacementTool 抽取重构零行为回归（既有 placement 测试守护）；守护三件套全绿。
