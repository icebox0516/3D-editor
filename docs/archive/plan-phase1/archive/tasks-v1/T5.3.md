## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### TabStrip 复用组件

`src/ui/components/TabStrip.tsx`：通用双/三标签条（T5.4 复用）；键盘左右切换、`role="tablist"/"tab"`、激活态琥珀下划线（沿用面板语言，不引入新令牌）。

### 场景大纲树模型（纯数据，node 可测）

- `src/ui/panels/outlinerModel.ts`：`buildOutlinerTree(objects, opts)` → 组节点 + 叶节点树。
  - 分组：按对象 `type` 聚合，组顺序固定（building→Buildings / road→Roads / green→Green / water→Water / parking→Parking / marker→Annotation / model→Models / 其余→未分层，**顺序与命名对齐 `DEFAULT_LAYER_NAME_BY_TYPE`**）；组行显示类型中文名 + 计数。
  - `filterTree(tree, { search, typeFilter })`：名称模糊匹配 + 类型筛选；搜索时自动展开命中路径。
  - `expandState` 纯函数（toggleAll/collapseAll/toggleOne），受控于组件状态。
- 组节点是**虚分组**（不建真实父对象）：组显隐/锁定 = 对成员逐对象 UpdateObjectCommand + BatchCommand 合一条历史；P0 不做真实 parentId 层级（SceneObject.parentId 契约已在，真实拖拽层级归 P1）。

### 行交互

- 每行：`显隐(eye) ｜ 锁定(lock) ｜ 名称`；选中行高亮（selectedIds 同步，联动既有）。
- 单选 = `selection.select`；Ctrl 点按 = add/remove；Shift 点按 = 同组范围选择（P0 简化为组内范围）。
- 双击 / F2 = 行内重命名（input 就地编辑，Enter 提交 → UpdateObjectCommand(name)，Esc 取消）。
- 点击行联动：既有 selection:changed → Viewport/Inspector 链路零改动（T4.1 已通）。
- 行 hover 才浮显 eye/lock 按钮（降低视觉噪音），锁定对象行名降透明度。

### 顶部工具条

`搜索框 ｜ 类型筛选(下拉或芯片) ｜ 展开全部 ｜ 收起全部 ｜ 创建对象 ▾ ｜ ⋯(disabled)`。创建对象下拉 = 六类要素入口 → **进入对应绘制工具**（复用 T5.6 的垂直工具条激活路径常量；本任务先以本地常量对接 draw 工具激活参数，T5.6 统一收口到 toolIA 模块时替换引用——若 T5.6 未开工则以 `tools.activate('draw-polygon'|'draw-line'|'draw-point', { elementType, perspective:false })` 现签名直连）。

### 图层管理标签

- 现有 LayerPanel 迁入（命令路径不变：UpdateLayerCommand）。
- 增补：每层对象计数（`layer.objectIds.length`）；新建图层按钮（SceneManager.addLayer 经 UpdateLayerCommand 或专用路径，P0 支持：新建/删除/重命名/显隐/锁定/透明度沿用现状）。
- 删除非空图层语义：跟随契约（成员置 null 落「未分层」），UI 弹轻量确认（复用 notice/Toast 通道）。
