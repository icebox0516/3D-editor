## 注入提示词（原文）

> 实现 IO 层，负责场景序列化和外部数据导入，严格遵循「导入产物是标准 Element，不是不可编辑的 Mesh」。
>
> 【核心约束】
> 1. SceneSerializer 只做 SceneData 和 JSON 的互转，不包含任何业务逻辑
> 2. JSON 导入必须生成标准 Element 对象，导入后可以正常编辑、改样式、改高度
> 3. 场景文件只保存数据定义和引用，不保存模型文件本体
>
> 【任务】
> 1. SceneSerializer：serialize(sceneData): string；deserialize(jsonString): SceneData；带版本号校验
> 2. JSON Importer：配置化映射机制（映射配置文件定义 JSON 字段 -> Element类型/Geometry格式/默认Style）；parse 转成标准 SceneObject 数组；必须是标准 BuildingElement/RoadElement 等；失败给字段级错误提示
> 3. 基础 Exporter：导出标准 Scene JSON
>
> 【输出要求】所有 IO 代码在 io 目录，导入输出的对象可以直接加入 SceneManager，和手绘的对象完全一致。

## 偏差与补充（优先级高于上方提示词）

- 导入产物先过 `validateGeometry` 与 ElementDefinition.validate，非法对象进 errors 不入 objects。
- 提供 `assets/mappings/building.example.json` 示例映射与 `tests/io/fixtures/buildings.sample.json` 示例数据（字段与映射严格对应，含 floors 字段供 `"floors*3"` 表达式映射演示）。
- deserialize 遇不识别版本抛错（信息含版本号）；缺 objects/layers 字段抛定位错误。
