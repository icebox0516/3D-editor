# T6.4 · GeometryBuilder 与渲染管线接入

> **状态：done（2026-09-12）** ｜ 阶段：6（形状驱动创建与样式引擎） ｜ 前置依赖：T6.3 done ｜ 执行者：threejs-expert ｜ 需求来源：《绘制需求变更.md（定稿 v2）》第六节 ｜ 分域契约：contracts/stage6-region.md

## 任务背景

打通 Shape → Geometry → Style → 渲染完整链路，实现三类修改的解耦更新；渲染模式改场景级覆盖。旧要素渲染管线不动（共存）。含 three 代码，全落 runtime。

## 验收清单

- [x] `GeometryBuilder(shape, semantic) → THREE.BufferGeometry`：**落位 `src/runtime/geometry/GeometryBuilder.ts`（含 three 的模块仅在 runtime）**，输入 RegionShape+RegionSemantic 纯数据（参数化点列来自 T6.1 domain 纯函数）：polygon 三角化（沿用既有几何算法）、rectangle/circle/ellipse/freehand 参数化生成、line 折线管状/带宽面（**road 带宽读 semantic.properties.width，几何在构建器不在插件**）、point 保留锚点几何、baseHeight → y 平移；UV/法线产出
- [x] RegionRenderer（runtime/renderers 新成员，注册进 RendererRegistry）：RegionObject 增删改 → StyleEngine 实例生命周期管理；object.userData.objectId 拾取映射接入（pickObject / pickInRect 框选）
- [x] 三类修改更新逻辑（解耦断言单测，2026-09-11 审计拆分）：
  - 改 Shape：GeometryBuilder 重生成 → `instance.setGeometry()` 重绑；**材质实例与样式参数不变**
  - 改 Semantic·类型切换：旧实例 dispose → 新类型默认预设 createStyle（材质随预设重建）；**几何顶点不动**；归层由命令层完成
  - 改 Semantic·业务参数（如 road.width）：GeometryBuilder 按参数重生成几何 → `setGeometry` 重绑；**材质实例不重建**（同 Shape 的 setGeometry 路径）
  - 改 Style：旧实例 dispose → 新预设 createStyle；**BufferGeometry 复用不重建**；断言——`object:updated keys=['style']` 时渲染器**比对 presetId 前后值**分辨「切预设（dispose+create）vs 调参数（update）」
- [x] 图层联动：visible / locked / opacity 对 RegionObject 生效（opacity 语义与旧要素一致）
- [x] 资源纪律：disposeStyle 链路完整；删除对象后模板引用计数归零（内存泄漏单测）
- [x] 渲染模式改造：线框 / X-Ray 改为场景级 overrideMaterial 全局覆盖（RenderModeState 重构为状态 + composeRenderPasses 分遍计划，Shader 插件零配合）；**覆盖范围限内容组——Gizmo / 绘制预览 / 网格 / 环境豁免（沿 RenderModeState 现状边界，2026-09-11 审计注记）**；着色模式维持现状；三模式切换对 RegionObject 与旧要素同时生效
- [x] 旧要素（building/marker/资产模型）渲染与拾取零回归
