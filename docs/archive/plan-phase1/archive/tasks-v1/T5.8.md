## 任务背景

按阶段门 Q4 裁定执行**行业惯例手势迁移**（UE/Unity 同款）：左键=纯选择/确认、**右键拖拽=旋转视角**、中键拖拽=平移、滚轮=缩放、**右键点按=上下文菜单**、ESC=取消当前操作（唯一退出手势）。现状是 OrbitControls 默认（左拖=旋转）+ 右键=取消工具。同时落地四类右键菜单（需求第三十三章）与轻量 Toast 反馈（第三十四章，替代/升级 notice 条）。

## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### 手势重映射（runtime + app）

- `OrbitControls.mouseButtons`：`LEFT = null`（不旋转，点选/框选归工具层）、`RIGHT = ROTATE`、`MIDDLE = PAN`；滚轮缩放保持默认。touches 同步审视（单指=选择语义优先，双指=旋转/缩放——实现中明确并测试可测部分）。
- input.ts 右键语义分类器（纯函数 `classifyRightButton(dx, dy, dtMs)`，node 可测）：pointerdown 记起点 → pointerup 时位移 <4px 判定「点按 → 上下文菜单」（发射 `contextmenu:requested {x, y}` 事件给 UI store），否则视为旋转（OrbitControls 已消费拖拽）。`contextmenu` 原生事件继续 preventDefault。
- **ESC 成为唯一退出手势**（绘制/放置退出）；Context Toolbar 退出按钮兜底；README 操作指南必须同步写明（破坏性交互变更，明确告知）。
- 中键平移期间不触发工具 onPointerDown（button='middle' 早退，现状核对）。

### 四类右键菜单（ui，复用 T5.2 action 体系）

`src/ui/menus/contextMenus.ts` 纯模型 `buildContextMenu(target, state)`：

- **视口对象**（pickObject 命中）：复制 / 粘贴（同位置偏移语义沿用）/ 删除(danger) / 聚焦(F) / 隐藏 / 锁定 / 移动至图层 ▾（图层清单）/ 重命名（聚焦 Inspector 名称字段）
- **视口空白**：创建对象 ▾（六类绘制入口，同垂直条）/ 视角 ▾ / 渲染模式 ▾ / 网格 / 显示设置（disabled）/ 绘制中额外首项「取消绘制 (Esc)」
- **Outliner 行**：重命名 / 复制 / 删除(danger) / 隐藏 / 锁定 / 聚焦 / 移动至图层 ▾
- **Content Browser 卡片**：添加到场景（= 点击放置）/ 复制(disabled) / 重命名(disabled) / 删除(disabled) / 查看详情（disabled，P1）

`ContextMenu.tsx` 组件：定位（视口内翻转防溢出）、键盘导航、Esc/点击外部关闭、`role="menu"`、danger 项 `--danger` 着色。

### Toast（ui）

- `src/ui/feedback/toastStore.ts`：队列 reducer `{ push(kind, text), dismiss(id), tick }`，TTL 4.5s，上限 3 条（超出挤掉最旧）；`aria-live="polite"`、`role="status"`；右下角浮层（`--z-toast`），不抢焦点。
- 既有 notice（导入结果/保存失败/资产清单失败）全部迁移 Toast；MenuBar notice 条退役。
