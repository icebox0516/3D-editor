## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### 标签结构

- 复用 T5.3 的 `TabStrip`：`对象属性 ｜ 环境设置 ｜ 全局设置`。标签选择存 workspaceStore（跨选变化保持，含「设置」action 与菜单跳转目标）。

### 分组模型（纯数据，node 可测）

- `src/ui/panels/inspectorModel.ts`：`sectionsFor(object): InspectorSection[]`——按类型产出分组：
  - `Transform`：Position/Rotation/Scale 三排九值（现有控件复用，弧度/度显示沿用现状）
  - `Appearance`：样式参数（StyleParametersForm 复用）+ Opacity + Visible + Cast Shadow（无数据源的字段 disabled 占位，不做假数据）
  - 类型参数组（建筑：楼层/高度/基底高；道路：宽度/mode；绿地/水面/停车场：面积等派生只读值**仅当现数据源可得**，否则不显示；点位：坐标只读）
  - `Metadata`：名称（可编辑→UpdateObjectCommand）/ 类型 / ID（只读）/ 图层归属（下拉→ChangeLayerCommand，从 Advanced 上移）
  - `Advanced`：碰撞 / 标注（disabled 占位）
- 折叠状态：`collapsedSections: Record<string, boolean>` 存 workspaceStore，默认全展开、Transform 置顶。组头点击折叠（28px 条 + 展开指示 ▸）。
- **差异化的底线是数据真相**：只有场景数据里真实存在的参数才给控件；需求第十九章中无数据源的字段（植被密度、流向、车位标线等）一律不出现，待后续要素参数扩展时经注册制接入。

### 三态呈现

- **空态**（selectedIds 空）：图标 + 「暂无选中对象」+ 「请在场景中选择一个对象」；标签仍可切到环境/全局。
- **单选**：分组面板（上述）。
- **多选**（selectedIds.length > 1）：只读汇总条（「已选 N 个对象 · 类型分布」）+ Transform 组只读显示首个值，编辑控件隐藏，提示「批量编辑将在阶段 6 提供」。防止 P0 误改首对象。

### 环境设置标签

EnvironmentPanel 整体迁入（预设切换 + 昼夜等既有参数，接线回调不变）。渲染模式（Shaded/Wireframe/X-Ray）的**消费**在 T5.7，本任务标签内先不显示该组（避免不可用控件）。

### 全局设置标签

- GridSettings 迁入（网格显示/间距/吸附步长，setGrid 链路不变）。
- 单位：`Unit: m`（只读显示行）。
- 操作偏好 / 快捷键 / 编辑器行为：分组标题 + disabled 占位（快捷键项可跳「帮助→快捷键」弹层，若 T5.2 已建）。
