## 任务背景

样式系统升级为插件化：一预设一文件、统一公共入口调度、支持任意 ShaderMaterial（含 Shadertoy 移植）。落位 `src/runtime/styles/`（three 白名单内），TypeScript 强类型契约。旧 MaterialFactory / StyleRegistry 本任务不动（共存，T6.3 迁移、T6.7 清理）。

- [x] `src/runtime/styles/engine.ts`：`createStyle(geometry, shapeType, semanticType, presetId, overrides?)` / `updateStyle(instance, params)` / `disposeStyle(instance)`——纯函数无状态；参数校验 → 默认值合并（沿用 StyleParameter 语义与 min/max 钳制）→ 注册表路由 → 插件 build

- [x] `src/runtime/styles/` 构建路由注册表：`import.meta.glob` 扫描插件文件建立 `presetId → build` 映射（仅构建函数；**registries 层永不含构建函数**——DAG 禁止 registries→runtime）；首版不做按预设代码分包（升级路径见分域契约 §B）
