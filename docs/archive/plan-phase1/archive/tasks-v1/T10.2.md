## 任务清单

### 1. 模式启用与键位（stage10 §E）

- MODES 表 measure `enabled:true / verticalGroup:'measure' / accent:'--mode-measure'`（hint/hudHint/inspectorGuide 四卡位按其余六模式规格补全）。
- `ALT_MODE_ORDER` 第 7 位 → `'measure'`（Alt+7 生效；第 8 位 analysis 留待 T10.3）。
- 切入测量模式时若在绘制/放置中先自动取消（沿既有模式切换语义）；**模式退出不清空测量会话**（MeasureSession 生命周期归组合根，仅「清除全部」与显式动作清）。

### 2. 垂直条测量分组

- 新增 `measure` 分组：四子工具按钮（距离/高度差/面积/角度，lucide 图标，无数字键）；测量模式置顶本分组、其余模式折叠进「更多」抽屉（机制既有，零新逻辑）；激活琥珀高亮、再次点击退出（同既有工具语义）。

### 3. ContextToolbar 测量态

- 测量工具激活时中段：**四 kind 芯片**即切（沿绘制五形状芯片先例）+ 尾段「删除上一条」（=MeasureSession.removeLast，空表禁用）与「清除全部」（confirm 无需——会话态可重测）两按钮。
- 「删除上一条」快捷键 Delete/Backspace（测量工具激活时；有草稿先弃草稿）。

### 4. 状态栏测量读数段

- `describeMeasureStatus` 纯函数 + 渲染：段长/总长（distance）、三读数（height）、面积（area）、角度（angle）、error 拦截提示；游标拾取坐标（含 y，定宽两位小数）；工具退出空载荷复位。

### 5. 菜单与引导

- `tool.measure` 占位 → 「工具 → 测量」四子工具子菜单（checked 随激活工具同源）。
- Inspector 空态引导卡（测量模式四卡位：说明 + 快速开始——四子工具与结束手势）；HUD 徽标全名 + 专属色 + 一行引导（沿六联动 ⑤⑥）。

### 6. 视觉登记与令牌

- tokens.css 新增 `--mode-measure` 专属色（夜间制图台语言内选色，徽标描边/文字限定用途）；DESIGN.md 新增 **§5.22 测量标注**：覆盖层三数值（线 1px/端点 4px/标签字号与配色——测量用色须与琥珀参考线、幽灵蓝区分，登记单一对照源）+ 模式分组/芯片/读数段规范。

### 7. 测试

- describeMeasureStatus 分节纯函数单测；ALT_MODE_ORDER 路由更新既有键表测试；菜单模型 tool.measure 子菜单结构测试；芯片/按钮可用态（measure:changed count）store 桥接测试。视觉呈现归 T10.5 像素验收。
