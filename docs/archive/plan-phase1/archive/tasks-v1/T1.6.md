## 注入提示词（原文）

> 实现编辑器 Tool 工具系统，严格遵循「工具产生意图，Command 落地修改」的原则。
>
> 【核心约束】
> 1. 工具不能直接修改 Scene 数据，不能直接操作渲染对象
> 2. 任何修改都通过创建 Command 交给 HistoryManager 执行
> 3. 同一时刻只能有一个激活工具，切换工具自动停用上一个
>
> 【任务】
> 1. Tool 基础接口：id/name/activate/deactivate/onPointerDown/onPointerMove/onPointerUp/onKeyDown/cancel；ToolContext：scene/selection/commands/camera/renderer/input/viewport
> 2. ToolManager 类：register/activate/deactivate/getActiveTool/cancel；切换自动清理上一工具状态
> 3. 核心工具：SelectTool（点击射线检测选中，支持多选）；TransformTool（调用 Gizmo，拖拽结束生成 TransformCommand）；PlacementTool（接收 assetId，Ghost 预览跟随鼠标，左键生成 CreateObjectCommand，连续放置，右键/ESC 取消，随机旋转缩放参数，Ghost 不进正式 Scene）
> 4. PreviewManager：管理所有临时预览（绘制预览、Ghost、Gizmo），show/update/hide/clear，与正式场景完全隔离
>
> 【输出要求】所有工具在 editor/tools 目录下，每个工具单独文件夹。工具只负责交互逻辑，修改全部走 Command。

## 偏差与补充（优先级高于上方提示词）

- **（重要）提示词 ToolContext 直接含 renderer——会造成 editor→runtime 反向依赖，违反分层 DAG**。改为 CONTRACTS.md 的 Port 注入方案；DOM 指针事件由 app 层（`src/app/input.ts`）归一化为 `PointerEventInfo` 后转发 ToolManager。
- TransformTool 本任务仅留桩（activate 时经 GizmoPort attach，Gizmo 实现在 T2.4）；本任务验收聚焦 SelectTool 与 PlacementTool。
- PlacementTool 参数：`{ assetId, continuous: true, randomRotation?: [min,max], randomScale?: [min,max] }`；左键放置（CreateObjectCommand）、右键/ESC 退出且已放置对象保留；Ghost 经 PreviewPort，不进 SceneManager。
- `src/app/input.ts` 同时挂全局快捷键表：Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z、Delete、ESC、W/E/R（W/E/R 此时无 Gizmo 可空实现，T2.4 接管）。

## 验收标准

- ToolManager：activate 自动 deactivate 上一工具并 emit tool:changed；同一时刻仅一个激活。
- SelectTool：命中→select；shift 点击→add/remove 切换；点空处→clear。
- PlacementTool：FakePort 模拟移动+左键×3 → 场景 3 个 ModelObject、Ghost 从未进 SceneManager、历史 3 条；右键退出后 activeTool=null；随机旋转/缩放落在配置区间。
- 工具代码零 three 导入、零直接 SceneManager 写入（写操作只见 CreateObjectCommand）。
- 守护三连全绿。
