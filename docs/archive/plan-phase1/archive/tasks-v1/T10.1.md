## 任务清单

### 1. 契约类型与事件（editor 层）

- `MeasureKind / MeasureItem / MeasureSession`（stage10 §A：四不变式——会话态、纯数据、零场景副作用；`MeasureSession` 切工具**不清空**，模式退出/清除全部才清）。
- EventMap 增补 `measure:status`（MeasureStatusPayload）与 `measure:changed`（{count}）——stage10 §B 签名为准；空载荷复位先例沿 draw:status。
- ID 前缀 `measure_`（createId）。

### 2. 四类测量工具（editor/tools/measure）

- 单实现类 + kind 参数（沿 DrawToolBase shapeType 先例），四个 id 注册 ToolRegistry：`measure.distance / measure.height / measure.area / measure.angle`。
- 交互语义按 stage10 §A 表：distance 逐点+双击/Enter 完成（末点去重 ε=0.01m）；height 2 点自动完成；area ≥3 非共线+双击完成（共线拦截 error 草稿保留）；angle 3 点自动完成（∠ABC）。
- 拾取经 `viewport.surfacePoint`；吸附 G/Shift/A 作用于 x/z（snap.ts 复用），y 保留；**不切机位不锁旋转**。
- `cancel()`（ESC）只弃草稿（measure:status 空载荷 + updateDraft(null)），已提交项不动。
- 移动/落点/完成/拦截全程发 `measure:status`（字段按 kind 最小集）。

### 3. MeasurePort 实现（runtime/services/MeasureOverlay）

- stage10 §B 渲染纪律逐条落实：恒驻组 `__measure_overlay__` + 池化、AUX_LAYER + depthTest:false + renderOrder 1001、端点 4px 屏幕恒定。
- **标签 Sprite**：canvas 纹理（DPR 2x）、文字变更才重绘、`frame()` 屏幕恒定字号（沿 AlignGuides 换算）；标签内容按 kind（段长/总长/三读数/面积/角度，单位 m/m²/°，两位小数）。
- `updateDraft / updateMeasurements / clear` 三方法；弹性段 = 末点→cursor（area 闭合环含 cursor）。
- Renderer 接线四点沿 AlignGuides 同位（构造/sink 装配/frame 调用/dispose）。

### 4. surfacePoint 实现（runtime viewport 服务）

- 表面优先（content 对象 raycast 交点世界坐标；AUX/gizmo/网格/地面辅助不参与）→ 未命中落 y=0 地面平面 → 射线近水平（交点距相机 >2000m）返回 null。

### 5. 组合根装配（app）

- MeasureSession 单例 + MeasureOverlay 实例化注入 EditorFacade 工具上下文；测量工具注册 ToolRegistry。

### 6. 测试（TDD）
