## 任务背景

低频全局功能要从工具条收进**主菜单栏**（文件/编辑/场景/资产/工具/视图/帮助），顶部右侧固定撤销/重做/保存与保存状态。保存语义按阶段门 Q5 裁定：**dirty 位 + 下载制**——任意场景变更 →「修改未保存」，保存 = 下载 JSON（成功清 dirty、失败 Toast 不静默），「保存中」为瞬态占位；beforeunload 脏退出守卫。不引入 localStorage 场景自动保存。

菜单是纯数据模型 + 统一 action 路由：本任务建立的 action 体系将被 T5.6（快捷键）、T5.8（右键菜单）复用，属 P0 的骨架设施。

### Action 路由（app 层，io 与剪贴板归位）

- `src/app/actions.ts`：`createEditorActions(deps): { dispatch(actionId, payload?): void }`。deps = facade + InputController 共享能力 + workspaceStore。InputController 内部的剪贴板/删除/全选逻辑**抽取为共享模块**（如 `src/app/editorActionsCore.ts`），InputController 改为委托调用（行为零变化，既有 input 相关测试守护）。
- UI 侧菜单组件只发 actionId 回调（`onAction`），不感知 io。
- 打开/导入的文件读取留在 app 层 action 内（复用现有 Toolbar readFile 模式）。

### 保存状态机（纯 reducer，node 可测）

- `src/ui/saveStatus.ts`：`SaveState = 'saved' | 'saving' | 'dirty' | 'error'`；`reduce(state, event)` 处理 `SCENE_CHANGED / SAVE_START / SAVE_OK / SAVE_FAIL / SCENE_LOADED`。
- dirty 判定（app 层接线）：节流 500ms 快照对比——`facade.saveScene()` 字符串 !== lastSavedSnapshot → dirty；openScene 与保存成功后刷新 lastSavedSnapshot 并置 saved。**不用 scene:changed 计数**（openScene 也发该事件，计数法会误报）。
- 保存失败：try/catch 包住 serialize+下载，失败 → error 态 + Toast（Toast 体系 T5.8 前先沿用 Toolbar notice 呈现）。
- beforeunload：app 层 useEffect，dirty/error 时 `e.preventDefault(); e.returnValue = ''`。

### 顶部右侧常驻区

`撤销 / 重做｜保存 ● 状态｜布局(disabled) / 设置`。状态点文案：已保存 / 保存中… / 修改未保存 / 保存失败（`--success`/`--accent`/`--ink-3`/`--danger` 着色）。旧 Toolbar 组件退役，其 notice 机制由本任务的顶部提示条承接（样式沿用 `.ed-notice`）。

### 菜单交互（UX 检查项）

- 点击菜单名展开、再点/点击外部/Esc 关闭；hover 切换顶层项（已展开时）。
- 键盘可达：方向键导航、Enter 触发、Esc 关闭；`role="menu"/"menuitem"`、`aria-haspopup`、`aria-disabled`。
- 快捷键提示右对齐等宽键帽（`.ed-kbd`）。
