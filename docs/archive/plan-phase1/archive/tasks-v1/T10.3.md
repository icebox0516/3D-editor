## 任务清单

### 1. 统计聚合纯函数（domain，stage10 §D 签名为准）

- `computeSceneStats(data: SceneData)`：分图层行（layerName / regionCount / modelCount / areaSum / subRows 按语义分节）+ 合计行；口径注记——水平投影面积（多边形 polygonArea、圆/椭圆参数化、line/point 计 0、model 不计）、组壳不计、隐藏图层照常统计（数据口径非显示口径）。
- 单测：空场景 / 混合语义 / 含组壳嵌套 / 含 line/point 零面积 / 合计一致性。

### 2. 报表弹层（UI）

- 「场景 → 场景统计」（`scene.stats` 转正）打开 dialog：合计行置顶 + 分图层表格（图层名 / region 数（按语义分节小行）/ model 数 / 面积合计），两位小数与千分位格式化；空场景空态文案。
- dialog 走 T9.1 根浮层容器体系；关闭即数据失效（每次打开重算，无缓存失效问题）。

### 3. 分析模式启用（stage10 §E）

- MODES 表 analysis `enabled:true / verticalGroup:null / accent:'--mode-analysis'`（四卡位补全——非工具型：说明统计与日照两类能力、日照标注「T10.4 交付」）。
- `ALT_MODE_ORDER` 第 8 位 → `'analysis'`（Alt+8）。
- ContextToolbar 分析态：中段「场景统计」按钮（同源菜单 action）；日照入口**占位禁用**（T10.4 接线，标注清晰）。
- 禁用模式回落语义核对：workspaceStore 持久化「禁用的测量/分析模式不可恢复回落场景」既有守卫随启用自然失效——移除该特判（若存在）并在测试更新（T7.3 遗留注记，layoutPresets.ts / workspaceStore.ts）。

### 4. 视觉登记

- `--mode-analysis` 令牌；DESIGN.md 新增 **§5.23 场景统计报表**：表格密度/分节小行/合计行样式（夜间制图台语言）。

### 5. 测试

- computeSceneStats 全口径单测；菜单模型 scene.stats 转正测试更新；Alt+8 路由键表更新；分析模式引导卡/回落守卫移除的回归测试。
