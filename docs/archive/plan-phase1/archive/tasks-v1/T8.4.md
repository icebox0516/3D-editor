## 任务清单

- **HUD 渲染模式下拉扩展**，按「常规/诊断」**两组分隔**呈现（调研补，UE Buffer 类收进子级分组先例——降低误触、留扩展空间；视图菜单三路同源同步）：
  - 常规组（既有）：着色 Shaded / 线框 Wireframe / X-Ray；
  - 诊断组（新）：
    - **灰模（Clay）**：内容遍 OverrideMaterial **MeshBasicMaterial 单色**（≈UE Lighting Only 语义：无光影无贴图；选型注记防走样成 Lambert+环境光即 UE Detail Lighting 变体，后者依赖环境预设违反正交性目标）；透视遮挡关系保留；
    - **法线（Normals）**：内容遍 OverrideMaterial MeshNormalMaterial（验收口径：RGB=世界空间法线，与 UE World Normal 视觉等价）；
    - **孤岛高亮（数据卫生档）**：语义=「未归入语义图层的对象」高亮、其余降暗（与「未分类」兜底层对应；SketchUp Color by Layer「数据属性驱动视口着色」范式的降暗变体）；**HUD 角标计数**「未归类对象：N」（N=0 显示「全部已归类」）——数据卫生验收从纯视觉变可量化（调研补）。中文主导命名，英文标注避用 Isolate（防与 Maya isolate select 仅显示选中语义撞车）。
- **架构约束**：沿 T6.4 分遍 overrideMaterial 架构（内容遍 override/环境遍/辅助遍豁免矩阵不变）；每遍 override 材质池按需构造缓存复用，**切换一次性遍历不进帧路径**。
- **正交性**：与环境预设（day/night…）/样式参数/图层透明度任意组合下切换与恢复无残留（override 撤除后材质/贴图/阴影状态完全回原；图层 opacity 乘算语义在诊断档下维持或明确降级并注记）。
- **豁免面**：Gizmo/绘制预览/顶点句柄/参考线（T8.1）等 AUX 层不受诊断 override 影响（沿既有豁免矩阵）；Sprite 独立渲染路径已知边界注记沿 T6.4 ⑦。
- **档位克制**（调研裁定）：六档即合理全集，不仿 Unity Debug 组堆 Overdraw/Mipmaps 类引擎管线诊断档。
