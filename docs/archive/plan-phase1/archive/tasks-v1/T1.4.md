## 注入提示词（原文）

> 实现 runtime 运行时渲染层，核心职责是「业务数据 → Three.js 对象」的单向映射。
>
> 【核心约束】
> 1. 运行时层**只读不改** Scene 数据，绝对不能反向修改 SceneObject 的任何属性
> 2. 所有业务对象通过 Adapter 映射到 Three.js，不能直接把 THREE.Mesh 当业务对象用
> 3. userData 只能存 objectId 做映射辅助，不能存业务数据
>
> 【任务】
> 1. RuntimeObjectMap 类：Map 维护 业务ID -> THREE.Object3D 映射；set/get/delete，支持 userData.objectId 反查
> 2. ObjectAdapter 抽象类：create/update/dispose
> 3. ElementRenderer 体系：基类（supports/create/update/dispose）；BuildingRenderer（ExtrudeGeometry 挤出 Polygon）；基础 GreenRenderer、WaterRenderer；样式应用（StyleReference → StyleRegistry 取样式生成材质）
> 4. AssetLoader 类：load 加载 ModelAsset 返回 THREE.Group；基础缓存（同 assetId 不重复加载）；支持 InstancedMesh 实例化渲染
> 5. Renderer 基类：初始化场景、相机、光照、地面；attach/update/detach 同步 SceneObject
>
> 【输出要求】所有渲染相关代码都在 runtime 目录，业务层完全不感知 Three.js 的存在。

## 偏差与补充（优先级高于上方提示词）

- AssetLoader 的 InstancedMesh 完整优化在 T2.3，本任务仅「同 assetId 缓存共享 geometry/material，多实例克隆」。
- 额外实现 CONTRACTS.md 的 `ViewportPort / CameraPort / PreviewPort` 运行时实现类（`RuntimeViewport / CameraController / PreviewManager`），供 T1.6 注入（依赖倒置：接口定义在 editor，实现在 runtime，装配在 app）。
- `MaterialFactory`：`StyleDefinition + ResolvedStyle → THREE.MeshStandardMaterial`（color/opacity/emissive/metalness/roughness/flatShading/doubleSide/wireframe 全参数映射；opacity<1 时 transparent=true）。
- 新建场景默认环境：天空渐变 + 无限地面（大平面 + 网格辅助线）+ 平行光带阴影 + 环境光。
- Renderer 监听 EventBus 的 `object:*` 事件驱动 attach/update/detach。
