## 主代理派发裁决（随门记录，2026-09-12）

- **裁决 A（旧契约类型面收口删除）**：legacy-elements.md 预留「Element/ElementRegistry/StyleRegistry/StyleDefinition/StyleReference/resolveStyle 最终去留随 T6.9 收口」——JsonImporter v2 重设计后上述类型面零消费者，随本任务删除；`StyleParameter` / `StyleParameterType` 保留并迁独立文件（阶段 6 语义定义/预设元数据/UI 表单消费）；`EditorFacade.registries` 删 `elements`/`styles` 字段、`ToolContext.registries` 收窄为 `{ assets }`。基础契约同步由主代理在验收后执行（子代理禁止改 CONTRACTS.md）。
- **裁决 B（导入映射 v2 形态）**：
  ```ts
  interface ImportMapping {
    version: '2.0';
    rootArray: string;                      // 点分 JSON Path（沿 v1）
    semanticType: SemanticType;             // 十类语义，取代 v1 elementType
    geometry: { path: string;               // 沿 v1 三格式：xy-array / xyz-array / ring-array
                format: 'xy-array' | 'xyz-array' | 'ring-array';
                shape?: 'polygon' | 'line' | 'point' };  // 显式覆写（xy/xyz 足迹场景）
    fields: Record<string, string>;         // 目标 "name" → 对象名；其余 → semantic.properties；乘数表达式 "floors*3" 沿用
    defaults: { presetId?: string;          // 缺省 = 语义 defaultPresetId
                layerName?: string;         // 缺省 = 语义 defaultLayerName（写入 metadata.layerName）
                [k: string]: unknown };     // 其余键 → semantic.properties 默认值
  }
  ```
  shape 推断（无 `geometry.shape` 覆写时）：ring-array → polygon；xy/xyz-array 单点 → point、≥2 点 → line。ring-array 多环取外环为 points，内环丢弃记告警。`closed`：polygon=true，line/point=false；`baseHeight` = 语义 defaultBaseHeight；`options` 不写（导入形状为显式点列，无参数化缓存）。
- 裁决 C（收尾语义）：导入告警与自动修复语义沿用 v1——NOT_CLOSED 补闭合点与顺时针反转就地修复后收录并附「已修复」说明；SELF_INTERSECT / TOO_FEW_VERTICES / INVALID_COORD 不可修复 → 对象进 errors 不入 objects。导入器零注册表依赖（不再注入 ElementRegistry）。
