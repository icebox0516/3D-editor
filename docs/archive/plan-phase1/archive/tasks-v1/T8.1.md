## 任务清单

### 1. 角度吸附

- **Gizmo rotate 步进**：rotate 模式下按步进吸附（TransformControls `rotationSnap`，弧度换算，模式沿 translationSnap 同步先例）；步长为会话级设置项，**默认 15°**（Unity 默认/UE 常用档，调研确认主流），控件形态=下拉固定档 5°/15°/45° + 自由数值输入（UE 下拉快切 + Unity 自由值合体），非法值不吸附。
- **相对步进语义注记（验收口径）**：TransformControls 旋转吸附为**相对拖拽起始姿态的增量步进**（7° 起拖落 7°+15°k），非 Unity 式绝对世界角度网格（15°k）——非缺陷，写入验收口径防 T8.6 误判（three.js 官方论坛确认语义）。
- **顶点编辑 A 键补齐**：VertexSnapPipeline 增注入 angleLock，会话中 A 键 45° 锁定（与 Shift 正交互斥、Shift 优先——与绘制管线完全同语义，`DrawToolBase.applyAids` 单一真相源复用）。
- 绘制管线 A=45° 为既有行为，回归锁定不改。

### 2. 地面高度层吸附（elevation snap）

- 作用面：gizmo translate 的 Y 轴拖拽（proxy.position.y；region 的 baseHeight 与 position.y 分工叠加语义不变，吸附只作用于 gizmo 侧 y）。
- 候选高度层：地面 y=0 + 场景内其他对象的底面/顶面派生层（region：baseHeight 与 baseHeight+height 合成；model：position.y 与 +包围盒高）。
- 容差复用对象吸附容差（`ObjectSnapConfig.threshold`，默认 0.5m）；开关入设置「吸附」组（新分项「高度吸附」，默认开）。
- 幂等修正模式沿 T7.6 对象吸附（objectChange 内从内部增量重算，外部修正不累积）。

### 3. 对齐参考线与自动对齐提示（拖拽期间的智能对齐）

- **触发**：gizmo translate 拖拽中，拖拽对象足迹（T7.6 并集先例）的**边缘或中心**与其他对象足迹的**边缘或中心**在 X 或 Z 轴进入容差时——吸附修正（复用 T7.6 边对齐机制，中心线对齐为新增维度）+ **参考线可视化**。
- **参考线视觉**：细线 + 端点标记（需求 §42 验收口径「不喧宾夺主」）；**视觉规范数值化**（调研补）：1px 等效线宽 + 端点 3–4px 方形/短刻线标记 + 颜色取既有 CSS 强调令牌（Figma 1px 红线先例；三数值登记 DESIGN.md 单一对照源，防实现随意发挥）；AUX_LAYER 独立组渲染（沿顶点句柄/足迹预览先例），拖拽会话期间存在、松手即逝，不产生对象、不入历史；**不做距离数字徽标**（Figma 的测距为独立功能，调研确认非参考线本体）。
- **场景化对齐源**（需求原文「同排建筑基线、道路边缘」）：同排基线 = 中心线对齐（x 或 z 中心重合生成中点连线）；道路边缘 = line region 足迹（中心线 ±width/2 条带边缘）作为对齐候选——由足迹管线自然覆盖，验收场景专项覆盖。
- 与 FootprintGhost 预览关系：ghost 显示吸附后位置（既有），参考线叠加显示对齐来源（新增）；两者同会话生命周期。

### 4. 吸附开关分级

- 全局设置「吸附」组扩为：网格（既有）/ 对象（既有）/ **角度（新）** / **高度（新）** + 容差（既有）+ 角度步长（新）。全部会话级偏好（不入历史、不随场景文件持久化——沿 ObjectSnapConfig 语义）。设置 UI 文案显式区分「吸附」（上述分项）与「绘制辅助锁定」（Shift 正交/A 角度/G 网格三键，既有行为）两组概念，总开关只压吸附分项、不影响绘制三键。
- Context Toolbar「吸附」toggle 升级为**总开关**语义：off = 全部吸附分项压下（不写各分项记忆，恢复 on 时各分项回设置值）；与菜单 tool.snap 路由同源同步。总开关状态为会话级。
- **按住 Ctrl 临时反转吸附总状态**（调研补，Unity/UE/Blender/Figma 四家标配旁路）：拖拽会话内按住 Ctrl = 总状态反转（开→关、关→开），松开恢复；作用于 gizmo 拖拽与顶点编辑；绘制管线 Shift/A/G 三键语义不变（Ctrl 在绘制中无占用，核实后接入）。Alt 不用（留给未来）。

### 5. 一次性「贴地」命令（阶段门裁定纳入）

- 选中对象右键菜单项「贴地」+ 快捷键：y 归 0 或吸附到下方最近高度候选层（高度吸附候选管线复用），单条历史（UE End 键/Snap to Floor 先例）；园区场景「把对象放回地面/平台面」高频操作。多选=逐对象贴地合一条 BatchCommand。
