## 范围

- **对齐**：多选对象对齐（X/Z 轴最小/最大/中心/均匀分布），经 BatchCommand（TransformCommand 组合）。
- **吸附增强**：现有网格吸附（1m 步长）之上的对象吸附（包围盒边/面对齐）；**Vertex/Edge 吸附属 CONTRACTS 排除项，不做**——如需解禁走按需门。
- **阵列**：选中对象线性阵列（数量 + 间距 + 方向），预览后确认，一条历史。
- **道路分割/合并**（2026-09-12 门 Q4 裁定自需求 6.2 并入）：line region 在指定节点处分割为两条、相邻两条合并为一条——shape 级几何命令（新增命令对象 + BatchCommand 语义不适用，单命令单历史）；完成后对象语义/样式保留；经 Context Toolbar 上下文项启用（T7.1 已留 disabled 占位）。**偏移不做**（等宽偏移几何成本高，width 参数覆盖多数诉求，记观察项）。
- 全部经工具/命令注册制接入（Context Toolbar 上下文项启用），不增加常驻按钮（需求 39 章准入规则）；对齐/阵列同时启用 T7.1 的 disabled 占位按钮。
