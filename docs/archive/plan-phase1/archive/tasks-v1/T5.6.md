## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

### 工具信息架构模块（纯数据，node 可测）

`src/ui/tools/toolIA.ts`：

- `VERTICAL_TOOLS`：六项 `{ id, label, icon, key, toolId, params }`——
  建筑→draw-polygon+building（键 1）、道路→draw-line+road（键 2）、绿地→draw-polygon+green（键 3）、水面→draw-polygon+water（键 4）、停车场→draw-polygon+parking（键 5）、点位→draw-point+marker（键 6）。键位为**阶段门新增裁定**（需求 13.2 未覆盖垂直条键位；Blender 数字键惯例，tooltip 展示）。
- `deriveMode(activeToolId, drawTarget)`：select/transform→`scene`；draw+building→`build`；draw+road→`road`；draw+green/water/parking→`terrain`；draw+marker→`annotation`；placement→`decoration`（纯函数）。
- `MODES`：八模式 `{ id, label, enabled }`——P0 仅 `scene` 可显式选择，其余 disabled 占位（measure/analysis 灰显 + tooltip「后续版本」；build/road/terrain/annotation 由绘制状态**派生**显示激活，不可手选——手选入口 P1 完整模式体系）。
- `contextToolsFor(state)`：默认组 = 选择 Q / 移动 W / 旋转 E / 缩放 R ｜ 吸附 G（toggle，checked=网格吸附）｜ 网格（toggle，checked=env.grid.visible）；绘制模式追加中段：要素类型切换器（同几何类内切换）+ 几何形态（线/面，仅道路类）+ 完成提示文案 + 退出按钮；P1 上下文工具（对齐/阵列/复制等）以 disabled 预注册。

### 垂直工具条组件

48px 常驻列：图标 24px 线性统一描边、尺寸统一、hover tooltip（名称 + 快捷键 + 一句操作提示）、激活态琥珀左缘竖线 + soft 底（沿用面板语言）；**再次点击退出当前绘制**（activate/deactivate toggle → 既有 tool:changed(null)→select 回退订阅零改动）。

### Context Toolbar 组件

左段 QWER 组（gizmo 模式，激活工具联动 store）→ 分隔 → 吸附/网格 toggle → 分隔 → 绘制上下文中段（按 contextToolsFor 动态）→ 右段：模式徽标（当前模式名，琥珀描边芯片）+ `Scene ▼` 模式选择器（P0 仅 scene 可选）。QWER 点击与快捷键同路由。

### 快捷键扩展（input.ts）

- `Q` → activate select；`1–6` → 垂直工具 toggle（激活中则 deactivate）；`G` → 网格显示 toggle（经 handle.setGrid 翻转 visible）。
- 保留既有：W/E/R（含 placement 工具内所有权）、F、Home、Esc、Delete、Ctrl+Z/Y/C/V/D。**Tab 不占用**（纯三维模式 P1）。
- 与 T5.2 action 体系对齐：快捷键表与菜单 shortcut 字段同源于 toolIA 导出的键表（单一真相源）。

### 退役清单

- toolIA 纯函数全覆盖；既有绘制/放置链路测试零回归；守护三件套全绿。
