## 实现要点（主代理已定方案，按此执行；遇阻先报告勿自行改方案）

### B1 归层（domain 单一真相源 + 完成时解析）

- Create `src/domain/elements/defaultLayers.ts`：导出 `DEFAULT_LAYER_NAME_BY_TYPE: Readonly<Record<string, string>>`（building→'Building'、road→'Roads'、green→'Green'、water→'Water'、parking→'Parking'、marker→'Annotation'、model→'Models'，与现 bootstrap 表内容一致）。
- Modify `src/app/bootstrap.ts`：本地 `DEFAULT_LAYER_BY_TYPE` 删除，`defaultLayerIdFor` 改用 domain 导出常量（导入侧行为零变化）。
- Modify `src/editor/tools/draw/DrawToolBase.ts` `createElement`：完成时按 `DEFAULT_LAYER_NAME_BY_TYPE[elementType]` 经 `ctx.sceneManager.getLayers()` 查名→id，写入 `create(type, { geometry, layerId })`（init.layerId 契约已支持；确认各 ElementDefinition.createDefault 正确消费 layerId）。**解析放完成时而非激活时**（图层可能在绘制期间被删）。类型无映射或名未命中 → layerId=null（现状兼容）。
- 检查 Point 工具 mergeBatch 连续段路径：撤销旧批重建更大批时 layerId 不丢（克隆保留或重解析均可，测试锁定）。

### B2 组合根订阅联动

- Modify `src/app/bootstrap.ts` createEditor 装配区：订阅 `object:removed` → id ∈ `selection.getSelectedIds()` 时 `selection.remove(id)`（逐事件处理即可，不做聚合）。订阅纳入既有退订清理模式（dispose 成对）。
- `openScene` 既有 `selection.clear()` 不动、不回归。SceneManager.clear 不发 object:removed（契约语义），无需另处理。

### B3 机位恢复

- Modify `src/runtime/services/CameraController.ts`：私有 `mode: CameraMode` 状态（初始 `'perspective'`），`setMode` 写入，新增 `getMode()` 读取（返回类型与 CameraPort 契约字面量集一致）。
- Modify `src/editor/tools/draw/DrawToolBase.ts`：activate 时记录 `savedMode = ctx.camera.getMode()`（在切 top 之前取）；deactivate 时 `if (this.enteredTop) ctx.camera.setMode(this.savedMode)` 替代硬编码 `'perspective'`。perspective 工具（不切 top）行为不变。
- Modify `src/app/bootstrap.ts` camera 空桩补 `getMode: () => 'perspective'`。
- editor 层测试 fake camera 同步补 `getMode`（缺省返回 'perspective'，测试可控）。
