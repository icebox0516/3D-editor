## 任务清单

### 1. 异类型多选分组编辑面板

- T7.5 Mixed 面板扩展：混 semantic.type 多选时，通用组（图层/可见/锁定）置顶不变，其下**按 semantic.type 分节**——每节头显示类型名 + 该类型对象计数（「建筑 ×2」），节内复用 T7.5 同类型语义组组件（类型切换/参数/预设，作用域=该节对象集合）。
- **节内混合值占位语义**（调研补，Unity "-"/UE 空白惯例）：节内参数值不一致时显示「—（混合）」占位，编辑提交后应用到节内全部对象；与 T7.5 单类型 MIXED 占位语义同源。
- 逐节提交互不误伤（节 A 改参数不动节 B 对象——沿 T7.5 逐键提交语义，作用域为节内对象集）；每节操作各自单条历史。

### 2. 批量重命名规则

- 多选（或单图层筛选集）右键/上下文入口「批量重命名…」：弹层配置 前缀 + 起始序号（默认 1）+ 步长（默认 1）+ 序号位数（1/2/3 位填充，默认 1 位）；**预览固定前 8 条实时刷新 + 「…共 N 项」**（Blender/UE 原生均无实时预览属社区诟病点，我方补齐为加分项）；确认 = 逐对象改名合一条 BatchCommand 单条历史。
- **查找/替换第二模式**（阶段门裁定纳入，Blender Ctrl+F2/UE Advanced Rename 双先例）：与前缀+序号模式单选互斥，共享同一实时预览路径；空查找串禁用确认；园区改名清理（「楼1」→「宿舍楼1」）高频场景。

### 3. 个人布局管理增强

- T7.3 个人布局补：**重命名**（布局弹层内联或弹窗）；**导出**（JSON 文件下载——布局字段 + name，sanitize 后载荷）；**导入**（文件上传，经 layoutPresets 同款 sanitize 校验，非法拒收提示）。
- 布局文件往返无损（导出→删→导入→应用等价）。

### 4. 图层面板补全：合并

- 源图层行操作「合并到…」→ 目标图层选择弹层（排除源自身与不可合并目标）→ 执行 = 源图层全部成员迁移（ChangeLayerCommand 批量）+ 删源图层，**一条可撤销 BatchCommand**；合并后目标图层计数正确、源图层从面板消失；undo 一次完整复原（成员回迁+源图层复活）。
- 边界：空图层可合并（等价删除）；「未分类」默认语义层不设为源（沿默认层保护先例——若现无此保护则一并加固）。

### 5. 资产库补全：标签浏览 + 排序

- Content Browser 展开态工具行增：**标签芯片**（manifest tags 聚合去重，点击切换筛选，与分类/搜索 AND 叠加）+ **排序下拉**（默认（现状序）/名称/分类）。
- 紧凑态不受影响；筛选/排序状态为面板会话态（不入持久化）。

### 6. 顺手清扫（T7.8 观察项）

- menuModel 同菜单多分隔线 React `file-sep` 重复 key 告警：分隔线 key 加唯一后缀消重（纯 console 卫生，零行为变更；沿 T6.10 ⑤「候选微修随后续任务顺手处理」先例）。

## 明确不做
