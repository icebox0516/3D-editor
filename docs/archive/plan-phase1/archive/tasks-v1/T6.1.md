## 验收清单

- [x] domain：`RegionObject`（shape / semantic / style 三层独立存储）+ `ShapeType` 七类（polygon / rectangle / circle / ellipse / freehand / line / point），字段与契约一致（含 baseHeight、closed、options 缓存）
- [x] domain：参数化形状点生成纯函数——矩形（长宽→角点）、圆（半径+分段→点列）、椭圆（两轴→点列）、自由形状（跟踪点列→道格拉斯-普克简化 + 可选平滑）；输出 Vec2[]，圆/椭圆参数存入 shape.options
- [x] domain：语义注册表——SemanticType 十类（unclassified / water / grass / plaza / parking / bare_land / road / building / poi / custom）注册制接入：每类含 label / 默认图层名 / 业务参数定义（road: width，building: height）/ 默认预设 id（unclassified→default_solid）/ **defaultBaseHeight**（贴地层抬升基准：road 0.06 / grass 0.12 / water 0.18，其余 0——数值沿现状 runtime SURFACE_ELEVATION，语义见分域契约 §A 高度合成）；`DEFAULT_LAYER_NAME_BY_TYPE` 扩展十类语义；禁止框架散落 `if (type === …)` 判断
  - **执行注记（主代理裁决，2026-09-11）**：`DEFAULT_LAYER_NAME_BY_TYPE` **未扩展**——water/road/building/parking 四键与旧要素类型撞键且目标值不同（旧表 water→'Water'，语义 water→'水面'），既有测试已锁定旧值，硬扩展必破坏共存；语义→默认图层名单一真相源 = 语义注册表 `defaultLayerName` 字段，旧表与十类语义图层统一翻转让 T6.7 收口（决策日志留痕）
- [x] domain：校验适配——validateGeometry 语义作用于 polygon / freehand（自相交 / 顶点不足拦截、顶点顺序修复）；参数化形状（rect/circle/ellipse）与 line / point 天然合法直通
- [x] editor：三条原子命令（TDD）——`ChangeShapeCommand`（形状类型切换与 points/options/baseHeight 变更）、`ChangeSemanticCommand`（**语义层一切变更**，分域契约 §A 注记：①类型切换 = 自动迁入类型默认图层 + presetId 置新类型默认预设 + overrides 清空，一条历史整体回退；②业务参数变更 = semantic.properties 键值修改，同命令承载；自动归层遇目标图层被删 → 落「未分层」，沿 bootstrap defaultLayerIdFor 现状）、`ChangePresetCommand`（presetId + overrides 变更；命名避开 v1 ChangeStyleCommand 同名冲突，见分域契约 §A/§D）；连续段合并语义沿用 HistoryManager 既有机制
- [x] RegionObject 过渡期序列化：**三层字段经 SceneSerializer 整体透传往返 + 反序列化结构校验测试锁定**（shape/semantic/style 持久化、保存/打开往返无损，v1 version 容器不变；io 层现状 serialize = 整体 stringify、不消费注册制 serialize/deserialize——**勿造无人消费的注册壳**；正式 v2 归 T6.9，分域契约 §D）
