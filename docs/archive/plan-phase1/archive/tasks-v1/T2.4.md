## 偏差与补充（优先级高于上方提示词；本任务 UI 为主，提示词覆盖不全，以需求文档为准）

- **Gizmo**：runtime 用 three `TransformControls` 实现 `GizmoPort`（`src/runtime/services/GizmoImpl.ts`）；拖拽中临时直接改渲染对象矩阵、不发事件不进历史（预览隔离），拖拽结束一次性 onDragEnd(before/after) → TransformTool 生成 TransformCommand。完整实现 TransformTool（替换 T1.6 桩）。
- **属性面板升级**：由 `StyleDefinition.parameters` 声明自动生成控件（color→取色器、number→滑杆+数值框、boolean→开关、select→下拉），写值经 ChangeStyleCommand(overrides)/ChangePropertyCommand；样式作用域下拉（当前对象/同类型/当前图层/全部使用该样式）批量执行 BatchCommand。
- **场景树**：按图层分组树；点击选中、眼睛/锁图标、双击重命名（ChangePropertyCommand）、搜索过滤并定位（focusObjects）；图层条目支持显示/锁/透明度滑杆/拖拽排序（ChangeLayerCommand）。
- **EnvironmentPanel**：环境预设下拉（白天/傍晚/夜景/科技），切换只改 SceneData.environment 并 emit scene:changed，随场景保存。
- **快捷键补全**：W/E/R 切 gizmo 模式、F 聚焦、Home 全景、Delete 删除、Ctrl+C/V、Ctrl+D 复制（偏移 1m，CreateObjectCommand）。
- **SelectTool 增强**：空白处拖拽=框选（PreviewPort 画 2D 框，屏幕矩形投影相交选中）；Ctrl 多选。
