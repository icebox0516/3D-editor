## 任务清单

### 1. 场景模板

- **数据形态**：`TemplatePayload { id; name; builtin: boolean; scene: SceneData }`；模板 = 完整 SceneData 快照。
- **内置模板**两套随构建打包（`src/io/templates/*.json` 静态导入，零 fetch）：「空园区」（等同现新建语义）与「示例园区」（轻量示范：少量 region/model、图层、环境预设——可由验收园区样例裁剪）。
- **用户模板**：localStorage 持久化（键沿 `t3d-editor.workspace` 先例命名）；「另存为模板…」= serialize 当前场景 + 命名弹层；管理动作（重命名/删除）在模板子菜单或管理弹层。
- **入口**：主菜单 文件 →「新建场景 ▾」子菜单（空场景/内置模板/用户模板分区）；「另存为模板…」入文件菜单。
- **实例化语义**：加载模板 = openScene(深拷贝 + **全量 id 重生成**——场景 id 与对象/图层 id 重建，防跨场景 id 冲突与模板原场景污染；Unity Hub/Figma duplicate「模板只读、实例全新」同语义)；新建经确认弹层（当前场景未保存时沿 beforeunload/dirty 语义提示），弹层含**三行摘要**（模板名/来源内置·个人/对象与图层数——管理预期防误建，调研补）。
- **用户模板容量兜底**（调研补）：数量达 20 套或总载荷约 1MB 触达时提示清理（localStorage 现实约束，超限拒存并提示删除旧模板）。

### 2. 批量导入

- **多文件**：导入入口支持一次选择多个 JSON 文件，每文件沿用当前单映射配置路径（ImportMapping v2，零注册表）；逐文件独立解析。
- **导入预览**：确认弹层列出每文件条目为**三态行**（拟导入 N 对象 / W 条告警 / X 条错误，图标+数字；控件形态对齐 Ant Design Upload file list 惯例——React 生态用户熟悉的视觉语言，调研补；单文件解析失败行置灰不阻断其余展示；告警沿 JsonImporter errors/autoFixed 既有产出）；确认后**全部入库 = 一条 BatchCommand 单条历史**；取消则零副作用。
- 导入语义与现有 JsonImporter 宽限规则完全一致（NOT_CLOSED 修复收录/自相交等排除报错），零新解析逻辑。

## 明确不做

- 批量**散布**（scatter，CONTRACTS 排除项）；
- DXF/GeoJSON/OBJ/FBX 等格式（排除项）；
- 模板资产化共享（导出/导入模板文件）——按需门另议；
- 「设为默认模板」记忆默认（阶段 8 门裁定不纳入，2026-09-13）；
- 映射配置编辑器（沿用现有映射配置路径，不新增编辑 UI）。
