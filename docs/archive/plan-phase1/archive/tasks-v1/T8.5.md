## 背景

SceneObject.parentId 契约字段自始存在但恒为 null（createRegionObject/modelFactory 均写 null）；Outliner 分组为图层虚分组（outlinerModel 注记「真实 parentId 分组归 P1」）；T5.8 行右键菜单已交付移动至图层等操作。本任务补齐 §9.3 清单中「分组」「拖拽调整层级」两缺口。

## 任务清单

### 1. 场景格式与数据层：group 对象类型

- 新增 `'group'` 对象类型：SceneObject 空壳（id/name/parentId/layerId/visible/locked/transform 恒等），无 shape/semantic/style/asset；**场景格式维持 version 2.0 增量扩展**（阶段门裁定 2026-09-13）：反序列化 fail-fast 类型校验放行 'group'——未知类型仍路径化报错，前向兼容语义注记入契约。
- **纯组织节点先例**（调研确认，UE Actor Folders + Blender Collections 双先例）：组不传递变换（Blender Parenting 才传变换、UE 文件夹非 Actor 无 transform）、删组不删成员（UE 删文件夹不删 Actor 同构）——Unity empty parent 传变换路线刻意不走。
- 层级不变式：树形无环（挂入前环检测拒绝）；子对象 layerId 独立于组（组不动图层归属）；组可嵌套；删除组 = 仅删组节点、成员上提父级（**不级联删除成员**——防误删，级联删除为显式二次确认动作可选）。
- 契约修订（主代理权限内 + 决策日志留痕）：SceneSerializer 校验面 + ID 前缀增 `group_`。

### 2. 命令与撤销

- GroupCommand（建组：选中对象收编为新组子级）/ UngroupCommand（解散：成员上提）/ ReparentCommand（拖拽换父/排序）——各自单条历史；成员迁移不改变对象自身 transform 世界语义（**组 transform 恒等**：本阶段组为纯组织节点非变换节点，世界变换不因挂组改变——杜绝嵌套变换矩阵复杂度）。

### 3. Outliner 树形 UI

- 大纲从「图层虚分组平铺」升级为**层级树**（组节点可折叠、成员缩进；图层分组视图保留为并列标签或视图切换——沿现有双标签先例裁量）；行计数显示组内直接成员数。
- **拖拽调整层级**：HTML5 dnd（图层排序先例）——拖对象/组到组节点=挂入；拖到同层间隙=排序/上提根级；非法落点（拖入自身后代=环）拒绝并提示。
- **drop indicator 三态视觉规范**（调研补，Unity Hierarchy/UE Outliner 拖拽指示先例——三形态可感知的前提）：行上半/下半区 = 1px 插入线（排序落点）；行体高亮 = 挂入目标；非法落点 = 禁止态样式 + 环拒绝 toast。
- **拖拽 hover 折叠组 800ms 自动展开**（拖离重置计时；调研补，树形 dnd 惯例——无此则折叠组无法成为落点）。
- 右键菜单增：分组（Group，快捷键 Ctrl+G）/ 解散组（Ctrl+Shift+G，PS/AI 跨域惯例）/ 重命名（既有）。
- **组行「选择成员」次级动作**（阶段门裁定纳入，UE 选文件夹=选中成员先例）：双击组行或右键菜单项「选中组内对象」=仅选成员不选壳——纯组织节点（组壳 Transform 只读）的一键批量入口（后续移动/改参/删除沿多选语义）；不动「单击=选壳」主语义。
- 与 Viewport/Inspector 联动：组节点可选（选组=选组壳，成员操作沿多选语义；Transform 对组壳只读注记）。

## 明确不做

- 组变换/组 gizmo 成组变换（组为纯组织节点；多选 gizmo 已由 T7.5 覆盖）；
- 图层语义变更（组≠图层，两体系并存）；
- 嵌套组的批量样式作用域扩展（作用域过滤面维持现状）；
- T7.2 Docking 类面板形态（远期）。
