## 实现要点（主代理已定方案；遇阻先报告勿自行改方案）

- **workspaceStore**（`src/ui/layout/workspaceStore.ts`，zustand）：`{ leftWidth, rightWidth, bottomHeight, hiddenPanels: {left,right,bottom}, collapsedSections: Record<string,boolean> }` + 纯函数 `clampPanelSize(zone, px)`（钳制表：左 180–420 默认 260、右 240–480 默认 320、底 60–320 默认 60）。纯逻辑放独立导出供 node 测试。
- **App.tsx 改 CSS Grid**：`grid-template-rows: auto auto 1fr auto auto`；主行 `grid-template-columns: 48px auto 1fr auto`。面板隐藏 = 该列/行宽归零收起，Viewport（`1fr`）自动扩展，不留空白（需求第四章）。
- **Splitter**（`src/ui/components/Splitter.tsx`）：pointer 事件拖拽写 store，命中区 4px + 视觉 1px 线，hover/active 高亮；拖拽期间 `body` 禁止选择。
- **PanelFrame**（`src/ui/components/PanelFrame.tsx`）：统一面板壳（标题/折叠按钮/隐藏按钮），折叠收成 28px 标题条；沿用 `.ed-panel` 视觉语言（小型大写标题、hairline 分隔、零新装饰）。
- **令牌增补**（tokens.css 声明 + DESIGN.md §4 登记）：`--menubar-h: 32px`、`--contextbar-h: 34px`、`--vtool-w: 48px`、`--panel-w-left: 260px`（覆盖旧 232px 值）、`--panel-w-right: 320px`（覆盖旧 288px）、`--browser-h-compact: 60px`、`--browser-h-expanded: 280px`。
- **视口占比自检函数**：`viewportShare(viewW, viewH, panels)` 纯函数（导出供测试）——1920×1080 默认布局下宽度占比 ≥65%（(1920−48−260−320)/1920 ≈ 67%），全隐藏时 ≥90%。
- App 装配生命周期（attach/detach、createEditor、缩略图链路）零改动，只动 JSX 结构与容器类名。

## 验收标准

- 四区一层骨架成形：菜单条（旧 Toolbar 内容）/上下文工具条占位/垂直条占位/左右面板/底部浏览器条/状态栏七段可见。

- `viewportShare` 断言：1920×1080 默认 ≥65%，全隐藏 ≥90%（node 纯计算）。
- workspaceStore 纯逻辑全覆盖（钳制边界/隐藏/折叠/复位默认）。
- 面板开合后画布渲染与拾取不错位（ViewportResizePolicy 逐帧自检兜底，浏览器目检确认）。
- 既有 730 测试零回归；守护三件套全绿。
- UX 检查项：面板控件 cursor-pointer、hover/active 状态可辨、过渡 150–300ms、键盘 focus 可见。
