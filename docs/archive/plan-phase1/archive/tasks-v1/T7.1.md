## 实现要点（主代理已定方案 = 阶段门裁定；遇阻先报告勿自行改方案）

### 1. 模式状态与派生合成（workspaceStore + toolIA 纯函数）

- `useWorkspaceStore` 增 `mode: WorkModeId`（默认 `'scene'`）+ `setMode(mode)`；**T7.1 内存态不落盘**（T7.3 随布局持久化，门 Q6 裁定）。
- 显示模式 = 纯函数 `combineMode(explicitMode, activeToolId, drawTarget)`：绘制/放置工具激活期间显示派生绘制态（沿用 deriveMode 现有映射：面→terrain、line→road、point→annotation、placement→decoration），工具退出恢复显式模式。
- `setMode` 时若有激活绘制/放置工具，先走 cancel 语义（ESC 同路，不产生 Command），防隐形状态（沿 T7.4 任务书同语义先例）。

### 2. 模式信息架构扩展（toolIA.ts，纯数据 node 可测）

- `MODES` 六项转正 enabled（scene/build/road/terrain/decoration/annotation），measure/analysis 维持 disabled + tooltip（排除项提示）。
- 每模式补充元数据：`label`（中文名）、`accent`（专属色，从 tokens.css 现有色阶取值并登记 DESIGN.md）、`verticalGroup`（垂直条置顶组）、`hudHint`（一行操作引导文案）、`inspectorGuide`（无选中时引导卡文案：模式说明 + 快速开始）。
- 模式→垂直条分组映射：scene→全部展开无折叠；build/terrain→「区域」组置顶；road→「路径」置顶；annotation→「点」置顶；decoration→「资产」置顶。

### 3. 六联动落地（门 Q1/Q3 裁定）

1. **Context Toolbar 更新**：右段模式徽标显示 combineMode 结果（全名+专属色）；无选中时中段显示模式引导芯片；选中对象时由上下文工具矩阵接管中段。
2. **工具可用性**：全部工具任何模式可用，无 disable（UE 聚焦裁定）。
3. **无关工具隐藏**：垂直工具条本模式组置顶，其余折叠进「更多」抽屉（抽屉内点击可正常激活工具，保留可达性——门 Q3a 裁定）。
4. **Inspector 随对象类型变化**：有选中时 `sectionsFor` 照旧（不随模式变）；无选中（empty 态）显示**模式引导卡**（inspectorGuide 数据驱动，纯展示组件）。
5. **Viewport 辅助信息**：仅 HUD 文案（门 Q3b 裁定）——HUD 模式徽标升级为全名+专属色，其下增一行 hudHint 引导文案；**场景内渲染零改动**。
6. **HUD 模式显示**：徽标数据源从 deriveMode 切换为 combineMode。

### 4. 上下文工具矩阵（门 Q4 四分裁定）

`contextActionsFor(selection, activeToolId)` 纯函数（toolIA.ts，数据表驱动注册制，禁止组件内散落 if）+ ContextToolbar 中段消费：

- **单选 building 族 region**：复制（复用 Ctrl+D 既有路由）/ 轮廓编辑（`toggleVertexEdit` 既有入口）/ 楼层步进器（floors ±1，经 `ChangeSemanticCommand` 写 semantic.properties，一条历史）/ 对齐·阵列 disabled 占位（tooltip「对齐与阵列工具将在后续任务启用」）。
- **单选 road（line region）**：复制 / 节点编辑（vertex-edit 入口，line 形状原生支持，`src/domain/regions/vertexEdit.ts:23`）/ 宽度步进器（width ±0.5m，同经 ChangeSemanticCommand）/ 分割·合并 disabled 占位（tooltip「道路几何工具将在后续任务启用」）/ 对齐·阵列占位。
- **单选其他 region / model**：复制；unclassified 单选保留现有 RegionQuickApply 快选条。
- **多选**：对齐·阵列 disabled 占位（批量编辑属 T7.5，不占位）。
- **绘制/顶点编辑态**：现有绘制中段与顶点编辑指引并入矩阵统一框架（互斥关系保持）。
- 步进器为内联小组件（等宽数字读数、长按连续、min/max 按 semanticDefinitions 参数定义截断）；占位项 disabled + cursor-not-allowed + tooltip。

### 5. 快捷键与菜单（门 Q5 裁定）

- `Alt+1..6` → 六启用模式直切（按需求 24 章表序 scene/build/road/terrain/decoration/annotation）；Alt+7/8 **不绑定**（目标模式禁用，键表注明预留）。
- 复用 `isEditableTarget` 守卫（文本输入焦点不拦截）；键表单一真相源在 toolIA（input.ts 消费，菜单 shortcut 同源）。
- 「视图」菜单增「工作模式」子菜单：八项（六启用 + 两禁用灰显），与选择器/快捷键三路同源一致。
- README 操作指南同步（模式体系说明 + Alt 键位表）。
