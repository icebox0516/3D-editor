## 注入提示词（原文，第 10 组任务 2、3）

> 2. 三个绘制工具：
> - DrawPointTool：点击生成 Point 几何，对应要素放置
> - DrawLineTool：点击加点，双击结束，生成 LineString 几何，实时显示长度
> - DrawPolygonTool：点击加点，双击闭合，生成 Polygon 几何，校验自相交、最少顶点
>
> 3. 绘制模式：
> - 进入绘制模式自动切换顶视图、开启网格、限制相机旋转
> - 保留透视绘制开关
> - 绘制辅助：实时显示长度、面积、顶点坐标
> - 正交锁定、45°角锁定
>
> 【输出要求】所有绘制工具在 editor/tools/draw 目录下，绘制过程不污染正式场景和历史记录。

## 偏差与补充（优先级高于上方提示词）

- 三工具均经 `PreviewPort.updateDrawPreview` 渲染临时线/面/顶点；PreviewManager 扩展 3D 预览：Line 段 + 顶点 sprite、Polygon 半透明面、测长/测面积文字 sprite（CanvasTexture，仅 runtime）。
- 进入绘制：`CameraPort.setMode('top') + setOrthoLock(true)` + 网格显示；工具参数带 `perspective: boolean`（保留透视绘制开关）；退出恢复原模式。
- 状态栏数据经新事件 `draw:status` 驱动（payload 建议：`{ length?: number; area?: number; cursor?: Vec2; error?: string }`——最终定义写进返回报告，主代理落 CONTRACTS.md）。
- 交互键：Shift=正交锁定、A=切换 45° 锁定、G=切换网格吸附（默认开，1m 网格）。
- 完成 → `ElementRegistry.create(elementType, { geometry })` + 默认样式 → CreateObjectCommand 入场景。

## 验收标准

- FakePort 下：面工具点击 4 点 + 双击 → 场景 +1 个 Polygon 要素、顶点顺序一致、默认样式正确；绘制全程历史栈长度不变，完成后恰好 +1。
- 自相交 complete 被拦：场景无变化、收到 draw:status 错误提示。
- 长度/面积：3-4-5 直角三角形面积=6、长度实时累计（事件 payload 断言）。
- 正交锁定：Shift 下第二点仅沿主轴偏移；45° 锁定点落在 45° 方向。
- ESC/右键取消：清预览、切回先前工具、场景与历史零变化。
- 守护三连全绿。
