## 注入提示词（原文）

> 继续实现场景层和领域层的**纯数据模型**，严格遵守「数据层不碰渲染、不碰业务逻辑」的边界。
>
> 【核心约束】
> 1. Scene 层只存纯数据，只做增删改查，不校验、不计算
> 2. Domain 层的所有几何、样式、要素都是纯业务数据，绝对不能出现任何 THREE 开头的类型
> 3. 场景数据是唯一数据源，运行时只是表现
>
> 【任务】
> 1. 场景层 scene：SceneObject / Layer / SceneData 接口；SceneManager（getObject/addObject/removeObject/updateObject/getObjects/clear，只操作数据）；SelectionManager（select/add/remove/clear/selectMany/getSelectedIds/isSelected，通过事件总线广播变更）
> 2. 领域层 domain：Point/LineString/Polygon 三种几何接口；Element 基础接口（继承 SceneObject，含 geometry、style 引用、业务属性）；BuildingElement、RoadElement、GreenElement、WaterElement、ParkingElement；Style 相关（StyleDefinition、StyleReference、StyleParameter）；Asset 相关（Asset、AssetReference、ModelAsset、AssetDefaults）；ModelObject 接口
>
> 【输出要求】所有接口用 TypeScript interface 定义，SceneManager 和 SelectionManager 实现为类，方法只操作数据，通过 EventBus 发出 object:created/object:updated/selection:changed 事件。

## 偏差与补充（优先级高于上方提示词）

- SelectionManager 放 `src/scene/`。
- domain 额外实现 `validateGeometry`（提示词未列，T3.1 的前置，保证 domain 自足）：自相交 / 最少顶点 / 坐标非法 / 未闭合，顺时针环自动反转（`autoFixed=true`）。
- `resolveStyle` 三级优先级合成函数一并实现（对象覆盖 > 图层覆盖 > 预设默认，数值参数 min/max 钳制）。
- ShaderDefinition、AssetDefaults 不实现（明确排除项 / 由 ModelAsset 字段覆盖）；environment 用 `SceneEnvironment`（preset + 开放字段）。
- updateObject 不允许改 `id`（抛错）。

## 验收标准

- SceneManager 增删改查触发对应事件且 `scene:changed` 恰好一次/操作；updateObject 改 id 抛错。

- resolveStyle：三级优先级正确、越界钳制。
- 守护三连全绿（domain/scene 无 THREE 痕迹由 check:layers 保证）。
