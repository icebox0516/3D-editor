## 1. 身份

夏栎（Quercus robur L.），壳斗科（Fagaceae）栎属落叶乔木；英文 pedunculate oak / English oak / common oak；中文俗名橡树、夏橡、英国栎 [1][2][6]。原产欧洲（法国、意大利等地），广泛栽培于温带，我国新疆、北京、山东有引栽 [1]。使用语境：城市公园 / 园林绿化场景的温带乔木；本项目资产 tree3a 服务于中距离为主的园区可视化，近景（数米）材质细节亦需可信。

- 分类：壳斗科栎属，学名 Quercus robur L.（Sp. Pl. 996. 1753）
  - Form: Value
  - Evidence Status: Verified
  - Source: [1][2]
- 落叶性：落叶乔木（秋末落叶）
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1][2][3]

## 2. 主要尺度

- 成年树高：可达 40m；FOC 记 40–50m；Forestry England 记最高约 30m（不同来源的「可达」上限口径不同，均为极值而非典型值）
  - Form: Range
  - Evidence Status: Verified
  - Source: [1][2][3]
- 实测成年样例：新疆伊宁 4 株高约 20m，大者胸径 78.6cm；伊宁街道 1 株胸径 1.2m
  - Form: Value
  - Evidence Status: Verified

- 胸径（成年老树）：实测 0.786–1.2m
  - Form: Range

  - Form: Range
  - Evidence Status: Verified
  - Source: [1][2]
- 壳斗：钟形，直径 1.5–2cm，包着坚果基部约 1/5；坚果卵形/椭圆形，高 2–3.5cm、径 1–1.5cm；果序梗长 4–10cm（「悬垂果」，pedunculate 命名由来）
  - Form: Range
  - Evidence Status: Verified
  - Source: [1][2]
- 冠幅：无文献数值来源；真实照片推断见第 3 节（Inferred）
  - Form: Range
  - Evidence Status: Inferred
  - Source: [6]
- 寿命：可达约 1000 年（veteran/ancient 级）
  - Form: Value
  - Evidence Status: Verified
  - Source: [3]
- 物候：花期 3–4 月（FOC 记 5–6 月），果期 9–10 月
  - Form: Range
  - Evidence Status: Verified
  - Source: [1][2]

## 3. 轮廓与比例

- 整体树形：成熟树形成宽展、不规则圆顶状树冠，骨架枝粗壮有力
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [3]（照片佐证 [6]）
- 冠幅/树高比：成熟开阔地个体 ≈0.8–0.9；老树个体 ≈1.0（两张整树照各自双次独立目测核验一致）
  - Form: Relative
  - Evidence Status: Inferred（照片目测推断，无文献数值）
  - Source: [6]
- 冠幅/树高比随树龄与立地联动：开阔地个体显著宽于密林个体；树龄越大冠幅比越大（联动关系；幼龄个体相对更窄，照片样木为 ≥10m 成熟个体）
  - Form: Relative
  - Evidence Status: Inferred
  - Source: [6]
- 主干分枝点高度占比（干高/树高）：成熟–老树开阔地个体 ≈0.25–0.35（双照片一致）
  - Form: Range
  - Evidence Status: Inferred（照片目测推断）
  - Source: [6]
- 主干：明显、近直立，老树干身粗壮
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [3][6]

## 4. 结构层级

部件树：主干 → 骨架枝（一级粗枝）→ 二级枝 → … → 末级小枝 → 叶（簇）。

- 骨架枝：粗壮横展、自干中下部及以上四周展开；老树一级枝可极粗并承载大质量；数量 ≈5–7 根（三张整树照目测汇聚：5–6 / 5–7 / ~6）
  - Form: Range
  - Evidence Status: Inferred
  - Source: [6]
- 顶枝优势：成熟/老树冠顶由多主枝分摊（两张整树照均无单一领导枝）；中龄树是否存在明显领导枝：无照片证据
  - Form: Qualitative
  - Evidence Status: Inferred（成熟/老树）/ Unknown（中龄领导枝）
  - Source: [6]
- 末级结构：成年树末梢为细密小枝网络（老树冠层照呈蕾丝状细枝网）
  - Form: Qualitative
  - Evidence Status: Inferred
  - Source: [6]
- 小枝：赭色/红褐色，无毛，被灰色长圆形皮孔；幼枝被毛后脱落
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1][2]
- 冬芽：卵形，芽鳞多数、紫红色、无毛
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1]
- 叶序/叶形：叶片长倒卵形至椭圆形；顶端圆钝；基部为不甚平整的耳形（auriculate，叶柄极短、基部两侧有「耳」）；叶缘具 4–7 对深浅不等的圆钝锯齿（裂片）；侧脉每边 6–9 条（FOC：每侧裂片 5–7、侧脉 5–7(–10)）
  - Form: Range + Qualitative
  - Evidence Status: Verified
  - Source: [1][2][5]
- 叶片长宽比：由 6–20 × 3–8cm 推得 ≈ 1.6–2.7（典型 ≈ 2，明显长大于宽）
  - Form: Relative
  - Evidence Status: Verified（由叶片实测区间推得）
  - Source: [1][2]
- 花/果：雄柔荑花序春夏悬垂；果序梗纤细长 4–10cm、着果 2–4 个
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1][2]

- 叶色：叶面淡绿色、叶背粉绿色（FRPS）；FOC 记上面绿色、下面带绿的浅色（adaxially green / abaxially greenish）；照片显示健康冠层为中-深绿、新叶偏浅黄绿
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1][2][6]
- 秋季叶色：转黄褐色后脱落
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [3]
- 叶表面：哑光、无金属光泽（照片观察）；背光时叶背透暖绿光（视觉可观察）
  - Form: Qualitative
  - Evidence Status: Inferred（照片直接观察）
  - Source: [6]
- 树皮（树龄序列）：幼树光滑、银灰色；随龄变深、出现纵向开裂；成熟后形成深沟与窄脊交错的粗糙脊状树皮，老树极粗糙呈板块状
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [3][4]
- 树皮类型学：属「脊状/板状」皮（木栓层厚、外推开裂成脊），非光滑/剥落型
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [4]
- 树皮颜色：灰褐色、灰为主（bark-a 活树皮近景双次核验一致：grey-brown / grey，垂直深脊沟）
  - Form: Qualitative
  - Evidence Status: Verified（照片直接证据）
  - Source: [6]
- 树皮明暗微结构：沟底深、脊顶偏浅的倾向（近景照可观察；幅度未定量）
  - Form: Qualitative
  - Evidence Status: Inferred（照片可观察特征）
  - Source: [6]
- 附生：树干（尤其冠下背阴面与老树）常见苔藓与地衣斑块
  - Form: Qualitative
  - Evidence Status: Verified（照片直接证据）
  - Source: [6]
- 坚果：亮褐色，壳斗杯面被灰色细绒毛
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [1][3]

## 6. 变体范围

- 树高幅度：同龄/同种内个体差异大；立地与树龄主导（引栽 20m 实测 vs 欧洲极值 40–50m）
  - Form: Range
  - Evidence Status: Verified
  - Source: [1][2][3]
- 冠形变体：开阔地宽展不规则圆顶 vs 密林更高更窄、干净主干（联动：光照竞争决定枝下高与冠宽；照片样木均为开阔地个体 ≈0.8–1.0，密林端无照片证据）
  - Form: Qualitative
  - Evidence Status: Inferred（照片对比推断）
  - Source: [6]
- 树龄联动：树皮由光滑银灰 → 深沟脊粗糙；冠幅比增大（成熟 ≈0.8–0.9 → 老树 ≈1.0）；失去领导枝、冠顶多主枝分摊（三者在老树并发）
  - Form: Qualitative
  - Evidence Status: Verified（皮）/ Inferred（冠形联动）
  - Source: [3][6]
- 叶形变体：长倒卵形至椭圆形的连续幅度；裂片深浅不等（同叶内 4–7 对深浅混合）
  - Form: Range
  - Evidence Status: Verified
  - Source: [1]
- 叶色变体：新叶浅、成叶深；秋黄褐（季节联动）
  - Form: Qualitative
  - Evidence Status: Verified
  - Source: [3][6]
- 园艺栽培品种的极端形态（如柱形冠品种）：未调研
  - Form: Unknown
  - Evidence Status: Unknown

## 7. 远近景保留优先级

（写到视觉显著性为止；面数/切换距离等工程映射归任务书）

- 远距（>50m）：宽展不规则冠轮廓 + 灰褐干 + 中绿团块色域可辨认；单叶、裂片、枝条结构均不可辨，可全部牺牲
- 中距（10–50m，本项目主语境）：冠形不对称与骨架枝横展剪影、冠内空隙通透感（外密内疏）、簇团状叶块是主要辨识特征；单叶形状不可辨
- 近距（数米）：倒卵形叶 + 圆钝裂片轮廓、叶面哑光与背光透绿、树皮纵沟脊 + 苔藓/地衣、小枝皮孔点状细节依次进入可辨域
- 牺牲顺序（远→近）：叶片细节与叶形 → 末级细枝网络 → 骨架枝结构 → 冠轮廓与色块（最后保留）
