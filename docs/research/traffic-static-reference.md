## 消费摘要（Step 1–4 默认读本节；正文各节为逐项展开）

1. **防撞柱**：人行道禁车柱主流态 = 一体圆柱体（φ114 钢管 + 液压成型顶帽 + 四道槽口，上海官方推荐款），露出地面 **80cm**、埋深 ≥20cm、混凝土基础 ≥30×30×30cm C30；反光膜荧光黄、条宽 **3cm**、环贴柱上部；上海涂装锚 **RAL 7040**，全国市场另常见碳钢黑/黄黑/不锈钢原色。壁厚无可靠数值（Unknown）。
2. **人行护栏段**：横杆式钢管段栏（非密竖杆京式），净高锚 GB 50688 7.5.2「不宜低于 1.10m、不得低于 0.90m」+ GA/T 1567 行人隔离栏 ≥0.9m；段长 2–3m；涂装白色为主。横杆数 2–4 道（照片两读分歧，不承重单值）。
3. **道路隔离栏**：京式护栏（密竖杆 U 形弯头 + 上下横梁 + 独立底座）为全国最普及型。硬锚（GA/T 1567）：中央净高 ≥1.1m 且下缘距地 ≤0.25m、端部 ≤0.7m/渐变段 ≥15m、同向车道 ≥0.6m、机非 ≥0.4m；**段长 3m/片**（四源聚簇）；立柱 80×80 方管、竖杆 Φ16 圆钢、底座铸铁 ~30kg/混凝土底盒；反光警示装置间距 ≤6m；白色为主（蓝白/黄黑变体存在）。
4. **停车挡车器**：橡胶一体三棱/梯形截面阻挡件，尺寸聚簇 **550–560 × 150–160 × 100–110 mm**（L×W×H），黑体 + 顶棱黄反光条，膨胀螺丝固定，安装于**距车位后边缘线 1.0–1.1m**；橡胶为主流态，混凝土变体存在但证据弱。
5. **交通锥**：GB/T 24720-2009 锚定——锥体内外**宜为红色**、反光面白色；顶径 60±15mm；底座 4–8 边正多边形或圆形、内切圆径 ≈0.75H（厚边）/0.9H（薄边）；反光面 ≥1 条、最小宽 **8cm**、条顶距锥顶 10cm；高度五档 300–1000mm（停车场语境常用 500–700 档）。**色相裁定证据：默认红相（标准+市场双证）；黄相 = 停车场语境副卡**（详见 §5.5）。
6. **减速带**：黄黑逐段交替拼接的段式拱面条；截面聚簇**宽 350mm（300）× 高 40–50mm**、单段长 250/500/1000mm；橡胶为主（铸钢变体 50–70mm 高）；表面人字防滑纹；**全国无产品标准**（2017 口径，GA/T 489 已交叉排除为信号机规范）。端头处理无强证据（Unknown）。
7. **批级语境**：门口（减速带+锥）、道路（白护栏连续段+机非栏）、人行道（防撞柱+横杆护栏）、停车区（挡车器阵列+黄锥+网格线）四层典型同框（§7）。

## §1 防撞柱 bollard（asset_bollard）

### 1.1 身份/识别特征

中国城市语境的固定防撞柱主流形态 = **人行道禁车柱**：阻止机动车驶入人行道/步行区的竖直圆柱体，设置于人行道缘石坡道口、进口坡道、单位大门等 [2][3]。结构分解：一体加工圆柱管柱体 → 液压成型顶帽（弧顶）→ 柱身环贴 1–2 道反光膜 → 柱底开孔对穿钢筋预埋入混凝土基础（市政主流）或法兰盘 + 膨胀螺栓（产品常见）[2][3][P1]。识别要点：细长圆管（径高比 ≈1:7–1:10）、弧形顶帽、上部荧光色反光环。反光带型/黄黑环涂型均为常见态；活动式（可拆卸/升降）与固定式并存，本资产锚定固定式 [2][26][P2]。

### 1.3 材质相（部件 × 材质 × 配色）

- 柱体：一般区域 = 型钢钢管（Q235 级）镀锌 + 粉末静电喷涂（上海：RAL 7040 灰白）[2]；重点区域 = **304 不锈钢表面拉丝、壁 3mm、上盖板 3mm 不锈钢** [3]。全国市场常见另态：碳钢黑漆、黄黑环涂（警示型）、201/304 不锈钢亮面 [P1][P2]。
- 反光环：荧光黄/荧光黄绿 V 类微棱镜反光膜（无金属镀层），柔性膜 + 底涂 + 接口 50mm 亚克力护膜 [2][3]。
- 基座：预埋混凝土（C30，市政主流，地面不可见）或圆形法兰盘 + 4 膨胀螺栓（产品态，照片可见）[P1]。

## §2 人行护栏段 pedestrian barrier（asset_pedestrian_barrier）

### 2.1 身份/识别特征

人行道边缘的**横杆式钢管段栏**：若干道水平横杆（常见含中横杆宣传/标语板位）+ 圆管/方管立柱分段拼接，区别于密竖杆的京式隔离栏——两者共型不同参（人行护栏横杆式、更高、底座更轻，见 §3.6 差异轴）[P4][15]。设置语境：人行道外缘、绿化带边缘、二次过街安全岛 [2][15]。

### 2.2 硬数值锚表

| 数值 | 依据 | Evidence / 多变度 |
|---|---|---|
| 净高 **不宜低于 1.10m，并不得低于 0.90m**（从可踏面算起） | GB 50688-2011《城市道路交通设施设计规范》7.5.2，经厂家文转引 [10] | **Medium→Strong**（终审独立检索多源同文印证——非仅软文转引；规范原文仍未取得）｜中 |
| 行人隔离栏安装净高 ≥0.9m | GA/T 1567-2019 4.4.4 [1] | Strong｜中 |
| 常用整体高度 0.9 / 1.0 / 1.1 / 1.2m（另源：0.6/0.8/1.0/1.2m） | [11]（+京式族 [12]） | Medium｜中 |
| 段长（立柱间距）**2–3m** | 照片判读立柱间距 ≈2m [P4] + 京式族 3m/片四源 [12][13][14][15] | Medium（交叉推断）｜低（3m 为段式件通行值） |
| 横杆数 2–4 道（上/下横梁必备，中横杆可镶板） | 照片两读分歧（三横杆白色 vs 上下双横梁黑色，见 §2.4 分歧记档） | Weak（不承重单值，建模取 2–3 道为常见域）｜**高** |
| 专用管径 | 无可靠数值源（京式族面管 40×80 级仅可作同族参考） | **Unknown** |

### 2.3 材质相

本体：热镀锌钢管 + 静电喷塑（同京式族工艺 [13]）；涂装主色 **白色**（全国通行，[12][13] + 街景照片 [P3]）；上海官方口径为黑 / 灰 RAL 9002（≈#D7D5D2 级）/ 墨绿 RAL 6004（≈#014F39 级）[2]。中横杆镶长条宣传板为城市常见态（文明标语/公益广告）[P4]。hex 均为通行换算近似（Inferred，非标准定义）。

## §3 道路隔离栏 road barrier（asset_road_barrier）

### 3.1 身份/识别特征

全国最普及型 = **京式护栏**：密排竖杆（顶端 U 形弯头/馒头弯）+ 上下横梁 + 方管立柱 + 独立底座，段式拼接，广泛用于中央隔离、机非隔离 [12][13][14][P5]。结构分解（照片判读 [P5]）：方管立柱（顶帽 + 橙红反光警示块）→ 上横梁 → U 形弯头竖杆密排 → 下横梁/底部框架 → 靴形/方形独立底座。横管式与网片式为任务书预设变体：网片式无强源（Weak），横管式即机非栏常见态 [15]。

### 3.2 硬数值锚表（GA/T 1567-2019《城市道路交通隔离栏设置指南》，公安部 2019-06-15 发布实施 [1]）

| 中央隔离栏端部渐变：端部高 ≤0.7m、端部长 ≥10m、渐变段 ≥15m | 4.2.6 + 附录 A.3 图注（≥15m/≥10m/≤70cm）[1] | Strong（正文+图注双证）｜低 |

### 3.3 材质相

本体：热镀锌钢管（锌钢）→ 热镀锌 + 静电喷塑/浸塑 [12][13]；主色 **白色**（「颜色多采用白色」[12]，街景佐证 [P3]），变体蓝白（知乎照片 [P6]）、黄黑（北京日报街拍 [P2]）；上海官方统一色：黑 / 灰 RAL 9002 / 墨绿 RAL 6004，禁红白杆作防倾覆支撑 [2]。反光件：立柱橙红反光警示块（照片判读 [P5]，对应 4.1.6 反光警示装置）、端部反光/发光警示柱（荧光黄/荧光黄绿膜）[1][2]。底座：铸铁黑漆 / 混凝土灰。

### 3.6 与人行护栏「共型不同参」差异轴（消费方：D19.2 单档几何裁定）

- **高度**：人行护栏 0.9–1.1m（净高锚）vs 道路隔离栏按用途 0.4/0.6/1.1m 三档 [1][10]；
- **结构型**：人行护栏横杆式（2–4 道）vs 京式密竖杆 + U 形弯头 [P4][P5]；网片式 Weak 不建议本批采；
- **底座**：人行护栏立柱贴地/轻底座 vs 隔离栏独立铸铁/混凝土底座（可移动式）[12][15]。

## §4 停车挡车器 wheel stop（asset_wheelstop）

### 4.1 身份/识别特征

车位尾端（距后缘线约 1m）的车轮阻挡件，主流态 = **橡胶一体模压条**：三棱/梯形截面（顶窄底宽、两侧斜面）横置于车位，黑体 + 顶部棱线黄色反光条纵贯，膨胀螺丝穿底盘固定 [17][18][19][P7]。称谓族：车轮定位器/挡轮杆/阻位器/倒车垫 [17][19]。

### 4.2 硬数值锚表

| 数值 | 依据 | Evidence / 多变度 |
|---|---|---|
| 尺寸聚簇 **L 550–560 × W 150–160 × H 100–110 mm** | 欣浩 550×150×100 [20]、赛帝 560×160×110 [21]、autohome 500×160×105 [22]（AI 生成标注，仅作第三点参考） | Medium（厂家聚簇；照片判读 ≈550×150×100 同簇 [P7]）｜低 |
| 安装位：**距车位后边缘线 1.0–1.1m** | 太平洋汽车「离车位后边缘线前1米处，左右两边距离为25公分」[18]、有驾「距离车位后边缘线向后1.1米处」[19] | Medium（双源区间）｜中 |
| 固定：冲击钻打孔 + 膨胀螺丝穿底盘（12mm 钻头级） | [18][19] 双源一致 | Medium｜低 |

## §5 交通锥 traffic cone（asset_trafficcone）

### 5.1 身份/识别特征

圆锥体 + 方形（或圆角方/圆）底座 + 白色反光环的临时隔离件。GB/T 24720-2009《交通锥》（2009-11-30 发布、2010-04-01 实施，SAC/TC223 归口）[4][6][7]。结构分解：锥体（圆锥形或多边锥形）→ 反光面 ≥1 条 → 正多边形/圆形底座 → 可选手持顶孔。市场材质 PVC/橡塑/EVA，高度档 300–1000mm，停车场/园区常用 450–700 档 [8]。

## §7 批级公共节：城市园区典型同框语境（Contact Sheet / 验收场景参考）

- **园区/小区/厂区门口**：减速带（黄黑拱面条横铺）+ 交通锥（临时导流）常同框；减速带语境锚「繁华地段或小区厂区门口」[25]。
- **园区内部道路**：白色京式隔离栏连续段（中央/机非）+ 立柱橙红反光块；中央栏开口处黄黑警示柱成排 [P2]。
- **人行道层**：防撞柱（缘石坡道口、间距成排）+ 横杆式人行护栏（道边）+ 行道树；禁车柱与人行护栏常相邻设置（同为分隔设施体系）[2][3]。
- **停车区**：挡车器阵列（每车位一件、距后缘线 1m 一致的重复节奏）+ 黄色网格禁停线 + 交通锥（黄相语境）+ 石质挡车球 [P10]。
- **一张实拍同框参考**：[P4] 四格拼图——黑色横杆式人行护栏 + 灰色隔离栏（梯形底座 + 黄黑警示贴）+ 花箱护栏 + 消防栓 + 行道树同框，可作 Contact Sheet 场景布设的现实原型。
- 各件均属「运营态画面骨架件」：成排/阵列重复出现是共同的空间语言，散布消费以线状（护栏/减速带）与点阵（防撞柱/挡车器）为主。
