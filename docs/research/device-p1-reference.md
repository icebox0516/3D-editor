## 消费摘要（Step 1–4 默认读本节）

1. **监控摄像头（杆装枪机）**：构成 = 钢立杆（锥形主流）+ 底部法兰 + 杆顶横臂（水平侧伸，摄像机经万向鸭嘴支架装于臂端下挂或杆侧）+ 白色枪机（筒形壳体 + 顶置遮阳罩 + 前端镜头/红外窗）。立杆高 **3.5–6m**【承重】（Verified·Range [1]），壁厚 **3–4mm**（Verified·Range [1][3]），锥形杆口径 **上口 ≈Φ76–90 / 下口 ≈Φ140–180**（Verified·Range [1][2][5]）；横臂长标准带 **0.4–2m**（Verified·Range [1]），园区单枪横臂 **0.3–0.5m** 常用档（Medium·Range [14][15]）；支臂/横臂管径 **≥Φ60**（Verified·Value [1][2]）。枪机壳体压铸铝合金、白色，带遮阳罩，外形 **长 ≈0.29–0.40m × 截面宽/高 ≈0.10–0.17m**【承重】（Verified·Range [7][8][9] 聚簇）。杆材无缝/热轧钢管 + 热浸锌 ≥85μm + 表面涂装 ≥60μm（Verified·Value [1]）；色相 = 喷塑白/灰为主（产品照聚簇），热镀锌原色与黑/不锈钢变体存在。底部方形法兰 + 地脚螺栓；杆内走线无明线（照片聚簇，Inferred·Qualitative）。球机/壁装态记增补位（任务书裁定 3）。
2. **交流充电桩（落地式）**：两常见落地构成——**一体柜式**（钣金柜体直落地面：单枪 **340×151×1400mm**【承重】Verified·Value [16]，双枪三相 **567×258×1600mm**【承重】Verified·Value [18]）与**桩体+立柱式**（头部桩体 400×460×170mm [21] / 262×143×372mm [26] 装于 ≈1.2–1.4m 方管立柱 [19][25]）。正面 = 上部黑色操作面板（LCD **2.8–4.3 寸**三源 [16][18][21]）+ 刷卡/标识区，占比 ≈桩体正面 50–70%（照片比读）；**枪座 = 柜体/立柱侧面挂置**（照片聚簇），充电枪白壳黑缆、**枪线 4–5m**【承重】（Verified·Range [18][22][23]），挂置态线缆自然弧线下垂。指示灯带（Y 型三色跑马 [18] / 电源·充电·故障三态 [21]）为常见识别特征。材质 = 钣金/镀锌板静电喷塑（Verified·Qualitative [23][24]），**白色为主调**（照片三源聚簇）；「国网绿」为运营商标识语域（色值两源冲突记档 [28]），非本批主色调证据。防护 IP54–IP55（四源）。底座 = 方形法兰 + 膨胀螺栓（照片）。直流快充不进本批（裁定 1）。
3. **井盖（圆形检查井盖）**：构成 = **球墨铸铁圆形井框（宽边，外缘带椭圆浇筑孔）+ 内沉盖盘**（照片三源聚簇 [P1][P2][P3]）。承载等级族 **A15/B125/C250/D400/E600**（Verified·Qualitative 五源 [29][32][33][34][35]）：A15 = 绿化带/禁机动车人行道，B125 = 人行道/小车停车场，**D400 = 400kN 市政主干道/车行道主流档** [33][34]；净开孔规格系列 **600/700/800/900mm**【承重】（Verified·Range 三源 [29][35][36]），**Φ700 = 圆形主流档**（Medium·Value [37][38][39] 聚簇）；盖盘外径 ≈ 净开孔 + 100–200mm（Inferred·Relative [30][40][41] 推断）。防滑花纹面高 **3–8mm**【承重】（Verified·Range 双源 [30][31]）；盖面纹样 = **满布十字网格防滑纹 + 中央圆形字章（污/雨/电语义）+ 矩形字样槽/标准规格槽**（Verified·Qualitative [42][43][44] + 照片三源）；盖面与路面**齐平安装**：车行道允许偏差 ±3–5mm、绿化带 ±20mm、高差 ≥15mm 即安全隐患【承重】（Verified·Range 多导则聚簇 [45]）；井座壁厚 ≥6mm、支撑面 ≥24mm、整重 ≥70kg（Weak·Value [30]）。材质相 = 球墨铸铁灰黑单相（照片三源）。井室不建模、贴地 min 凸起放置（任务书裁定 5，齐平安装语义支撑）。
4. **批级语境**：园区设备同框 = 停车场充电位（交流桩 + 路面井盖）+ 出入口/围墙监控杆（园区短杆带 2.5–4m 照片聚簇 [P1][P2]，道路杆 3.5–6m）——三件均为「运营态画面骨架件」，识别语义远大于装饰语义。

## §1 监控摄像头 cctv_camera（asset_cctv_camera）——杆装枪机主形态

### 1.1 身份/识别特征

城市园区/道路语境的**杆装定點监控设备**：钢立杆 + 顶部横臂 + 枪型摄像机（筒形壳体 + 遮阳罩），园区/停车场/围墙常见 [1][2][14][P1][P2]。结构分解（照片判读 [P1][P2][P3] 双问一致）：**立杆（锥形/等径圆管，底部方形法兰四螺栓孔，顶部可加不锈钢装饰球）→ 横臂（水平侧伸，圆管/方管，经抱箍或法兰块与杆连接）→ 万向鸭嘴支架（铰接云台座，抱箍圈或臂端下挂安装板）→ 枪机（白色筒形壳体 + 顶置前伸遮阳罩 + 前端镜头/红外补光窗 + 尾部线缆接口）**。杆身中下段常设检修手孔 [P3]。任务书立项预期（杆 3.5–6m + 横臂/抱箍 + 白色枪机筒壳 + 遮阳罩，杆内走线无明线）与判读相容。近景保留项 = 枪机壳体三分段（遮阳罩/壳体/视窗圈）、鸭嘴支架铰接形态、法兰与手孔；远景保留项 = 杆+臂+头的整体剪影与下挂姿态。

### 1.3 材质相（部件 × 色相/质感/工艺）

- **立杆**：钢管（无缝/热轧/镀锌管）热浸锌后喷塑——色相以**浅灰/白色喷塑**为主（产品照 [P1][P2][P3] 三款白/深灰/黑可选，「颜色定制」为常态 [P3]），热镀锌原色（银灰金属相）与不锈钢拉丝相并存 [P4 语境]；哑光粉末质感。
- **横臂/支架**：与杆同色喷塑（金属烤漆）；鸭嘴万向头带铰接螺栓结构（金属亮件点缀）[P3]。
- **枪机**：**白色（米白）哑光烤漆/喷粉铝合金压铸壳体** [7][8][P1][P2]；遮阳罩与壳体同色一体 [P1]；前端玻璃视窗圈（深色圆窗）+ 红外补光窗（照片 [P1][P2] 中央枪机可见多灯珠环）；尾部线缆接头。黑壳/深灰壳变体存在 [P2 右款]。
- **顶部装饰球**：不锈钢亮面球头（围墙/园区杆常见，[P1][P2]）——园区语境识别特征，道路杆可无。

### 3.1 身份/识别特征
