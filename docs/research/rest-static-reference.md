## 消费摘要（Step 1–4 默认读本节；正文各节为逐项展开）

1. **花箱**：主形态 = **矩形（长方形）**（厂家形状筛选序 + 照片聚簇双证）；尺寸带聚簇 **长 60–150 × 宽 20–80 × 高 20–120cm**，道路隔离花箱**高 ≈80cm**（双源同句）、景观花箱常见 150×55×65cm；市政主流相 = **镀锌钢外板 + PVC 内板**烤漆箱体（朗汀产品面），防腐木/碳化木/塑木/实木同为常见材质相（厂家筛选多值），玻璃钢/PE 存在；土面低于沿口（照片比读 ≈箱高 10–20%，Weak），箱内蓄排水板语义实存（照片）；落地直置为主，垫脚无强证据。壁厚 Unknown。
2. **休闲桌**：桌凳组合位单体；桌高聚簇 **720mm**（铸铝圆桌 Φ700×H720 / Φ900×H720 三源同簇），圆桌桌面主流径 700–900mm；凳位两常见态：**四凳环绕连体**（金属冲孔一体桌，照片）与**四凳分离环绕**（石桌+方凳，照片）；桌面材质相 = 金属冲孔烤漆 / 石质 / 木条三态并存；桌面中央**伞孔实存**（照片判读，与遮阳伞成套语境互证，常见度中）；框架管径无源（照片比读 Φ25–32 级，Weak）。
3. **遮阳伞**：中柱立伞；开伞直径带 **1.8–3.0m**（主流 2.4m「标准餐桌」/3.0m「多人遮阳」，档位 2.3–3.0 多源聚簇）；**总高 2.1–2.7m**（b2b 尺寸标准文 + 照片比读一致）；伞骨 **6–8 根常规**（高档款 8 骨 + 斜拉索，照片双读一致）；伞布涤纶/牛津布（210D/420D）；底座 = 配重盘（大理石 20kg ~ 大伞 90KG）/ 十字折叠脚 / 地插预埋三态；**伞面色相：厂家标准三色 = 墨绿/酒红/卡其（四源聚簇），米白次之（双源+照片）——消费方：preset 卡集裁定（任务书待裁决位 4）**。侧立伞（罗马伞）与四脚折叠篷为邻类，不并入本资产。
4. **自行车架**：型制族 = **卡位式（高低弯管）/ 螺旋式（别名地笼式、圆笼式）/ 卡槽式 / 立体式**，园区地面主流 = 卡位式 + 螺旋式；卡位式段规格聚簇 **1200×530×360mm（1.2m 标准段）**，角钢 40×40×3.5、热镀锌后喷塑（双源）；螺旋式聚簇 **2000×300×300mm、卡位间距 280mm、管径 Φ20–25×壁厚 1.5–2.0mm**（五源聚簇）；单车占位 **2.0×0.6m**（五源聚簇，1.2m 段=双位 → 位距 ≈600mm 交叉推断）；离地形态 = 长条法兰底板 + 膨胀栓（照片）与预埋并存；材质相 = 热镀锌喷塑 / SUS304 不锈钢原色；停放姿态 = 前轮卡入圈口、车体斜置倚架（T026 联动记档）。
5. **批级语境**：园区休憩角典型同框 = 休闲桌 + 遮阳伞成套（伞立桌侧地插/配重盘为主，穿桌孔为辅）、花箱列植（隔离带/边界线状重复）、自行车架沿边排布（多段连排）；桌伞成套有实拍参考（§5）。

## §1 花箱 planter（asset_planter）

### 1.1 身份/识别特征

城市园区/道路语境的**矩形种植箱体**：金属或木质的开放式箱壳 + 顶部种植土面（下沉），用于隔离带、边界、外摆围合 [1][2][5][P1]。结构分解（照片判读 [P1][P2]）：外板箱体（金属折边或木条拼板）→ 顶部开口 + 内衬翻边 → 箱内蓄排水板/排水层 → 土面（低于沿口）→ 落地直置。市政产品主流 = **镀锌钢外板 + PVC 内板**复合箱体（厂家产品页明示「PVC 内板搭配镀锌钢外板」[P1]），可带镂空图案外饰面 [P1]。任务书立项预期「木/塑木/金属箱体」与本判读相容：金属烤漆与木/塑木两相并存，按场景选择（见 1.3）。

- 箱体外板：**金属烤漆**（镀锌钢外板 + 粉末/静电喷涂，咖啡棕等深色为主 [P1]；MIC 工艺筛选：粉末喷涂/静电喷涂/拉丝/喷漆/氧化 [5]）｜**防腐木/碳化木/实木条拼板**（原木色/白色涂装 [P2]）｜塑木（MIC 材质筛选列名 [5]）——市政街区语境金属烤漆品牌产品面多见 [P1]，庭园语境木/塑木常见 [P2][5]，两者并存无单一主流强证。

- 玻璃钢/PE 材质相存在（MIC 筛选 [5]），混凝土相未检索到可靠来源（不记为常见）。

### 3.5 色相证据面（preset 卡承重，多源证据锚）

- **厂家标准三色（Medium-Strong，四源聚簇）**：**墨绿 / 酒红 / 卡其**——莫家户外家具「三种颜色可供选择：墨绿、酒红色和卡其色」[16]；馨宁居两文「深绿色、勃艮第色和卡其色」「墨绿、酒红、卡其色」[19]；抖音定制「五色可选：墨绿/酒红/米白/卡其/咖啡」[18] 同簇。
- **米白（Medium，双源+照片）**：黄页88「伞布颜色：墨绿、酒红、米白、托普色等」[17] + [18] + 照片 [P1（白/银）][P3（米白）]——园区/商业外摆实拍中素色（白/米白）出现频次最高（[P3] 阵列、§5 多伞实拍）。
- **深色防晒语义**：深色伞紫外线透过率约 5–10%、黑色 5%、浅色系 15–20% [16][19]（佐证深色为功能性主选，不做几何/材质消费）。
- **鲜艳纯色/拼色**：广告伞语境（拼色八片 [P5]）；立项预期「伞面常为鲜艳纯色」与判读有出入——**园区/商业外摆主流为素色（米白/卡其/墨绿），鲜艳色集中在广告促销语境**（记档，供主代理修正立项假设）。
- **裁定建议（供主代理定卡）**：default = **米白/卡其素色相**（实拍主流）；preset 副卡 = **墨绿 / 酒红**（厂家标准三色双证）；拼色/条纹 = 广告语境可选第三卡（Weak）。卡变仅动伞面基调材质，骨架/柱/底座不变（D44 #1 同则）。
