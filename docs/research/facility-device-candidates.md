# 园区设施与设备候选清单（立项参考）

> 定位：T025（设施，阶段 2）与 T028（设备部分，阶段 5）的立项候选参考——发现/分流用，**非立项前置**（口径同乔木候选池，D37）。
> 证据口径：本清单为**规划级枚举**，无逐资产现实调研；各资产现实依据（尺寸/型号/材质/色卡 preset）在立项时过 Research Gate（D26）确认，结论落各自 Reference Spec。开发 Agent 开工前照常校验 Spec Version 锚点。
> 复杂度路由：轻量（simple-asset 批量制）｜中等（届时按 D36 §5 分裂判据裁定路由——同批次混合复杂度时拆批，一批一方法）。分类建议列 = meta.category / taxonomy 归属建议（category 值收敛策略为 T025 立项必答，见 TASKS.md）。
> 排期口径：设施 = 阶段 2（T025）；设备 = 阶段 5（T028）或按需提前——穿插排期待定（2026-09-24 共识 Q13）。
> 动画联动：带活动件的候选（道闸/闸机/车位锁）与 T005 Animation Pathway 占位任务联动，静态版先行、动画后续。

## §1 设施库

**P1 = 画面骨架件**（园区运营态成立所需，优先立项）；无标 = 完善件；P3 = 低优先留池。

| 候选 | 复杂度 | 优先级 | 备注 |
|---|---|---|---|
| 防撞柱（固定型 / 反光型） | 轻量 | P1 | 批量散布消费主力 |
| 人行护栏段 + 端头柱 | 轻量 | P1 | 段式拼装，长度参数位 |

| 挡车器（车位阻车器） | 轻量 | P1 | 停车位标配 |
| 减速带 | 轻量 | — | 段式 |

## §3 推荐批次切分（T025 起步，一批一方法）

| 批次 | 成员 | 路由 | 说明 |
|---|---|---|---|
| A 交通静态 | 防撞柱 / 人行护栏段 / 挡车器 / 减速带 / 凸面镜 | 全轻量 | simple-asset workflow 首例批次 |
| B 休憩卫生 | 花箱 / 树池篦子座椅 / 分类垃圾桶组 / 草坪灯 / 烟蒂柱 / 投光灯 | 全轻量 | 含三件现有家族变体位 |
| C 能源 | 交流充电桩 / 直流快充桩 / 配电柜 | **混合** | 直流桩与配电柜若判中等 → 拆独立子任务，交流桩留批 |
| D 安防信息 | 监控摄像头 / 道闸 / 一键报警柱 / 导览屏 / 广播音柱 | **混合** | 道闸与导览屏若判中等 → 拆出；静态版先行 |

## §4 边界与留池记档

- 偏建筑候选（廊架 / 岗亭 / 配电柜）在 T028 立项时重裁归属，本清单不预判
- P3 项（宠物拾便箱 / 高杆灯 / 光伏组件 / 喷灌喷头）留池，无画面需求不立项
- 立杆交通标识 / 长椅变体 / 分类垃圾桶 / 草坪灯四系优先走**现有家族变体**路线（streetlamp / parkbench / trashbin / signpost 家族契约已立），变体口径在各自立项时定
- 本清单为 2026-09-24 规划会话产物；资产生产排序以 TASKS.md 路线图与届时立项裁定为准
