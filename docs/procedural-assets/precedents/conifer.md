## 层状骨架语言（族核心——vs 阔叶「骨架枝 + 挂高段 + 椭球密度场」）

- **scaffold 挂点按层位量化路由**（近轮生成层 / 层间距均匀 + jitter / 首层挂高 = 干高比 × 树高）→ cedrus（骨架算法复制自 tree3a growBranch 递归，挂点语言层状改写）
- **层角梯度**（下部近水平 → 上部上举，沿层位插值——ginkgo 角度梯度法的层状版）→ cedrus
- **层板升扇/拱形 + 外缘微垂下卷**（垂直速度场 sin 拱 + smoothstep 下卷）→ cedrus
- **层叠尖塔冠**（层板轮廓串联、非光滑圆锥面；锥形收顶指数 + 基部最宽）→ cedrus（vs ginkgo 光滑圆锥）
- **层隙观感带**（簇布点按层聚集 + 层间空带——vs 阔叶外密内疏；层隙带宽工程校准值）→ cedrus
- **末级垂帘**（droop 负链 + fringe 乘子——salix upturn 负链机制直承）→ cedrus
- **顶梢专路下垂点头**（近直立初向 + 二次点头曲线 + 裸梢散生针卡防秃）→ cedrus

## 针叶表达（长短枝双挂点——ginkgo 机制直承 + 针叶改写）

- **短枝莲座簇卡**（1 卡 = 整簇针叶 SDF：极坐标扇区窗列放射 + 逐针 sin-hash 长宽抖动 + hub 实心 + 先端锐尖；针数随档变体 20/14/8）→ cedrus（新形态语言，限定文件内）
- **长枝散生针卡**（sin(π·v^1.55) 单针包络——上部较宽先端锐尖下部渐窄；近景散生读向，M25 无质量贡献——单针卡 2–3px，预算应让给簇）→ cedrus
- **中距浓密板三杠杆（T012.1 Step 4 校准实证——浅调线密度无效）**：①莲座簇**交叉双卡**（单面卡⊥枝切向无角度覆盖——第二卡零 rng 派生偶奇分工）；②**卡尺度 ≥0.3m**（亚像素卡〔<0.2m〕中距不可辨——簇是「点」质量、卡尺度才给「面」质量；**T012.2 证伪「聚合单元例外」假设：羽状小枝卡〔真实 3–7cm 聚合单元〕同判——5.5–10cm 实测 M25 亚像素，放大至 0.18–0.30m 后 SDF 内部羽列密度不变即近景身份保留，杠杆普适于族内两种叶语言**）；③挂点前移消裸段（clusterInnerStart + childPlan ts）→ cedrus + metasequoia（012.2 密度经簇位基数翻倍交付——皮面恒等约束下 childPlan 加站必增皮面，密度主控权归 clusters 计数）
- **羽状小枝卡 SDF（第 2 叶语言——vs 莲座针簇放射）**：叶单位 = 脱落性侧生小枝系统（对生二列条形叶）；SDF = 沿垂轴帧 + 两列对生叶胶囊并集 + **三候选固定循环（长斜叶跨 ~5 带，单候选求值仅覆盖 11.3%——k0 名义带最近判据 + ±1 带窗口并集；固定 trip count 循环 = 纯 ALU 常量成本，白名单断言模式）**；挂点 = 对生叶序（clusterAzimuthStep π/2 交错）→ metasequoia
- **绳状鳞卡 SDF（第 3 叶语言——vs 莲座放射 / 羽状二列）**：1 卡 = 末级鳞叶小枝聚合系统（中轴枝 + 四列交互对生贴生鳞叶轮廓并集——绳状/corded 3D 聚合）；贴枝列语言 = 枝末梢延伸 + 枝周球面全方位着生（径向 0.7/前向 0.55/tilt ±0.7 全方位斜立——薄片化对策）；minority 刺卡复用 cedrus 散生针卡机制挂幼态梢/旺枝位（**二型叶同株——族内首例双叶型并存**；M8 观感弱于预期记档归族门）→ juniperus
- **三针束聚合卡 SDF（第 4 叶语言——束生短枝 fascicle）**：1 卡 = 末级枝段多束聚合（固定 3 针小扇 15–45° 开展 + 螺旋束位 + 束间距 ≈针长 1/3–1/2 + 束基裸叶鞘早落）；**判级主证 = 挂点律**（束生短枝单律——vs 雪松长短枝双挂点/水杉对生二列/圆柏贴枝四列；卡形机制近亲莲座管线可复制）；卡尺度 0.26–0.32 ⊂ 终值带；退化门第三次消费（bngPitchPx/bngStrokePx/bngAa/bngScGate 四门 + bngSolidify 剪影保持）→ bungeana
- **导数感知亚像素退化门（中距淡染材质对策——T012.3 Step 4 材质域第二轮实证）**：fwidth 门控两域——亚像素域（pitch ≤1.3px）带占→1.00（绳隙→带色收敛）+ 坡宽→max(0.02, fwidth(d)) footprint AA；可解析域（≥1.4px）原值逐位不动（**近景密度不稀释**——012.2 教训保持）；刺卡独立门 smoothstep(1.2,4.5,1/fwidth)。实效：同窗绿 17.0→22.8%（绿像素 +34%、mask 恒定 = 纯材质域增益）。**薄元素卡（绳列/羽列/针列）中距 alphaToCoverage 淡染的族级对策先例** → juniperus
- **校准终值带（密度先验导航，T030 记档）**：M25 冠带绿终值两例 33.0%（cedrus）/ 34.3%（metasequoia）同量级——新成员密度类初值从该带起步（规则见 tree.md Step 2 先验句），初版显著低于带即疑点信号；第三例 juniperus 22.8%（同窗硬编码口径）——**8m 小树体量口径差记档**（固定窗口对小树天然稀释 ~10pt+，族门横向验收建议「树冠投影带」口径或体量标定）；第四例 bungeana **45.2%**（11.5m 大树固定窗——体量敏感方向相反数据点）+ **疏散冠 caveat 例外第一例**（Spec 承重半透光疏散结构时低于带不必然缺陷——012.4 未触发方向，判读规则留档）
- **针卡双帧 uv 域**（散生 v∈[0,1) 根→尖帧 / 莲座 v∈[2,3) 中心放射帧，材质判别阈值 1.5；**族级提炼候选**——云杉/冷杉第二例必再遇）→ cedrus
- **无两面色差**（针叶辐射着生——契约不含两面字段即语义；vs 阔叶两面色差语言）→ cedrus
- **受光色差**（冠层暴露度 ramp 阳/荫 mix + 白粉随暴露度——观感色差来自受光与白粉而非两面）→ cedrus

## 球果账目（koelreuteria 花果零 rng 账目法改写）

- **直立如烛账目**（上半冠层板外缘结果枝带 + posHash 确定性布点 + 两类果并存〔将熟绿转褐 / 当年幼果淡绿〕+ 宿存中轴第三类 + 交叉双卡 4 tri/果入皮组、uv v 域分流材质）→ cedrus
- **浆果状肉质果账目（第三果形态）**：posHash 零 rng + 无柄腋生 2–4 枚小簇 + **双熟度并存**（绿幼果少数 + 蓝黑霜粉熟果主导——两年熟常绿任意时点挂果）+ 白粉霜层三档材质保留（中距霜蓝果点 = Spec §7 身份信号）+ 近景 6–8mm 果径点彩（M25 亚像素、近景位为主）→ juniperus
- **双态两年熟松果账目（第四果形态——近景点彩级）**：posHash 零 rng + 一年生绿幼果主导（直立、1–1.5cm——生长季主视觉；FRPS「初直立后下垂」精化消费）+ 少量二年生近熟淡绿-黄褐（u≥0.5 色档域）+ 4 tri/果入皮组 + **Mid/Low 省略**（vs 圆柏 Mid 全量——族内 LOD 取舍差异）；近景可见性经 4x 裁帧证实（30–40 处沿枝散布）→ bungeana

## 树皮语言谱系（接 broadleaf 13 语言后）

- 第 14 语言：鳞状方块片系（砖错位网格 + 方↔长方两型 + 平顶块片剖面 + 沟浅-中近黑 + 块顶浅灰褐 + 上部渐光滑株内梯度 + 一年生小枝淡灰黄高位门控）→ cedrus
- 第 15 语言：**纵长条片-纤维剥落系**（条片长宽比 4–6:1 沿 v + 脊:沟 2–3:1 深索浮雕 + 长纤维条翘边 + 幼淡橙褐→老暗红褐三色株内梯度）→ metasequoia
- 第 16 语言：**灰-灰褐基调纵长条片剥落系**（条片机制沿用第 15——长宽比/脊沟比/翘边浮雕 + 色相轴换灰-灰褐〔vs 水杉红褐基调〕+ 枝皮灰长纤维条剥高位门控〔vs 第 14 鳞状方块片〕）→ juniperus
- 第 17 语言：**白基调多色斑驳薄片剥落系**（族内首个非褐色系——乳白/灰白 40–65% 主导 + 灰褐 20–30% + 近黑 5–10% + 淡黄绿新皮露斑；地图状混杂 + 边缘窄-中等过渡域〔终审槽间差异记档——s07 渐变 vs s08 锐利不取单一读向〕+ **株内上白下深最强梯度**〔y-ramp `(y-1.5)/6.5 → mix(-0.10,+0.14)`——年龄皮色轴替代承载〕+ 薄片翘边亮斑缘反光 + 近光滑弱浮雕 barkGrooveDepth 0.18 族内最低；机制 platanus 斑驳剥落跨族复制〔broadleaf 第 5 语言〕+ 色相序列全新）→ bungeana（M75 斑驳不可辨记档归族门——远景档白干强化策略）

## 骨架族内变体（挂点语言三型横向）

- **层内方位律**：雪松 = 近轮任意方位 / **水杉 = 对生成对 ±180° + 层间 90° 交错（decussate）**——tierPhaseStagger + tierBranchCount=2 → 同一挂点语言两种方位律（族内差异轴之一）
- **密连续锥 vs 层叠带隙**：tierGapBand 0（水杉密冠）vs 观感带（雪松层隙）——同字段两端消费
- **高度域连续散生（第三骨架型）**：圆柏无规则轮层——挂点语言 = 高度域连续散布 + 方位均匀化 + 枝角梯度（下 40–70° 近平展 → 上 20–40° 上举，ginkgo 角度梯度法第三次消费）；**层位契约字段可退化消费**（高 tier 密度 + tierGapBand 0 + 大 jitter → 近连续，零契约修订零缺口）→ juniperus
- **柱/卵双型冠（冠轮廓包络第三型）**：从「锥形收顶」（cedrus/metasequoia 共用）改写为柱体/卵圆体轮廓——狭圆柱 0.2–0.3（上下近等宽 + 钝圆收顶）↔ 卵圆 0.4–0.6（中部最宽）；冠形谱系第三极 → juniperus
- **开张卵圆→伞形平顶包络（第四型——exp<1 端型首用）**：中龄开张卵圆 0.7–1.0 → 老树伞形平顶 >1.2（顶平截/外抛）；exp<1 包络指数 + 解析冠顶适配（max(attach+climb) 树高解——8 槽树高涌现 ⊂ 锚 ±3.2%）；散生退化消费**第二例直承**圆柏路径（零契约修订）→ bungeana
- **多干近似 slot（近基多干双态消费先例）**：自然态近基多干（FRPS「或从树干近基部分成数干」）经连续参数渐近承载——低位 trunkHeightRatio + 陡 tierAngleBase + rank 双强 → s08 型 30–45% 高度分叉伞状读向成立（零契约修订）；**真近基并立型（分叉 <10% 高度）不可承载**——单干管拓扑 + rng 恒等约束 → D31.2 候选归族门 → bungeana
- **器官帧域三级化**：羽卡 [0,1) / 球果 [1,2) / 枯穗 [2,3)（阈值 1.0/2.0，vs 雪松双帧域 1.5）——族级 uv 帧域规范第三例前维持资产侧定（缺口归族门）

## 风动

- **三成分**（整层低频慢摆〔层状大枝 massive〕+ 层缘垂帘/针簇高频颤 + 顶梢专路摆幅上 1/4 门控；树高锚 16.5 = slot-0 totalHeight 同源）→ cedrus（salix 两层频率档法的三成分扩展位；canopy 退化 = 三成分→两槽映射，顶梢成分远景不保留——结构性简化记档）
