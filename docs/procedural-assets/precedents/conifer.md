## 层状骨架语言（族核心——vs 阔叶「骨架枝 + 挂高段 + 椭球密度场」）

- **scaffold 挂点按层位量化路由**（近轮生成层 / 层间距均匀 + jitter / 首层挂高 = 干高比 × 树高）→ cedrus（骨架算法复制自 tree3a growBranch 递归，挂点语言层状改写）
- **层角梯度**（下部近水平 → 上部上举，沿层位插值——ginkgo 角度梯度法的层状版）→ cedrus
- **层板升扇/拱形 + 外缘微垂下卷**（垂直速度场 sin 拱 + smoothstep 下卷）→ cedrus
- **层叠尖塔冠**（层板轮廓串联、非光滑圆锥面；锥形收顶指数 + 基部最宽）→ cedrus（vs ginkgo 光滑圆锥）
- **层隙观感带**（簇布点按层聚集 + 层间空带——vs 阔叶外密内疏；层隙带宽工程校准值）→ cedrus
- **末级垂帘**（droop 负链 + fringe 乘子——salix upturn 负链机制直承）→ cedrus
- **顶梢专路下垂点头**（近直立初向 + 二次点头曲线 + 裸梢散生针卡防秃）→ cedrus

## 针叶表达（长短枝双挂点——ginkgo 机制直承 + 针叶改写）

- **短枝莲座簇卡**（1 卡 = 整簇针叶 SDF：极坐标扇区窗列放射 + 逐针 sin-hash 长宽抖动 + hub 实心 + 先端锐尖；针数随档变体 20/14/8）→ cedrus（新形态语言，限定文件内）
- **长枝散生针卡**（sin(π·v^1.55) 单针包络——上部较宽先端锐尖下部渐窄；近景散生读向，M25 无质量贡献——单针卡 2–3px，预算应让给簇）→ cedrus
- **中距浓密板三杠杆（T012.1 Step 4 校准实证——浅调线密度无效）**：①莲座簇**交叉双卡**（单面卡⊥枝切向无角度覆盖——第二卡零 rng 派生偶奇分工）；②**卡尺度 ≥0.3m**（亚像素卡〔<0.2m〕中距不可辨——簇是「点」质量、卡尺度才给「面」质量）；③挂点前移消裸段（clusterInnerStart + childPlan ts）→ cedrus
- **针卡双帧 uv 域**（散生 v∈[0,1) 根→尖帧 / 莲座 v∈[2,3) 中心放射帧，材质判别阈值 1.5；**族级提炼候选**——云杉/冷杉第二例必再遇）→ cedrus
- **无两面色差**（针叶辐射着生——契约不含两面字段即语义；vs 阔叶两面色差语言）→ cedrus
- **受光色差**（冠层暴露度 ramp 阳/荫 mix + 白粉随暴露度——观感色差来自受光与白粉而非两面）→ cedrus

## 球果账目（koelreuteria 花果零 rng 账目法改写）

- **直立如烛账目**（上半冠层板外缘结果枝带 + posHash 确定性布点 + 两类果并存〔将熟绿转褐 / 当年幼果淡绿〕+ 宿存中轴第三类 + 交叉双卡 4 tri/果入皮组、uv v 域分流材质）→ cedrus

## 树皮语言谱系（接 broadleaf 13 语言后）

- **第 14 语言：鳞状方块片系**（砖错位网格 + 方↔长方两型 + 平顶块片剖面 + 沟浅-中近黑 + 块顶浅灰褐 + 上部渐光滑株内梯度 + 一年生小枝淡灰黄高位门控）→ cedrus

## 风动

- **三成分**（整层低频慢摆〔层状大枝 massive〕+ 层缘垂帘/针簇高频颤 + 顶梢专路摆幅上 1/4 门控；树高锚 16.5 = slot-0 totalHeight 同源）→ cedrus（salix 两层频率档法的三成分扩展位；canopy 退化 = 三成分→两槽映射，顶梢成分远景不保留——结构性简化记档）
