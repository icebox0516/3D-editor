# Reference Spec 模板

> 使用：复制本结构到 `docs/research/<asset>-reference.md` 后填写；域扩展节字段按 `references/<domain>-schema.md` 定义填写（新域无 Schema 时先起草草案）。`←` 注释为填写指引，定稿时删除。描述原则与 Evidence Status 见上级 SKILL.md。

---

```md
# <asset> Reference Spec

Spec Version: 1.0        ← 修订内容时递增（1.0 → 1.1）；任务书执行快照锚定此字段
Domain: plant            ← 所属域，对应 references/<domain>-schema.md
Asset: tree3a            ← 资产 id 或暂用名
Updated: 2026-09-18      ← 最后修订日期

关键事实统一写法（各节内联、逐条标注；Source 填来源表编号或「用户提供」）：

- 树高：7–9m
  - Form: Range
  - Evidence Status: Verified
  - Source: [1]

## 1. 身份
← 是什么、具体种/型号、使用语境（一句话到一段，定位性信息）

## 2. 主要尺度
← 核心尺寸及最小/典型/最大范围。不强制统一为高/宽/深——按对象选关键尺度
  （路灯是杆高/悬挑长，湖泊可能是岸线/水域面积/深浅）

## 3. 轮廓与比例
← 整体形态、关键数量关系、相对比例（如 冠幅/树高 ≈ 0.8–1.0）

## 4. 结构层级
← 部件树、部件形态、连接/着生关系（干→枝→针叶束；杆→臂→灯头→灯具）

## 5. 材质与表面
← 颜色域、粗糙度、透光、反射、表面结构。写到可观察层，不给实现参数

## 6. 变体范围
← 真实对象的主要变化维度、范围及联动关系（锥角摆动时枝长如何联动）

## 7. 远近景保留优先级
← 远距必须保留什么、可牺牲什么，写到视觉显著性为止
  （如「50m 外只剩层叠锥轮廓 + 深绿域可辨认」）。面数/切换距离等工程映射归任务书

## 8. 来源证据

| # | 来源 | 类型 | URL/文献 | 检索日期 | 提取内容 |
|---|------|------|----------|----------|----------|
| 1 |      | 论文/官方/产品页/技术手册/百科/图片/用户提供 |  |  |  |

← 类型不限于图片；用户提供行填用户所给参考的说明；数量按对象复杂度定；核心结论必须可追溯到本表某行

## 域扩展节：<domain>
← 字段由 references/<domain>-schema.md 定义；结构化填写，禁止自由文本
← 每条关键事实带 Evidence Status（Verified / Inferred / Unknown）
```
