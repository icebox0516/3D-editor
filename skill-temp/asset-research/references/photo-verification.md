# 照片判读与证据验证规程（当前有效口径）

> 归属：`asset-research` references。
>
> **本规程是按需启用的证据工具，不是所有资产的默认调研步骤。**
>
> 仅当候选照片承担身份、关键结构、比例 / 尺度或其他承重现实主张时启用。
>
> 当前有效裁定来源：D35.1 第 4 条及 2026-09-21 追加裁定。第二视觉系统已取消。

## 1. 双问一致

仅当照片承担关键身份或形态判定时执行。

对同一张照片进行两次独立视觉提问：

* 提问不得直接泄露对象名称或预设答案；
* 两次判断相互独立；
* 两次结果一致，照片才可以承担对应现实主张；
* 两次结果不一致 → 该照片不承重，并记录分歧；
* **不得通过“取中间结论”让不一致照片重新承重。**

“双问”是同一视觉判断能力的两次独立判读，不等于第二视觉系统，也不等于第二个 Agent。

## 2. 关键数值独立抽查

仅当数值会影响身份、结构、比例或核心生成决策时执行。

主代理：

* 独立重新拉取权威原句；
* 逐位核对；
* 不直接复抄调研稿中的数字。

普通、不承重的数字无需全部重复核验。

## 3. URL 权威口径

仅针对外部候选照片：

* URL 的域名与扩展名从对应 API JSON / 权威记录获取；
* 不手拼猜测扩展名；
* 无法确认 URL 真实性时，不将其作为正式证据来源。

## 4. 图片加载确认

仅当图片本身承担证据作用时：

* 判读前确认图片实际加载成功；
* 截断副本必须修复并核对；
* Content-Length 与实际字节不一致时，该图片判读作废；
* 加载失败 / 截断图片不得进入承重证据链。

## 5. 像素内参照物

凡作尺度或比例主张：

* 必须存在画面内可承重的尺度参照物；
* 没有参照物时，只能给出定性或相对描述；
* 不得从单张无尺度照片伪造绝对尺寸。

## 6. 字节溯源边界

字节级溯源只能证明：

> 图片确实来自某个来源 / 某个文件。

不能自动证明：

> 图片中的对象、尺寸或形态判读正确。

内容判读仍必须根据图像证据独立完成。

## 7. 何时不启用本规程

以下情况可以不做照片验证：

* 图片只是普通视觉参考；
* 用户已经提供充分事实，不需要图片承担新证据；
* 当前资产生产没有身份、结构、比例等照片承重问题；
* 当前 Research Gate 已判定无需实际调研。
