# 照片判读与证据验证规程（当前有效口径）

> 归属：asset-research references——跨资产的现实研究与证据验证方法论（DECISIONS D36 第 7 条：生产 Workflow 只引用、不复制）。
> 当前有效裁定来源：DECISIONS D35.1 第 4 条及 2026-09-21 追加裁定——第二视觉系统步骤取消，照片判读回到夏栎 008.6 口径。

1. **双问一致**：两次独立视觉提问（提问不出对象名，防引导幻觉）一致方定名；双问不一致 → 该照片不承重处置并记档，不硬凑结论。
2. **主代理硬数值抽查**：关键数值独立重拉权威原句逐位比对，不抄调研稿。
3. **URL 权威口径**：候选照片 URL（域名与扩展名）都自 API JSON 记录取，不手拼。
4. **加载确认**：判读前确认图片实际加载成功（截断副本修复 + Content-Length 逐字节核对——加载失败 / 截断的判读一律作废）。
5. **像素内参照物**：尺度主张须有画面内参照物承重；无参照物的比例读数降级为定性描述。
6. **字节溯源边界**：字节级溯源只证来源，不证内容判读（照片确系该来源 ≠ 画面内容读数成立——判读仍走双问）。

历史注记（不作现行要求）：「异系统交叉」（第二视觉系统）曾为 D35 外派终审口径的一部分，2026-09-21 追加裁定取消；曾出现在历史任务书与 epic 进度行中的该表述为当时事实，不再复述。
