# T011.5 悬铃木全链（第五树）

## Goal

悬铃木（Platanus × acerifolia 二球悬铃木——具体种口径由 Spec 调研确认）生产资产 `asset_tree_platanus`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证（外派验证子代理）。**新叶形 + 树皮语言再分化**：掌状 3–5 裂大叶（第六种叶形语言——前五例全部「全缘/锯齿连续轮廓」与银杏「扇形+顶缺刻」，掌状深裂为裂片达叶中的多裂轮廓）+ **斑块剥落树皮**（大块不规则斑块剥落露出奶油/黄绿/灰褐新皮——「迷彩」拼贴，vs 榉树小片暖色斑驳的实质分化，银杏取「第五语言」后本树为第六语言）。长江流域行道主力。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外见 Constraints，D31.2）。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → 植物志（FRPS/FOC 优先——FRPS 35(2):120 强证据已在候选池），形态材质变体 → 真实照片直接视觉证据（判读必须含异系统交叉）。重点调研面：种定名（二球悬铃木 Platanus × acerifolia 杂交起源口径 vs 一球/三球——中国城市语境主力确认）；**掌状裂叶**（阔卵形轮廓、宽/长数值、3–5 裂、裂深（达叶中？）、裂片形态（中央裂片宽三角/楔形）、裂片缘齿、叶柄长、叶背绒毛后脱）；**斑块剥落树皮**（剥落斑块尺度相对干径、色带组成（奶油/浅黄绿/灰褐？）、剥落节奏（幼光滑→成斑块）、vs 榉树暖色小片斑驳分化点）；**树体量与冠形**（悬铃木为大乔木——中龄公园个体树高锚定与可混植量级（夏栎 ≈8m 语境）、冠形（阔卵/圆头）、大枝开展姿态、干形（通直？基部分叉？行道修剪语境 vs 公园自然冠）；宿存球状果序（夏季可见性——建模与否以 Spec 定）；枝叶密度读向（大叶疏簇 vs 小卡密簇——前例卡尺度对照）。
- **Step 1 结构分析**：Spec → 五先例方法基线对照——可继承 / 改写 / Unknown；**掌状裂 SDF 可行性预判**（银杏「半周期包络+顶边缺刻」先例的推广性——多裂深裂轮廓表达路径）。
- **Step 2 参数化**：`tree/platanus/platanusShapeProfile.ts`——BroadleafShapeProfile 填悬铃木数值（逐字段 Spec 依据 + Evidence Status + 三标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量展开。
- **Step 3 几何（procedural-asset-agent）**：`tree/platanus/platanusGeometry.ts`——方法复制 + 悬铃木算法细节（大叶疏簇挂点语言/冠形/干形按 Spec 与 profile；树皮起伏按 Spec）；LOD 三档同流；入口 `assets/asset_tree_platanus.asset.ts`（meta 同契约 + build slot→profile 路由 + level 透传 + customDepthMaterial 通道）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/platanus/platanusMaterials.ts`——**掌状裂 SDF**（3–5 裂深裂轮廓——参照银杏顶边系统推广或新路径，最小扩展限定文件内）+ 裂片缘齿 + 叶面尺度感（大叶纹理频率相对卡尺度）+ 叶色（叶背初期绒毛后脱的表达口径）+ 背光透射 + 风动两层 + **树皮斑块剥落配方**（大块多色拼贴——vs 榉树频率/尺度/色带重排；门控判定：满干型 or 干基型——影响取证机位）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/platanus/platanusStage.ts` 同构 + bootstrap 挂载 `window.__platanus`；缺口 D 评估（门控型树皮取证机位）。
- **Step 4 视觉验证（验证子代理，D35）**：三必做（①身份判定：掌状裂大叶 + 斑块剥落干 + 阔卵大冠；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.5/`；③缺口记档归 011.13）+ 疑点触发（掌状裂近景读出/树皮斑块判读（若门控型按 011.3 仰视先例）/风动三证据/console/LOD 档间）；校准默认一轮、两轮封顶；校准编辑归开发 agent、同一验证子代理复判；冲突主代理仲裁、像素为准。
- **测试**：对称 ginkgo 组织（tests/runtime/procedural/tree/platanus* 五件）。
