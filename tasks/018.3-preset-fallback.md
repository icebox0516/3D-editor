## Goal

四预设（day/dusk/night/tech）从「渐变双色 + Hemi/太阳配色」旧参数面转为**新参数面**（Sky 四大气参数 + Cloud 四参数 + sun elevation/azimuth/intensity/color + ibl intensity + ground/grid），预设差异化首次全生效（此前四预设同用 day 太阳角与 provisional 大气表）；**HemisphereLight 退出正常路径**（D29.4 禁多光源叠加——Hemi+IBL 偏亮中间态收口）；**事务式 fallback 单一开关**（D29.5）：首次初始化失败（Sky 构造 / PMREM 初烘）→ 完整 legacy 路径（CanvasGradient 背景 + Hemi + 现行太阳常量），**运行中重烘失败 → 保留上一份成功环境**（不降级不闪断）。Runtime 层不进 Scene 持久化（`preset: string` + 开放扩展键天然兼容，UI 零改动）。

## Requirements

- **预设新参数面（收口单一真相源）**：`EnvironmentPreset` 重构——新增 `atmosphere`（turbidity/rayleigh/mieCoefficient/mieDirectionalG）+ `cloud`（cloudCoverage·cloudDensity·cloudElevation·cloudScale，**cloudSpeed 恒 0 不进预设**——D29.11 静态云语义）+ `sun`（elevationDeg·azimuthDeg·intensity·color）+ `iblIntensity`；`groundColor/gridMajor/gridMinor` 沿用；`skyTop/skyBottom/ambient*` 保留**仅供 legacy fallback 消费**（不再出现在正常路径读路径）。018.1 provisional 表 `SKY_PRESET_ATMOSPHERE` 收口入统一预设面（**避免两份真相**——`SkyAtmosphereParams` 类型归 skyCore，预设数值归统一预设面；落点由实施 agent 按可测性定，Renderer 内表或 environment/ 新模块均可）。
- **预设差异化 provisional 值**（018.5 视觉验收终调，表内注明可调）：day = 现行零漂移锚**不动**（太阳角 50.2°/53.1° / 大气沿用 018.1 day 值 / ibl 1.0）；dusk = 低太阳角（elevation ~5° 量级）暖浊大气 + ibl 略降；night = 低角 + 低强度太阳（月光语义）+ 低 rayleigh + ibl 显著降（Preetham 无夜晚语义为已知近似 D29.6）；tech = 冷色偏高 rayleigh 低云量 + ibl 中低。四预设 ground/grid 配色沿用现有值（预设视觉差异主载体 = 天空/太阳/IBL）。
- **Hemi 删除（D29.4）**：applyEnvironment 正常路径不再创建 HemisphereLight——环境漫射光全部由 IBL（scene.environment）承担；`ambient.layers.enableAll()` 段随删。Hemi 仅存在于 legacy fallback 路径。
- **事务式 fallback 单一开关（D29.5）**：
  - **结构**：applyEnvironment 尝试新路径（SkyCore 构造 → 挂 envGroup → PmremEnvironment 构造 → 初烘 bake）；**任一步抛错 → 事务清理已建部分（sky/pmrem 释放）→ 完整 legacy 路径**（createSkyTexture 渐变 `scene.background` + Hemi + 现行太阳常量 `(80,120,60)` 同向同模长口径 + scene.environment 置 null）；
  - **单一开关不变式（单测锁定）**：状态二选一，无混合态——新路径成功 ⇔ { displaySky 存在 · scene.environment 非空 · 无 Hemi · background null }；fallback ⇔ { 无 sky · environment null · Hemi 存在 · background = 渐变 }。**「真天空但无 IBL」禁止出现**；
  - **失败可见性**：fallback 触发 console.error 记档原因（诊断可查，不静默降级）；
  - **每次 applyEnvironment 重新尝试新路径**（失败是环境性的——WebGL context 异常等，恢复机会留给下次切换；不把 fallback 态粘死在 Renderer 实例上跨预设切换）；
  - **运行中重烘失败保留旧环境**：SkyCore 三写入口回调 `() => pmrem?.bake()` 增 catch——重烘抛错**不传播到写入口调用方**（DEV 面/后续消费路径），旧 environment 天然保持（018.2 事务基础），console.error 记档。**初烘失败 ≠ 重烘失败**：初烘（applyEnvironment 内）走 fallback 整组降级；重烘（运行中）只记档不降级。
- **legacy 路径完整性**：fallback 用现行 `createSkyTexture(skyTop, skyBottom)` + 预设 ambient* 键 + shadow camera 全套同正常路径（2048/±160/bias 不动 D29.1）；RenderModeState useBackground 口径已预留（`RenderModeState.ts:71-75` 注——background 每遍重绘机制对 fallback 天然生效，**零 renderMode 改动预期**）。
- **UI / 持久化零改动**：bootstrap `ENVIRONMENT_PRESETS`（id/label）不动；`SceneEnvironment = preset: string` 不动；environment/bootstrap 既有预设断言零回归。
