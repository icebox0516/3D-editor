## Requirements

- **叶材质（ShaderMaterial 或 onBeforeCompile 注入，park-shader-agent 定方案）**：
  - SDF 程序化叶形：片元内 alpha 叶形（零外部贴图，D13），叶缘微锯齿/叶脉明暗可选
  - 光照：与场景光照模型一致（PBR 基座或自定义光照项），**透光**（translucency：背光透射项，近观层级感关键）
  - 色彩变化：底色 × `aLeafRand` 逐叶变奏（明度/色相/透光强度），冠内深浅层次
  - 风动：顶点位移 = `aBend × hash(aSeed) 相位 × uTime`——uTime 管全局风帧、aSeed 管每棵树个体相位（D19.7 分工语义）；多层摆动（整树缓摆 + 叶片快颤）按 aBend 权重分离
  - instanceColor 色相通路保留（T002.3 逐实例色相微差乘算链不破坏）
- **树皮材质**：程序化升级（沿 plantMaterials onBeforeCompile 范式：沟壑/节疤/苔痕方向性调制），近观经得起看
- **几何契约只读**：aLeafRand/aBend 语义消费方，**不修改几何数据契约**（008.2 冻结；违约改动审查打回）
- **锚点定调门（任务尾，人工阻断——门未过 008.4/008.5 不得启动）**：
  1. 主代理开工前先行确定参考基调（外部视觉基准 1–3 张，仅沟通用不进产品资源与代码契约）
  2. slot-0 一棵树，**近/中/远三距离固定机位**出图，分别检查：枝干/分枝真实度 ｜ 树冠体积与空隙 ｜ 整体轮廓自然度
  3. 取证纪律：固定机位 + 固定曝光/环境光 + 固定相机距离（防渲染条件变化误导迭代）
  4. 用户裁定，最多 1–2 轮针对性微调；定稿后形态+材质参数基准记录在案（后续 8 槽扩展与回归对比的锚）

### 2026-09-17 代码段完成 + 取证归档（锚点门待用户裁定）

- **实现**（park-shader-agent，两段派发——首派撞账户 5h 限额阵亡未留半成品，14:07 重置后原简报重派成功）：`tree/tree3aMaterials.ts` 三工厂——叶（SDF 橡叶形 alpha：卵形包络×4 圆裂×高频锯齿 + 中脉/侧脉明暗，alphaTest 0.5 + alphaToCoverage 吃 MSAA；背光透射项 `dot(V,-L)·pow³·逐叶变奏` 进 outgoingLight 走色调映射；aLeafRand 色相/明度/透光三去相关变奏 + 冠内自遮蔽 + 叶团斑块；风动 = 整树缓摆 0.18Hz/4.5cm 高度²权重 + 叶片快颤 2.2–3.7Hz/≤11mm aBend 权重，相位 hash(aSeed)/hash(aSeed+aLeafRand)）、皮（14 脊深沟 + 竖长板块 + 节疤同噪两用 + 冠下苔痕方位调制 + 同公式缓摆）、叶影裁切深度材质（同一 SDF 单一来源 + 皮组 aLeafRand=0 守卫实心）。uTime 桥接 = 材质级 `uniforms.uTime` 与 `shader.uniforms` 同对象引用（TimeUniformService 扫描面）。
