## Goal

D4/D5 落地：「Style 即完整配方」进数据模型——样式预设携带 表面材质 + 资产配比 + 散布参数；区域只存 `presetId + overrides + seed`；派生式语义端到端打通。

## Requirements

- **配方结构**：预设定义扩展为 `{表面, 配比[assetId×weight], 散布参数(密度/聚簇/边缘衰减/尺寸范围)}`；表面与散布两段均可独立为空（纯表面 / 纯散布）
- **区域数据**：`style` 扩 seed 位；场景序列化增量放行（不破坏存量场景往返）
- **端到端**：应用散布样式 → 撒点（003.1）→ 分块渲染（003.2）→ 参数/seed 覆写 → 受影响块局部重算
- **换装语义**：散布样式 ↔ 表面样式互切，散布内容随换（换入即散、换出即清）；撤销作用于区域对象（undo 恢复前样式与前散布）
- **拾取反查**：点散布实例 → 选中所属区域（instanceId → 块 → region 映射）
- **Inspector**：散布参数组（密度/聚簇/边缘衰减/seed 重掷按钮）
