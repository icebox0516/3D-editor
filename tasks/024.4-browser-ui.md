# T024.4 浏览器色点 UI + 放置入口接线

> 状态：**done（2026-09-28）** ｜ Epic：[024-color-presets.md](024-color-presets.md) ｜ 前置：024.1 done（放置链 preset 全链通用：PlacementTool parsePreset 写侧 fail-fast / Ghost 带卡 / modelFactory 默认卡省略不落盘）+ 024.3 done（13 树卡集全量真卡数据——冒烟吃全量）

## Goal

激活色卡的**用户入口面**：资产卡片名旁色点（swatch 数据色）点击切换色卡，选中态 localStorage 持久（沿收藏先例）；全部放置入口（点击卡片 / 右键「添加到场景」/ 拖放 / 键 4 重放）注入选中卡——Ghost 所见即所得（D44 #8），落地对象 asset.preset 随撤销重做与保存重走 024.1 已交付的全链。机制层零新增（024.1 已全链通用）：本任务只做 **browserModel 存储纯逻辑 + ContentBrowser 色点 UI + App/toolIA 四入口读选中**。无卡资产（presets 空数组 / GLB）不显色点、放置零注入，行为与现状逐位一致。

## Research Gate

`Status: waived`（非程序化资产生产任务——UI 入口接线，无现实对象调研面；色卡证据纪律已由 024.2/024.3 承接完毕）。

## 待裁决位（D44 已裁定 + 本任务立项裁定，执行时不再复议）

- **色点显隐判据 = `presets.length > 1`**（本任务裁定）：epic「无卡资产不显色点」的落点——色点语义是**切换**，单卡资产（camphor/ligustrum 常绿 default 单卡）无可切换项，单点纯噪音不渲染；空数组 / GLB（无 presets 字段）天然不渲染。单卡资产的卡信息由 tooltip 承载缺席不构成缺口（常绿终态无季相可切，024.3 已记档）。
- **选中态真相源 = localStorage（面板私有，沿收藏先例）**：键 `t3d-editor.asset-presets`，形态 `Record<assetId, presetId>`；**默认卡省略不落盘**（D44 #4 同构——点 default 删条目，存内只有非默认卡）；损坏 JSON / 非法形态宽容归空集合（loadFavoriteIds 同纪律）。**不进 zustand / 不进工作区快照**——色卡选择是内容偏好非布局态，与收藏同层。
- **读侧统一走 `resolveDeclaredPreset`**（D44 #4 已有纯函数，零新增语义）：已删卡 id 存留 → 宽容回退 default（UI 激活态与放置注入同一判定，不抛错）；写侧（PlacementTool parsePreset）fail-fast 现状不变——UI 只传已声明卡，非法即接线错误。
- **放置注入覆盖全部四入口**（本任务裁定——「放置链带该卡」的完整性）：点击卡片与右键「添加到场景」同走 `onPickAsset`（激活 PlacementTool 携 preset）；拖放走 App onDrop（dataTransfer 增 `application/x-asset-preset` mime，仅非默认卡写入；text/plain 保持纯 assetId 跨应用兜底不变）；键 4 / 垂直条重放走 `togglePlacement` 增可选尾参。四入口同一读法：事件时刻从存储读选中 → `resolveDeclaredPreset` 校验 → 传参（默认卡 = 不传，路径与现状逐位一致）。
- **放置中点色点 = 重激活会话**（本任务裁定，WYSIWYG 收口）：PlacementTool「换卡 = 重新激活」既有语义的用户触发面——正放置该资产时点色点：先持久化新选中，再走 onPick 同路重激活（Ghost 立即换卡）；重激活重启放置会话批次与卡片重点击行为一致（既有行为，非新增语义）。
- **色点 UI 落位 = 卡片右下角覆盖条**（本任务裁定，frontend-design 技能 + DESIGN.md §5.8 增量承载）：真实 `<button>` 不得嵌套进 `__main` 按钮——色点条为 `.ed-card` 的绝对定位兄弟层（沿 kind 角标左上 / 星标右上的覆盖语言），锚定 `bottom/right: var(--sp-2)`（cat 行右侧，token 纯锚定零魔法数）；点色 = swatch 数据编码色（「数据编码色不表达激活语义」条款不变），**激活态 = 琥珀环**（「正在被操作」琥珀专属语义）；视觉令牌零新增。
- 缩略图不随卡重渲（D44 #2 现状维持）；Inspector 换卡不在本期（epic 增补位记档不动）。
