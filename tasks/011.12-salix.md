## 待裁决位（Step 1 判定记档，2026-09-22 主代理——依据 Spec 1.0 + 终审修正口径）

1. **垂枝冠表达路径（应力位核心）：①档——现有 BroadleafShapeProfile 参数域内表达，D31.2 不触发、零契约修订**。实证：`growBranch` 每段方向更新 `d.add(UP × upturn·t·0.5)`（tree3aGeometry:1099 同构全体先例）——upturn 为带符号连续参数，契约注释明确「上翘/下沉姿态」双向语义，无 clamp；先例 11 树取值带 [-0.04, +0.41]（栾树 L5 微负在先），垂枝所需 L3/L4/L5 强负（预估 -0.6 ~ -1.5 量级，探针定档）属**量级极端化而非域外**。实现路径 = scaffoldAngle 大值域（骨架外展-拱起 20–60°）+ L3/L4/L5 upturn 强负链 + 末级 lengthRatio 加长（垂帘段覆树高 2/5–2/3）+ radiusRatio 末端细化（垂索径 2–6mm，growBranch 末径地板 0.004m 同量级可达）+ **簇沿切向机制**（先例「簇方向 = 挂点枝切向」——垂索切向近垂直向下 → 叶卡沿垂向排布，与 Spec 终审补强「叶尖沿索轴朝下」现实读向天然对齐）。风险留档：若 Step 2/3 探针发现结构性阻塞（帘幕密度/末径地板/簇球形分布与帘读向冲突）再升级 D31.2 判定，暂不停机。
2. **花 / 果：不做**（记档）。柔荑花序先叶开放花期 3–4 月、蒴果 4–5 月——时窗错位判据（ligustrum 先例直接适用：盛花信号再强，花期不覆盖 9–10 月主语境即不做）；身份由垂帘姿态 + 狭披针细叶 + 喷泉轮廓三信号承托。
3. **干形：slot-0 低叉单干中间型**（Spec 建议维持）；干形轴 = 主变体轴跨槽分化（单干高位分叉 ↔ 低叉多茎 ↔ 基部多干斜弯三型照片直证）；「旱柳砧高接」成因 Unknown 不消费——干形变体域由照片直接承重，嫁接叙事不进实现。
4. **slot-0 锚：树高 ≈10m**（生产锚 8–12m 带中值偏上——喷泉冠体量感 + form-a 岸线粗估 10–12m 佐证；Step 2 探针涌现回调）；冠幅比 1.0–1.3（终审修正上沿；sophora 宽冠邻档）；干高占比 ≈0.25–0.35。
5. **叶 SDF：狭披针形包络改写**（ zelkova 卵形-披针路径改写为窄域极端长宽比——典型 10–15、照片读 8–12、文献域 6–32；最小扩展限定文件内、记缺口候选）+ **高频细齿载波**（「齿极细密近全缘观感」= 高频小幅值载波，zelkova 同法频率上探）+ 羽状脉中脉清晰侧脉弱（近零侧脉信号——ligustrum 近零脉路径邻档）+ 先端长渐尖（变指数域）。
6. **叶取向：沿索轴**——簇切向机制天然消费（见 1）；叶卡窄长（卡宽映射真叶 0.5–1.5cm ×2 工程映射沿先例）。
7. **树皮第 13 语言**：暗灰黑（灰黑-近黑基）+ 波状不规则纵沟脊 + 沟深、脊浅褐 vs 沟近黑强对比 + 修剪残桩点缀——vs 先例：近国槐暗色深裂系但更波状不规则（语言谱系独立位）。
8. **小枝色：单档淡褐黄-淡褐（带紫端微调）**——Spec 无龄级两档信号（FRPS 单句色域），不做两档分化（vs fraxinus/ligustrum 两档先例的差异记档）。
9. **叶色/透射**：上面中绿-中深绿 + 阳面黄绿调变奏 + 下面浅绿微银（弱色差档，fraxinus 弱档先例 + 非苍白色差方向）；背光透射上探（细叶高透、发光观感——家族透射值域链上沿试探）。
10. **风动两层**：垂索高频低幅颤动 + 整帘低频摆（悬垂结构特性——频率/幅值按垂索质量分布调档；树高锚同步轮照走）；hash 去相关双通道域外取值沿先例。
11. Unknown 留档：旱柳砧成因（Unknown——不消费）、侧脉计数（Unknown——近零侧脉信号消费）、垂幕绝对长度（Relative 域消费）、scaffold_count 文献无计数（照片判读 3–6 枝 + 族典型域，标【工程设定无现实基准】补间）。

改写映射实现面：几何 = 垂枝 upturn 强负链 + 喷泉骨架（外展拱起）+ 干形中间型 + 簇沿切向垂帘；参数 = 全部按本 Spec 数值（树高 8–12m 带 / 冠幅比 1.0–1.3 / 干高 0.25–0.35 / 间隙 0.1–0.25 / 垂幕 2/5–2/3 / 索径 2–6mm）；材质 = 狭披针 SDF（窄域包络 + 高频细齿 + 近零侧脉）+ 黄绿调弱色差 + 高透 + 树皮第 13 语言 + 单档小枝。
