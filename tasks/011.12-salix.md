## Goal

垂柳（Salix babylonica，杨柳科柳属）生产资产 `asset_tree_salix`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证（外派验证子代理）。**垂枝冠 = 家族契约应力位**：小枝细长下垂的形态域超出既有枝角参数域的预期——Step 1 判定表达路径（现有参数域内重排 / D31.2 最小必要修订 / 停机问用户三档），为族门契约收口提供垂枝域实证。**狭披针形细叶**（线状披针形 + 缘细锯齿——细长叶形语言）+ 垂枝姿态（身份核心：冠形倒广卵/伞状垂帘）。水边场景语境（栽植语境记档，不扩 Runtime 场景能力）。柔荑花序早春先叶开放——生长季不可见，记档不建模预期。继续发现并记档家族契约缺口（默认零修订、归 011.13；**本树 D31.2 阻塞例外高概率触发——应力位**）。

## Research Gate 判定（D26，开工前留痕）

- **判定：强制调研**。命中情形：①高真实要求（垂枝姿态为垂柳独有身份）；②类型显著影响形态（**垂枝冠形态域应力**——枝角下垂超出既有实例域；细长叶形）；⑤资产将成同类生产基准（垂枝域首例与收口实证）。
- **执行**：通用子代理加载 asset-research 技能 → `docs/research/salix-reference.md`；Spec 终审外派独立校验子代理（D35：硬数值抽查 ≥12 条对照 iplant/FOC 原句 + 关键照片第三只眼中性判读〔判读前确认图片实际加载成功、尺度主张须像素内参照物〕、分歧取中庸、终审记档追加于 Spec 文末）。
- **Spec Version 锚点：1.0**——开发 Agent 开工前校验一致。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 20(2):138（自行复核原句）/ FOC Vol.4（卷页由调研确认）；形态材质变体 → 真实照片（异系统交叉）。重点调研面：种定名（S. babylonica vs 旱柳 S. matsudana 及「垂枝旱柳」栽培变体口径——公园语境垂柳定名判据；砧木嫁接口径〔苗市垂柳常旱柳砧高接——干形是否通直砧干 + 顶部垂枝幕，公园典型个体形态判定承重〕）；**垂枝结构**（小枝下垂长度/垂幕轮廓/枝先端垂坠姿态、大枝开展角 vs 小枝下垂角的分层关系——数值或可观察特征承重）；**狭披针形叶**（线状披针形？长宽 cm 与长宽比、缘细锯齿密度、叶柄短？、羽状脉、两面绿色/背面色差）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；倒广卵形/伞状？冠幅 vs 树高比——垂柳冠幅常大于树高的观感判定）；**干形**（通直/微弯/多干？——嫁接口径承重）；**树皮**（暗灰？纵裂/沟裂？——vs 先例语言定位）；**枝姿**（大枝粗壮开展 vs 小枝纤细下垂的分层质感——细枝直径量级）；**花/果**（柔荑花序早春先叶——生长季不可见性确认，记档口径）；**叶色**（生长季黄绿/亮绿？垂柳偏黄绿色调观察）。
- **Step 1 结构分析**：Spec → 先例方法基线对照——可继承 / 改写 / Unknown；**垂枝冠表达路径判定（应力位核心）**：①现有 BroadleafShapeProfile 枝角参数域内表达（下垂角极端化）②D31.2 最小必要修订（仅解阻塞、不扩大公共抽象、主代理判定留痕 + 修订后夏栎逐位零回退）③疑似另立家族契约（停机问用户）——三档判定与实证记档；细长叶 SDF 可行性预判；嫁接口径干形（若 Spec 承重）建模判定。
- **Step 2 参数化**：`tree/salix/salixShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注；垂枝域字段若触发修订按 D31.2 留痕）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量（垂幕长度/垂坠度/冠幅比为预期差异主轴）。
- **Step 3 几何（procedural-asset-agent）**：`tree/salix/salixGeometry.ts`——方法复制 + 垂柳算法细节（垂枝挂点语言按 Step 1 判定路径/冠形干形按 Spec）；LOD 三档同流；入口 `assets/asset_tree_salix.asset.ts`（meta 同契约）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/salix/salixMaterials.ts`——狭披针形细叶 SDF（长宽比极端叶形——最小扩展限定文件内、记缺口候选）+ 缘细锯齿载波（高频细齿）+ 羽状脉 + 叶色黄绿调 + 背光透射（细叶高透）+ 风动两层（细枝垂帘摆动——频率/幅值按悬垂结构特性）+ 树皮配方（按 Spec 定位）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/salix/salixStage.ts` 同构 + bootstrap `window.__salix`；VIEW_TARGET_Y 几何实测定档（垂枝冠心偏低预期）；缺口 D 评估。
- **Step 4 视觉验证（验证子代理，D35）**：三必做（①身份判定：垂枝垂帘姿态读出（中距剪影）+ 细长叶近读 + 冠形 + 树皮；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.12/`；③缺口记档归 011.13——垂枝域实证为族门收口关键输入）+ 疑点触发（垂幕动态（风动下垂枝摆幅/频率三证据）/细叶远距读向（细叶冠面纹理 vs 稀疏缺陷判读）/console/LOD 档间）；校准默认一轮、两轮封顶；冲突主代理仲裁、像素为准。
- **测试**：对称 platanus 组织（tests/runtime/procedural/tree/salix* 五件）。
- **验收基线**：预算 = 家族行；先例与 GLB 零变化。
