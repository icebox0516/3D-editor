## Goal

双档性能验收（D10）+ 七项观测报表 + 范围门判定（D27）——「性能希望」变「性能治理」的最终取证。

## Requirements

- **园区档**：≤ 2 万散布实例、核显 1080p 连续渲染 ≥ 30fps
- **城市档**：≤ 10 万散布实例、独显 ≥ 30fps；压力场景入独立测试资产（可复跑，不依赖 T003 样式链解冻，D27.11）
- **七项观测报表（D27.9）**：FPS / frame time p95·p99 / draw calls / triangles / visible instances / LOD 分布（各档实例数 + 各档桶数双口径）/ 各 Representation 桶数；GPU 耗时有则记录不做成承诺；renderLoopStats 保持零 THREE 零 DOM 边界
- **范围门判定（D27.3）**：城市档 triangles / draw calls / frame time p95 任一超预算 → Impostor 升级必做，结论写进完成记录并立项后续
- **对照组（D27.13）**：同场景 LOD 开/关对照留档；不回溯 009.7 基线
- **回归**：三重门槛 + 基线对账；LOD 关闭形态与 T003 验收结果对比（无退化）

## Acceptance
