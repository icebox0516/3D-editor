# T004 Style Gallery

## Goal

可视化样式画廊（D14）：缩略图卡片网格替代文字下拉——按要素类型过滤、悬停实时预览、点击应用，成为需求一「选预设样式」的核心交互。

## Requirements

- **画廊面板**：缩略图卡片网格，按要素类型分组/过滤（选中绿地区域 → 只显示绿地可用样式 + 通用样式）；搜索/分类能力与资产浏览器对齐
- **悬停实时预览**：悬停卡片 → 选中区域临时应用该样式效果（预览态，可丢弃、无闪烁）；移出 → 恢复原样式；预览不经命令不入历史
- **点击应用**：经命令落地（可撤销）；与 Inspector 参数区联动一致（应用后参数覆写表单刷新）
- **缩略图管线**：每预设以样例几何离屏快照生成缩略图 + 缓存；新增预设自动生成
- **入口（默认假设 1）**：资产浏览器区域双 Tab（资产 / 样式），不新开独立面板

## Scope

- 新建：画廊组件 + 预览态管理 + 缩略图生成管线
- 预期触碰：资产浏览器容器（双 Tab）、样式注册表元数据（缩略图键）
- 依赖：T003 交付的绿地样式（画廊有内容可显示；既有 24 套预设同步收录）

## Acceptance

- 40+ 预设浏览流畅（滚动/过滤/搜索无卡顿）；悬停预览无状态泄漏（快速划过多个卡片场景一致）
- 应用经命令可撤销；画廊 ↔ Inspector 双向一致
- 缩略图首次生成后缓存命中（二次打开零生成）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- UI 任务先读 frontend-design 技能；视觉遵循 `src/ui/styles/` 设计系统；图标 lucide-react
- 预览态严禁旁路命令系统落地任何持久变更
