# T002.2 资产库混排 + 缩略图

> 归属：[T002 Procedural Assets](002-procedural-assets.md) ｜ 状态：**done（2026-09-16）** ｜ 前置：T002.1

## Goal

ContentBrowser 对程序化资产一视同仁（D7/D13）：GLB 与程序化同库混排显示，分类/搜索/标签/收藏全覆盖；缩略图管线支持程序化源离屏快照。

## Requirements

- **混排显示**：浏览器按统一 AssetDescriptor 渲染条目，GLB 与程序化混排（可选角标/图标区分 kind，不做功能隔离）
- **元数据功能覆盖**：分类聚合、搜索（名称/标签）、标签芯片、收藏对程序化资产同样生效
- **缩略图管线**：程序化源离屏快照——渲染 build 产物 → 缓存（与 GLB 缩略图同形态：内存 + 持久两级）；新增资产自动生成
- **失败降级**：生成失败 → 占位图 + 提示，不阻塞库浏览

## Scope

- 预期触碰：ContentBrowser 数据源（读统一描述符）、缩略图缓存管线（程序化源分支）
- 明确不做：放置（002.3）、其余 4 个设施资产（002.4）

## Acceptance

- 冒烟资产在库中可见、可搜索、可收藏；缩略图正确且二次打开缓存命中（零重生成）
- GLB 资产浏览/缩略图回归零变化
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- UI 遵循 `src/ui/styles/` 设计系统；图标 lucide-react
- 缩略图快照复用既有离屏渲染设施，不新增第 5 个常驻 WebGL 上下文（按需懒建同前例）
