# T010.2 元数据与分类契约

> 归属：[T010 程序化资产公共能力与规范](010-asset-capability.md) ｜ 状态：**not-started** ｜ 前置：T010.1

## Goal

公共资产元数据只扩分类维度，为 T016 资产管理器「大类 → 小类/族 → 具体资产」浏览铺路；植物语义不得泄漏进公共协议。

## Requirements

- **公共层（AssetDescriptor）**：大类 enum（植物 / 建筑 / 车辆 / 自然 / 人 / 公共设施 / 设备 …）+ 可选 family（broadleaf / conifer / shrub …）；现有 11 个程序化资产归类映射（plant / facility / dev → 大类 + family）
- **植物语义隔离**：heightRange / crownWidthRange 等放 procedural 专属扩展（如 `proceduralProfile?: { heightRange?: Range; widthRange?: Range; }`）或 family 层元数据——crownWidth 等植物术语不得成为全局字段（消防车 / 建筑 / 湖泊 / 路灯不应被迫回答「冠幅是什么」）
- **资产管理器消费预留**：分类契约文档化（供 T016 直接消费），不实装任何 UI——非重做 Asset Runtime

## Scope

- 预期触碰：AssetDescriptor 类型、各资产 meta 归类、契约文档
- 不碰：UI、运行时行为

## Acceptance

- 大类 / family 枚举落型；11 资产映射完成且现有 UI 资产栏分组行为不变（或迁移方案经用户裁定）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 分类字段为浏览语义服务，不承载行为分支（渲染/放置行为不得按大类 if-else）
