## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 47(1):55（候选池强证据锚，自行复核原句）/FOC 优先；形态材质变体 → 真实照片（异系统交叉）。重点调研面：种定名（K. paniculata vs 复羽叶栾树 K. bipinnata——长江流域公园语境主力与「一回 vs 二回羽状」判据）；**复叶结构**（奇数羽状一回/不完全二回、小叶数（枚）、小叶形态（卵形/卵状披针形？长宽 cm、缘锯齿深浅/羽状脉）、复叶总长 cm、小叶着生间距——数值进参数须一手原句）；**夏花**（圆锥花序尺度、花色金黄、着生位（枝顶？）、花期 6–8 月生长季可见性、树冠整体观感——建模判定 + 若做的几何/材质最小表达）；**灯笼果**（蒴果膀胱状膜质、径 cm、果期、夏季后期可见性——记档口径）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；圆头形/伞形？）；树皮（灰褐纵裂？vs 七先例语言定位）；枝姿（开张/小枝细？）；叶色（绿/背面色差）。
- **Step 1 结构分析**：Spec → 六先例方法基线对照——可继承 / 改写 / Unknown；**复叶表达路径判定**（复叶卡 SDF 多小叶沿轴排布 vs 几何小叶分卡——预算/档间连续性/近景读出三判据评估，结论记档并映射实现面）；**夏花表达路径判定**（花序卡/几何簇/不做——以 Spec 建模判定为准）。
- **Step 2 参数化**：`tree/koelreuteria/koelreuteriaShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量。
- **Step 3 几何（procedural-asset-agent）**：`tree/koelreuteria/koelreuteriaGeometry.ts`——方法复制 + 栾树算法细节（复叶挂点语言按 Step 1 判定路径/冠形/枝姿按 Spec；花序若做参照悬铃木果序先例账目法）；LOD 三档同流；入口 `assets/asset_tree_koelreuteria.asset.ts`（meta 同契约）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/koelreuteria/koelreuteriaMaterials.ts`——**复叶 SDF**（多小叶沿轴排布——rachis 轴线 + 小叶包络窗序列；或按 Step 1 判定分工——最小扩展限定文件内、记缺口候选）+ 小叶缘齿/羽状脉 + 叶色 + 背光透射 + 风动两层（复叶整体摆 + 小叶颤双层——若框架内可表达）+ **花序材质**（若做：金黄花簇卡面/简色）+ 树皮配方（按 Spec 定位 vs 七先例）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/koelreuteria/koelreuteriaStage.ts` 同构 + bootstrap `window.__koelreuteria`；缺口 D 评估（树皮门控判定）。
- **Step 4 视觉验证（验证子代理，D35）**：三必做（①身份判定：复叶读出（中距羽状复叶剪影/近距小叶排布）+ 夏花若做金黄花相 + 冠形 + 树皮；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.6/`；③缺口记档归 011.13）+ 疑点触发（复叶近景/远距质感读向（复叶 vs 单叶的冠面纹理差异——粗质中距读向是否成立）/花序若做可见性/风动三证据/console/LOD 档间）；校准默认一轮、两轮封顶；冲突主代理仲裁、像素为准。
