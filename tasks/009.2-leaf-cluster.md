# T009.2 夏栎叶簇生成

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**done（2026-09-18）** ｜ 前置：T009.1

## Goal

将末梢叶片从「随机叶卡」升级为枝梢驱动叶簇：枝梢 → 叶簇空间 → 叶片分布；外层密实成形、中层递减透枝、内层稀疏成腔、簇间有间隙——视觉从「叶片堆起来的树冠」转变为「多个叶簇构成的树冠」。

## Requirements

- **叶簇空间**：簇中心 / 簇方向 / 簇半径 / 簇密度 / 叶量 / 叶尺寸区间 / 朝向区间 / 外壳偏置（shellBias）——叶片沿簇壳偏置分布，内层自然稀疏
- **簇-枝梢绑定**：叶片与枝梢存在明确生长关系（簇挂枝梢、簇方向承接枝梢方向）
- **层次目标**：外轮廓完整 + 内部不填死 + 局部透枝 + 簇间间隙
- **共性标注**：实现中标注哪些参数为阔叶共性候选、哪些为夏栎特有（供 T010.1 提炼家族契约取证，本任务不做公共抽象）

## Scope

- 预期触碰：`broadleafGeometry.ts` 叶卡生成段重构（可拆夏栎私有模块文件）
- 不碰：契约层、材质工厂接口（aLeafRand / aBend 语义延续）

## Acceptance

- 近景叶簇可辨、冠内空腔透枝、外轮廓完整（T008.6 参考对照 + 用户裁定）
- aLeafRand / aBend 烘焙契约延续；结构计数测试锁更新；面数在合理量级（正式预算 009.6 锁定）
- 固定机位取证（近/中/远 × 树冠整体/局部）；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- **命名与实现均为夏栎私有**（「夏栎叶簇生成」，不叫公共 LeafClusterGenerator）——公共叶簇能力必须从真实第二个消费者中提炼（T010.1 评估），不在本任务预抽象
- 三重门槛全绿
