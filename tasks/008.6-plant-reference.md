# T008.6 夏栎视觉参考研究

> 归属：[T008 程序化树木](008-procedural-tree.md) ｜ 状态：**not-started** ｜ 前置：锚点门已过（与 T008.4 并行互不依赖——参考研究只做「真实夏栎 → 结构分析 → 参数规则 → 现代码对照」，不依赖放置链路；T009 等 008.4 与 008.6 双完成）

## Goal

为开发中的夏栎补建视觉参考基准（回溯性）：真实参考图 → 植物结构分析 → 参数化生成规则 → 与现有生成规则对照。作为 T009 结构升级的输入与验收基准。不推翻已完成的 T008.2/T008.3，只补基准资料。

## Requirements

- **参考图检索**：真实夏栎（Quercus robur 英栎系）代表性参考图 1–3+ 张，优先覆盖：整体树形/植株形态、枝干与分枝结构、叶簇/冠层结构、树皮与叶片等识别度局部特征；归纳真实结构特征而非模仿单张图片
- **参数化规则归纳**：从参考图转为程序化生成规则——高度与冠幅比、主干比例、分枝层级/方向/密度、冠层空间结构、叶簇密度、叶片方向与尺寸、树皮/叶片视觉特征、常见自然形态变化范围
- **现状对照**：与 `broadleafGeometry.ts`（LEVELS/TRUNK/CHILD_PLAN/LEAF）和 `tree3aMaterials.ts` 现规则逐项对照，输出「已符合 / 存在偏差 / 后续优化项」三栏表；每条偏差项映射到 T009.x 任务编号
- **留存链路**：保留「参考特征 → 程序化规则 → 最终实现」对应关系，供后续复查与扩展——本任务即未来所有植物 Reference Research 前置任务的范本
- **存放**：结论落 `docs/plants/tree3a-reference.md`；参考图本地副本沿用 `screenshots/ref-tmp/` 惯例（不入 git 资产）

## Scope

- 预期触碰：仅新增文档；零代码改动
- 不碰：任何源码、运行时资源

## Acceptance

- 对照表覆盖上述全部结构维度；每条偏差项可映射到 T009.x 任务编号
- 用户过目确认定调（参考基调 = T009 结构验收的对照基准之一）
- `npm test` / `check:layers` / `typecheck` 全绿（零代码改动应天然绿）

## Constraints

- 参考图仅用于视觉定调、参数制定、开发对照、固定机位验收；**不进产品运行时资源与代码契约**（D13 口径），不得作为最终模型/贴图/运行时数据依赖
- 禁止：没有参考直接凭经验设计植物结构；拿夏栎结构规则换颜色生成其他树种；仅以「像一棵树」作为植物真实性验收标准（三-A 通用前置约束）
