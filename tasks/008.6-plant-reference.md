# T008.6 夏栎视觉参考研究

> 归属：[T008 程序化树木](008-procedural-tree.md) ｜ 状态：**done（2026-09-18）** ｜ 前置：锚点门已过（与 T008.4 并行互不依赖——参考研究只做「真实夏栎 → 结构分析 → 参数规则 → 现代码对照」，不依赖放置链路；T009 等 008.4 与 008.6 双完成）

## Goal

为开发中的夏栎补建视觉参考基准（回溯性）：真实参考 → 植物结构分析 → 参数化生成规则 → 与现有生成规则对照。作为 T009 结构升级的输入与验收基准。不推翻已完成的 T008.2/T008.3，只补基准资料。本任务同时是 **asset-research 调研机制（D26）的首跑试点**：技能、植物域 Schema、Evidence Status / Spec Version 约定在此首次实战验证；**不作为后续资产任务的标准子任务结构**（D26：调研永不立子任务，后续资产走 Research Gate 规则触发，不立 `.6` 式调研子任务）。

## Requirements

- **参考检索**：真实夏栎（Quercus robur 英栎系）代表性参考，来源不限图片（园艺数据库/文献/百科/图库均可），数量按复杂度定；优先覆盖：整体树形/植株形态、枝干与分枝结构、叶簇/冠层结构、树皮与叶片等识别度局部特征；归纳真实结构特征而非模仿单张参考；每个核心结论可追溯（来源 + 检索日期 + 提取内容）
- **参数化规则归纳**：从参考图转为程序化生成规则——高度与冠幅比、主干比例、分枝层级/方向/密度、冠层空间结构、叶簇密度、叶片方向与尺寸、树皮/叶片视觉特征、常见自然形态变化范围
- **现状对照**：与 `broadleafGeometry.ts`（LEVELS/TRUNK/CHILD_PLAN/LEAF）和 `tree3aMaterials.ts` 现规则逐项对照，输出「已符合 / 存在偏差 / 后续优化项」三栏表；每条偏差项映射到 T009.x 任务编号
- **留存链路**：保留「参考特征 → 程序化规则 → 最终实现」对应关系，供后续复查与扩展——机制范本已沉淀为 asset-research 技能（D26），本任务为其首跑实例
- **植物域 Schema 首跑起草**：本任务起草 `.zcode/skills/asset-research/references/plant-schema.md` 草案（结构化字段——枝干 taper / 分枝角 / 着生密度 / 异速生长 p 值等；可对齐 threejs-procedural-vegetation 参数字段模式，但不被当前实现反向绑死），交主代理审阅合入
- **存放**：结论落 `docs/research/tree3a-reference.md`——按 `.zcode/skills/asset-research/references/spec-template.md` 通用骨架 + 植物域扩展节，顶部 Spec Version / Domain / Asset 头，关键事实标 Evidence Status（Verified / Inferred / Unknown），现状对照表作附录；参考图本地副本沿用 `screenshots/ref-tmp/` 惯例（不入 git 资产）
