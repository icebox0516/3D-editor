# T011.4 银杏全链（第四树）

> 归属：[T011 阔叶乔木族生产任务集合](011-broadleaf-trees.md) ｜ 状态：**done（2026-09-20 连续生产轮 011.4–011.13，D35）** ｜ 前置：T010 5/5 + T006 5/5（epic 级前置）+ 011.3 done（D30 增量口径一轮验证）；Step 4 按 D30 增量口径 + **D35 本轮外派口径（终审/视觉验证外派子代理、三门槛末轮统一跑）**

## Goal

银杏（Ginkgo biloba，银杏科银杏属——单科单属单种活化石）生产资产 `asset_tree_ginkgo`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证（身份判定 + 基线帧 + 缺口记档三必做，外派验证子代理执行）。**方法最远端实例**：扇形叶（SDF 全新叶形族——前四例全部是「卵形/披针形+锯齿/全缘」连续轮廓，扇形为辐射状裂片轮廓）+ 长短枝系统（叶簇生于短枝——分枝/叶簇挂点语言与前例逐级叶位不同）+ 冠形最特殊（幼年圆锥→成年不规则宽卵形，主枝不规则轮生）——继续发现并记档家族契约缺口（默认零修订、归族级验收门收口；阻塞缺口例外见 Constraints，D31.2）。

## Research Gate 判定（D26，开工前留痕）

- **判定：强制调研**。命中情形同前三树：①高真实要求（扇形叶/长短枝为银杏独有身份特征，辨识度判据全靠 Spec）；②类型显著影响形态（**全族方法最远端**——叶形/叶序/枝系统/冠形四重分化，换色复用 prohibited）；⑤资产将成同类生产基准。
- **执行**：通用子代理加载 asset-research 技能 → `docs/research/ginkgo-reference.md`；**Spec 终审外派独立校验子代理（D35）**：硬数值抽查（对照植物志原句）+ 关键照片第二视觉系统交叉（008.6 双问定名规程）、分歧取中庸记档。
- **Spec Version 锚点：1.0**——开发 Agent 开工前校验任务书引用版本与 Spec 顶部一致。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节（plant-schema v0.2）；两轴标注（Form / Evidence Status）；结构尺度 → 植物志（FRPS/FOC 优先），形态材质变体 → 真实照片直接视觉证据；Unknown 显式留档。重点调研面：种定名（单种无争议，但需公园语境**雄株口径**调研——城市绿化以雄株为主、雌株果臭）；**长短枝系统结构**（长枝螺旋排列叶 + 短枝簇生 3–8(–10) 叶——挂点语言实现面）；**扇形叶**（叶扇形上部宽 5–8cm、波状缺刻/2 裂程度个体差异、叶柄细长；**二叉分歧脉**——前五例脉型全部羽状/三出，扇形辐射脉全新）；**冠形发育**（幼树圆锥形→大树广卵形/不规则、主枝轮生斜展——中龄公园个体锚定哪个相）；树皮（灰褐色纵裂深浅 vs 四先例第五种语言？）；秋色金黄不建模（epic 语境为生长季观感——以 Spec 定）；雌雄异株形态差异（雄株冠形较瘦长？）。
