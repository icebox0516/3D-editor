## Goal

休憩四资产全链生产（simple-asset workflow 第二例批次）：**花箱 / 休闲桌（桌+凳组合位）/ 遮阳伞（中柱伞）/ 自行车架（槽位段式）**——园区休憩语境「画面血肉件」；候选文档 §1.2 批次（分类建议 `public-facility`）。验收口径 = 批 A 同款轻量但完整（Contact Sheet 批级 + 逐资产身份结论 ×4 + 冒烟），不重跑批 A 已完成项（D30/D31）。

**立项假设层身份预期（以 Step 0 Spec 为准，未经验证不写成既成事实）**：四件均为中国城市园区常见休憩设施——花箱（矩形为主形态，木/塑木/金属箱体 + 顶部土面）、休闲桌（金属框架 + 桌面，配连体或环绕凳位）、遮阳伞（中柱立伞，开伞态伞面 + 可见骨架，~~伞面常为鲜艳纯色~~ **假设层修正（Spec 终审采信 2026-09-29）：园区/商业外摆主流为素色（米白/卡其/墨绿/酒红），鲜艳色集中在广告促销语境**）、自行车架（地面固定弯管槽位段式，镀锌/彩涂钢）。

## 重点调研面

- **花箱**：主形态（矩形 vs 圆形常见度）与总尺寸带（长/宽/高）；壁厚与沿口形态（外翻沿/平沿）；材质相（防腐木/塑木/混凝土/金属烤漆——含木条拼接缝语义）；土面（顶部下沉深度、土色相、有无覆盖物）；底座形态（落地/垫脚/轮座）。**植被填充与植物族联动后置**（T014/T015 后）——本批只交付箱体+土面。
- **休闲桌（桌+凳组合位）**：桌面高/直径（或方桌边长）；凳位排布（四凳环绕 / 两侧连体 / 桌凳分离——组合位常见态）；桌面与凳面材质相（金属冲孔 / 木条 / 混凝土）；框架管径；与遮阳伞的中柱穿位关系（桌面中央开孔常见态）。
- **遮阳伞（中柱伞）**：伞径（开放态直径带）；柱高与柱径；伞面开度形态（八角伞面下缘弧线 / 骨架数可见性）；伞面与骨架分层（伞面/骨架/柱/底座）；**色相证据（preset 承重）**：市售遮阳伞面常见色系与使用语境（default 卡 + 副卡证据锚）；伞面摆动 = 风动候选（T005 联动，静态先行——动画位声明不丢失）。
- **自行车架（槽位段式）**：型制（高低弯管式 / 卡槽式 / 螺旋式——园区常见度）；单槽位间距与单车占位；段长（标准段几槽位）；管径与离地形态（入地预埋 / 法兰底座）；材质相（镀锌钢原色 / 彩涂）；停放姿态与 T026 自行车联动（停放语义记档，不建车）。
- 批级公共面：四件在园区休憩区的典型同框语境（休闲桌+遮阳伞成套放置 = 常见组合——供 Contact Sheet 场景参考与验收身份对照）。
