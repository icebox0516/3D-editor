## Goal

交通静态六资产全链生产 + workflow 首例双重职责：① **六件轻量资产入库**（防撞柱 / 人行护栏段 / 道路隔离栏 / 停车挡车器 / 交通锥 / 减速带——园区运营态「画面骨架件」，散布消费主力）；② **simple-asset workflow 首例验收**（轻量但完整——Contact Sheet 批级基线 + 逐资产身份结论 + 冒烟，D30 最低可信证据原则）+ 先例索引 `precedents/simple-asset.md` 首建；③ **交通锥 = 首个设施色卡消费者**（preset 红/黄——T024 消费链在设施域的首个实例，卡 id 域增补）。

**立项假设层身份预期（以 Step 0 Spec 为准，未经验证不写成既成事实）**：六件均为中国城市园区常见标准件——防撞柱（金属圆管 + 反光带）、人行护栏（钢管横杆段式 + 立柱）、道路隔离栏（网片/横管 + 底座，与人行护栏共型不同参）、挡车器（车位尾端弧面阻挡件）、交通锥（锥体 + 底座 + 反光环，红/黄两色相）、减速带（黄黑段式弧面条）。

## 重点调研面

- **防撞柱**：总高 / 外径 / 壁态（单管常见规格）；反光带位置与配色（高强级反光膜常见做法）；基座形态（膨胀螺栓法兰 / 预埋）；本体色（碳钢黑 / 不锈钢原色 / 黄黑）。
- **人行护栏段**：标准段长 / 高度带 / 横杆数与排布 / 立柱截面与间距 / 底座形态；涂装主色（城市人行护栏常见色系）；与人行道边缘的安装语境（贴地 / 立柱底座）。
- **道路隔离栏**：段长 / 高度带 / 结构型（横管式 / 网片式 / 折叠式）；底座（分离式混凝土/钢底座 vs 一体）；涂装（白红 / 白蓝 / 灰白常见配色与分带方式）；与人行护栏的「共型不同参」差异轴（高度 / 网片 / 底座）。
- **停车挡车器**：长 / 宽 / 高与弧面形态（橡胶一体 / 混凝土 L 型）；安装位（车位尾端距线距离量级）；配色（黑黄 / 全黄 / 混凝土原色 + 黄条）；固定螺栓位是否可见。
- **交通锥**：锥高常见档位与公园/停车场语境选档；底座形态（方形 / 圆形，一体 / 套装）；反光环/带位置与道数；材质相（PVC/EVA 表面质感）；**色相证据（preset 承重）**：红相与黄相的常见度与使用语境（两卡证据锚）。
- **减速带**：单段长 / 总宽 / 拱高；端头形态（斜切收边 / 端帽）；黄黑相间方式（整体黄黑 / 黑体黄警示条）；表面形态（实面 / 棋格纹）；橡胶/铸铁材质相。
- 批级公共面：六件在城市园区照片中的典型同框语境（供 Contact Sheet 场景参考与验收身份对照）。
