## Goal

设备 P1 三资产全链生产（simple-asset workflow 第三例批次）：**监控摄像头（杆装枪机）/ 交流充电桩（落地式）/ 井盖（圆形检查井盖）**——园区运营态设备语境「画面骨架件」（候选文档 §2.A P1 项）；井盖为地面族主力散布件。验收口径 = 批 B 同款轻量但完整（Contact Sheet 批级 + 逐资产身份结论 ×3 + 冒烟），不重跑批 A/B 已完成项（D30/D31）。

**立项假设层身份预期（以 Step 0 Spec 为准，未经验证不写成既成事实）**：三件均为中国城市园区户外常见设备——监控摄像头（热镀锌/喷塑灰白立杆 ≈3.5–6m + 末端横臂/抱箍 + 白色枪机筒壳 + 遮阳罩，杆内走线无明线主流）、交流充电桩（落地钣金柜体，白/绿主色调 + 正面黑屏 + 枪座挂枪 + 线缆弧线）、井盖（球墨铸铁圆形 Φ600–700 主流档 + 框缘微凸出地面 + 网格/铸纹面 + 字样槽）。

## 重点调研面

- **监控摄像头（杆装枪机）**：立杆高带（园区/道路监控立杆常见带，预期 3.5–6m——Spec 定锚）与杆径（等径/锥度）；横臂长与安装态（末端下挂/侧伸）；枪机壳体形态（筒形 + 遮阳罩护罩 + 镜头端朝向）；支架/抱箍形态；材质相（杆热镀锌原色 vs 喷塑灰白、机壳白/米白、遮阳罩同色）；红外/补光窗相；线缆走位（杆内走线 = 无明线主流预期）。
- **交流充电桩（落地式）**：箱体三围带（宽×深×高，7kW 落地交流桩主流档——Spec 定锚）；操作屏面位置与占比（正面/斜面）；枪座位置与充电枪形态（侧面挂置主流预期、枪体轮廓、线缆弧线走向）；指示灯带/品牌面相；材质相（钣金烤漆主色 + 屏黑面 + 枪体黑/灰 + 国网绿装饰带证据）；底座形态（落地基座/膨胀螺栓法兰）。**直流快充不在本批**（裁定 1）——直流若立项按中等独立子任务（道闸先例），调研稿不混写。
- **井盖（圆形检查井盖）**：盖径主流档（市政 Φ700 / 园区轻型带——Spec 定锚，GB/T 23858 规格系列预期锚）；框缘高出地面量（毫米级常见带）；盖面纹样形态（网格纹/铸铁花纹/字样槽「污水/雨水/电力」——纹样语义裁定 5）；框形态（法兰宽框/窄框）；材质相（球墨铸铁灰黑单相预期）；放置语义（贴地 min 凸起圆盘，井室不建模）。
- 批级公共面：三件在园区设备语境的典型同框（停车场充电位 + 出入口监控杆 + 路面井盖）——供 Contact Sheet 场景参考与验收身份对照。
