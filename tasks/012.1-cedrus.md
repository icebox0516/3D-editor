## Goal

雪松（Cedrus deodara，松科雪松属）生产资产 `asset_tree_cedrus` 全链，兼四个首例职责：① **ConiferShapeProfile 家族契约草案创建**（D37.2——字段全部有真实消费点、全标【家族共性候选】，数值依据全留本资产 config）；② **conifer LOD 预算候选带实测锁定**（lod-spec §5.3，锁定后回写 §5.2 表）；③ **`precedents/conifer.md` 先例索引首建**（真实消费者触发建库，D36 第 8 条）；④ 针叶形态语言首证——针叶簇 SDF / 尖塔形冠 / 层状平展枝姿均无阔叶先例直接复用，契约草案字段按雪松真实需求建（首例「修订」= 草案创建本身，无 D31.2 阻塞概念）。

**立项假设层身份预期（D37.3——以 Step 0 Spec 为准，未经验证不写成既成事实）**：常绿大乔木；树冠尖塔形；大枝平展、小枝下垂（姿态身份核心）；针叶在长枝螺旋散生、短枝簇生；球果直立、翌年成熟；树皮深灰鳞状块片。中龄公园个体体量预期高于阔叶族锚（≈15–25m 量级假设，Spec 承重）。常见度证据（候选池 §2 已验证）：FRPS 7:200 全国主要城市广泛栽培作庭园树。

## 先例基线

→ [docs/procedural-assets/precedents/broadleaf.md](../docs/procedural-assets/precedents/broadleaf.md)（conifer 族内无先例——跨族方法复制，本任务同时首建 `precedents/conifer.md`）：**长短枝双挂点（莲座簇卡 + 散生卡）→ ginkgo**（机制直接继承——银杏短枝莲座簇与雪松短枝针簇结构同型）；**圆锥窄冠角度梯度法 → ginkgo**（尖塔冠底法）；**两段 scaffold 分层角 → bischofia**（层角梯度参考）；**末级垂枝 upturn 负链 + lengthRatio 加长 → salix**（层缘垂帘机制）；**两层风动 + 树高锚同步轮 → sophora**（机制继承、锚值换 15–18m）；**花果零 rng 账目法 → koelreuteria / platanus / ligustrum**（球果账目改写位——直立姿态 + 两类果色）。阔叶两面色差 / 缘齿载波语言不适用（针叶辐射着生无两面差）。索引只导航，方法细节回原任务书 / 原 Spec。

## 重点调研面

- **种定名与身份**：Cedrus deodara 中名口径「雪松」；城市语境「雪松」俗名混淆面（云杉/冷杉误称——公园语境定名判据）。
- **层状平展枝姿（姿态核心承重）**：大枝平展/近轮生的分层结构——枝层数 / 层间距 / 层角（平展角域）；小枝下垂姿态（下垂长度/角度）；幼树vs成树冠形变化（幼树尖塔→成树宽塔/平台顶？——中龄个体形态判定承重）。
- **尖塔形冠与体量**：中龄公园个体树高 / 冠幅 / 干高（≈15–25m 立项假设锚定）；冠幅比（尖塔冠预期窄于阔叶）；轮廓读向（顶部尖削度 / 基部宽度）。
- **针叶**：长度 / 粗细（横截面形态）；长枝螺旋散生 vs 短枝簇生的密度账目；色相（灰绿 / 蓝绿 / 银灰调——雪松灰绿叶色身份）；两面色差。
- **球果**：直立着生位置 / 大小 / 形态（卵圆柱形？）；成熟周期（翌年成熟——**生长季可见性承重**：中龄树往年球果宿存量级，时窗错位判据输入）。
- **树皮**：深灰色、裂成不规则鳞状块片——vs 阔叶 14 语言谱系定位（独立语言位预期）。
- **一年生小枝色**：常绿树小枝色承重（淡黄褐 / 灰绿？）。
- **常绿叶色季相**：presets 证据面——常绿针叶预期无季相卡（default 单卡终态候选，Spec 记档确认）。
- **风动读向**：层状冠 + 针叶簇的摆动特性（整层摆 vs 簇颤——风动两层参数档位输入）。

3. **表示链**：出生即声明 canopy（乔木标准链 High → Mid → Canopy → Culled，阔叶 13 树现状同构）——冠层场消费共享 ClusterRecord 契约、冠色进 `CROWN_PRESETS` 同源 + drift-lock、canopy 深度/风动/受光按 representation-runtime §六原样消费；conifer canopy 经 BroadleafCanopyProxy 统一实现派生（禁止每树种自建远景冠层算法——proxy 侧若需改动 = 公共能力变化，走公共回归记档，本任务预期数据驱动零改动）。
4. **presets（D44）**：出生即带必填声明；预期 **default 单卡**（常绿、无季相证据不建卡——Spec 确认后记档终态）；`assetColorPresets` 整表锁 EXPECTED_PRESETS 加行。
5. **先例基线 = 跨族方法复制**：conifer 无族内先例——Step 1 经 `precedents/broadleaf.md` 导航读阔叶方法基线（几何管线〔scaffold/growBranch/簇挂点/卡账目〕、材质管线〔SDF/载波/透射/风动/深度材质/键分档〕、测试组织、Stage 同构），方法复制 + 针叶形态语言改写；**阔叶 13 树与家族契约零触碰（零回退基线）**。

**Step 1 判定记档（2026-09-29 主代理——依据 Spec 1.0 含终审修正口径）**：

1. **层状轮生骨架表达路径（身份核心）：跨族方法复制 + 骨架语言层状改写**——`cedrusGeometry` 私有自建（tree3a growBranch 递归 / 簇布点 / 卡挂点算法骨架复制），挂点语言按雪松改写：**scaffold 挂点按层位量化路由**（近轮生成层、6–8 主层、层间距 ≈1.5–2m 算术推断 Step 2 探针验证）+ **层角梯度**（下部层近水平 60–90° → 上部层上举 30–60°，自垂直角）+ 层板升扇/拱形轮廓（外缘先平后微垂下卷）+ 末级细枝垂帘（upturn 负 + lengthRatio 加长——salix 机制）+ **顶梢专路下垂点头**（leader droop——近景身份读向）。**BroadleafShapeProfile 与 tree3a 零触碰**（conifer 契约草案从零建字段，无 D31.2 阻塞概念——雪松即草案第一消费者，D37.2）。风险留档：层位量化与 rng 流的确定性兼容（挂点消费次数跨槽恒等纪律照走）Step 2 锁定。
2. **针叶表达 = 簇卡语言**：短枝**莲座簇卡**（15–25 针放射 SDF——新形态语言，最小扩展限定文件内、记缺口候选）+ **长短枝双挂点直接继承**（ginkgo 机制：短枝莲座簇卡 + 长枝散生针卡）；LOD 降档 = 簇卡针数递减（Low 档近似星点）。
3. **冠形 = 层叠尖塔**：ginkgo 角度梯度法为底 + **层叠外缘改写**（层板轮廓串联、非光滑圆锥面；基部最宽 + 上 1/4 渐尖）+ **层间天光缝隙**（簇布点按层聚集 + 层间空带——vs 阔叶外密内疏模式分化，层隙观感带 ≈0.15–0.3 探针定档）。
4. **球果：做（账目法）**——时窗判定：翌年 10 月熟 = 常年带果，9–10 月主语境全覆盖两类并存（将熟绿-转褐 + 当年幼果淡绿），显著性成立（7–12cm 大型果 × 单枝 2–4 × 全冠数十枚量级；vs bischofia 幼果低于显著性不做的反向先例）；账目 = 层板外缘结果枝带 + posHash 确定性布点（ligustrum/fraxinus 账目法改写：**直立**桶形 + 两类果色 + 宿存中轴留枝淡入）；全冠绝对量级 Inferred——Step 2 探针定档。
5. **树皮新语言位**：中小尺度**鳞状方块片系**（3–8cm 方-长方板块 / 沟浅-中近黑 / 块顶浅灰褐 / 暗灰-灰褐基、不剥落、幼树光滑渐开裂发育序列）——阔叶谱系（13 语言至 salix）后独立新位，序号按完成记录口径顺延。
6. **针叶材质**：灰绿-蓝绿-银灰粉调基色（身份）+ **阳银荫深受光色差**（crown-b 承重）+ **无两面色差**（针叶辐射着生——与阔叶两面色差语言分化）+ 幼叶白粉→老叶深绿叶龄梯度（域内变体非季相卡）+ 气孔线白粉为银灰调来源（工程映射注释）；透射：针簇细密高透预期（家族透射值域链上带试探，Step 3b 定档）。
7. **风动两层**：整层低频慢摆（层状大枝 massive）+ 层缘垂帘 / 针簇高频颤（末级细柔）+ 顶梢明显摆幅（三成分——salix 频率档法扩展位）；**树高锚同步轮换锚 15–18m**（阔叶 8–12m → 1/实测树高重锚，测试锚断言同步）。
8. **presets 终态：default 单卡**（Spec 正面证据：FRPS 终年常绿 + NC State 无秋色字段阴性 + 冬季三点照片直证；年内新梢白粉调 = 叶龄域内变体、非季相卡——D44 无证据不建卡的正向应用）。
9. **slot-0 锚 = 开阔孤立中龄型**：树高 ≈15–18m（Spec 生产锚）、冠幅比 ≈0.4、干高 ≈0.25、6–7 层（Spec §6 建议；Step 2 探针涌现回调）；8 槽变体主轴预期 = 树高 12–20m × 冠幅 0.3–0.5 × 干高 0.1–0.4 × 层数 6–8 × 幼树密贴-中龄层展-成熟宽塔年龄轴。
10. Unknown 留档：老树平台顶极端态（不消费）、全冠球果绝对量级（探针定档）、层间距绝对值（算术推断——探针验证）。

改写映射实现面：几何 = 层状量化挂点 + 层角梯度 + 层板升扇 + 末级垂帘 + 顶梢专路 + 簇卡挂点（长短枝双挂点）+ 层隙布点 + 球果直立账目；参数 = ConiferShapeProfile 草案全字段按 Spec 数值（层结构 / 冠形 / 枝姿 / 针叶 / 器官 / 干形 / 树高锚）；材质 = 莲座簇卡 SDF 新语言 + 灰绿蓝粉调 + 无两面色差 + 受光色差 + 树皮新语言位 + 球果材质 + 风动两层。
