# T008.2 树几何生成器 · slot-0 锚点形态

> 归属：[T008 程序化树木](008-procedural-tree.md) ｜ 状态：**done 2026-09-17** ｜ 前置：T008.1（契约基建可用）

## Goal

`asset_tree_3a` 阔叶树的 CPU 几何生成器——morphRng 驱动拓扑 → 枝干 → 叶簇布点 → 叶卡片烘焙，交付**可复现的 slot-0 锚点形态**（本任务只做这一个形态；8 槽扩展在 008.5）。

## Requirements

- **可复现基准（本任务的核心交付语义）**：固定 `shapeSlot = 0`、`morphRng = mulberry32(hash32(assetId ∥ 0 ∥ 'morph'))`（008.1 纯函数）、生成参数固定于代码（相机无关）——**每次 build 同槽逐位一致**，008.3 调材质时看到的永远是同一棵树，视觉定调才有基准
- **meta**：`shapeFamily: { size: 8 }`（类型不写死，本资产配置）；`triangleCount` 实数声明
- **拓扑生成**：分枝递归/层级结构（3–5 级），枝角度/长度/曲率自然分布，主干到枝梢的锥度连续，树冠体量与空隙自然（中距离剪影目标：不规则但可信的阔叶树冠）
- **叶簇布点**：枝梢与冠外层密度分布，叶卡片朝向/尺寸抖动（aLeafRand 驱动）
- **叶卡片烘焙**：四边形烘进**单一合并几何**（树皮/叶恰 2 材质组，层内合并免组膨胀——沿 D15 植物惯例）；`aLeafRand`（逐叶随机：色相/透光/大小变奏源）、`aBend`（弯曲刚度 = 离枝距离/高度权重，风动幅度源）**一次定义冻结——属 Source 固有数据，不读取对象 seed**（D19.6；008.3 只消费不修改此契约）
- **初始目标预算（非验收门槛）**：枝干约 1.5–3 万面、叶卡数千级——最终数量以 008.3 锚点阶段固定机位观感与性能实测共同裁定，不预设硬上限绑架视觉
- **材质占位**：基础 MeshStandardMaterial（观感归 008.3）；原点底部中心 minY≈0（GLB MODEL_BASE_HEIGHT 语义对齐）；每次 build new 全部资源（D17 所有权惯例）
- **DEV 出图面**：`window.__tree3a`（build slot-0 + 场景直挂 + 转台参数），供 008.3 前的剪影自检与锚点取证驱动

## Scope

- 新建：`asset_tree_3a.asset.ts`（build 内部可拆 `tree/` 生成模块）
- 不碰：契约层（008.1 已冻结）、材质配方（008.3）、放置链路（008.4）

## Acceptance

- slot-0 锚点形态固定、逐位可复现（两次 build 几何逐属性相等）；生成器形态参数由 morphSeed 驱动、具备按 shapeSlot 扩展独立形态的接口（本任务不验收跨槽差异——8 槽跨槽差异统一在 008.5）
- aLeafRand/aBend 覆盖全部叶顶点、树皮顶点无该属性或恒等值；法线健康（无 NaN、包围盒有限）
- 剪影自检：DEV 出图 中/远距离树冠轮廓自然、无完美几何体感（顶点扰动/破碎轮廓在位）
- 预算报告入完成记录（实际面数/叶卡数 vs 初始预算）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 零外部模型（D13）；派发 threejs-expert；主代理 diff 审查
- 几何数据契约（属性名/语义/材质组结构）在本任务冻结——008.3 违约改动应被审查打回
