# T006.4 批次控制

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**done 2026-09-19** ｜ 前置：T006.3

## Goal

防「块 × 资产 × 档」批次爆炸：块尺寸自适应 + 远处合并 + 远距密度降级 + draw call 预算。

## Requirements

- **块自适应**：实例稀疏区域块自动合并（粗档下相邻同资产块合并批次）、密集区域可细分
- **远距密度降级**：远档块按比例抽稀实例（视觉可接受阈值内）
- **预算治理**：draw call 预算常量 + 超限运行时告警（状态栏/日志）；预算报表可取——LOD 分布双口径计数（各档实例数 + 各档桶数）提供归因数据（D27.9）
- **压力验证**：10 万实例压力场景下批次 ≤ 预算

## Acceptance

- 压力场景 draw call ≤ 预算留档；抽稀后远处视觉可接受（截图取证）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 降级只影响远处（近处全保真）；派发子代理 + MCP 取数验证
