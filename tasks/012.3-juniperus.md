## 立项选型记档（D34.2 四标准，主代理选型·用户观感复核窗口开放）

**选型 = 圆柏 Juniperus chinensis**（候选池剩余强 8：圆柏/龙柏/侧柏/白皮松/黑松/落羽杉/池杉/罗汉松）。四标准对照：

1. **证据强**：FRPS 7:362「为普遍栽培的庭园树种」+「各地亦多栽培，西藏也有栽培」——全国广布明文（候选池 §2 强档）。
2. **气候带匹配**：华北至西南全国（自生+栽培）——全国广布优先（现有组合：雪松全国 / 水杉全国广栽，圆柏补北方庭园主力位）。
3. **形态方法多样性增量（单树增量面最广）**：a) **鳞叶 = 族内叶型谱系唯一空位**（针叶✓条形叶✓鳞叶✗）且带**二型叶同株机制**（幼/刺叶 + 成/鳞叶并存——形态语言与材质双重增量）；b) **圆柱/卵圆冠 = 冠形谱系空位**（尖塔✓密锥✓宽伞层状✓圆柱✗）；c) **浆果状肉质球果**（被白粉、2–3 年熟）= 球果账目新形态（vs 雪松木质如烛 / 水杉绿果枯穗）；d) 后续龙柏共骨架基座（候选池注记——建模管线复用，增量成本最低）。反选记档：落羽杉/池杉与水杉同属近缘（圆锥冠+条形叶+落叶）——同质堆量正违反本标准；侧柏增量子集（鳞叶+阔圆锥，冠形与水杉密锥区分度低于圆柏圆柱冠）；白皮松/黑松针叶束与雪松长短枝机制略近（树皮增量强、留后续轮）。
4. **准入判据**：中龄公园典型单干针叶乔木 ✓（直立乔木型——铺地柏/沙地柏等匍匐变种不在本资产形态域）。

## 重点调研面

- **种定名与身份**：Juniperus chinensis 中名口径（圆柏/桧柏）+ 科属（柏科刺柏属——Sabina chinensis 旧口径变动）；公园语境混淆面（侧柏同域鳞叶——定名判据；龙柏为栽培变种基座关系）。
- **二型叶机制（表达路径承重——本任务最高优先）**：刺叶（针形、3 叶轮生、长宽、上面白色气孔带）vs 鳞叶（大小、交互对生、紧贴小枝、背面腺点？）；**成树叶型比例**（鳞叶占绝对主导的树龄拐点）；两种叶着生小枝的分域（幼树全刺叶？成树内膛/外围分域？）；小枝形态（直展/斜展、四棱/圆柱形、是否再分末级小枝系统）。
- **冠形与体量**：幼树尖塔 → 中龄/成年冠形（圆柱/卵圆/广圆？何时定型）；树高/冠幅/干高公园典型值（≈8–15m 假设锚定）；冠幅比（圆柱窄冠 vs 卵圆中等）；中龄公园典型个体判定；**骨架树与庭荫树体量差接受**（epic Constraints——圆柏预期低于雪松/水杉）。
- **骨架与枝姿**：主干通直性（圆柏主干常扭曲/通直？——干形字段输入）；大枝姿态（斜展上举？）与层性（轮生/不规则轮生/散生——vs 雪松层状平展 / 水杉对生轮生，族内第三骨架型候选）；枝基径与冠内密实度。
- **鳞叶色相与质感**：绿色/深绿色/翠绿色有光泽？；白粉有无（叶背/球果）；**两面色差有无**（vs 水杉温和两面差 / 雪松无——第三数据点）；受光色差读向。
- **球果（账目承重）**：浆果状肉质球果形态（径、近圆球形？）；**被白粉**（色相承重——蓝黑/黑紫+白粉）；熟龄（当年/翌年/第三年——**同树异年果并存判定**：肉质果宿存窗口）；着生位置（枝腋/小枝顶）；中龄公园个体宿存量级（vs 雪松如烛正向 / 水杉轻量偏轻——第三档位候选）；雄球花（黄色、观感可见性——雌雄异株注记）。
- **树皮**：色相（深灰/灰褐/淡褐？）与开裂形态（纵条裂/浅裂/片状？）——阔叶 13 + 雪松 14 + 水杉 15 后的**第 16 语言候选**。
- **风动读向**：密实圆柱/卵圆冠的摆动特性（整冠摇/末级小枝颤——成分档位输入）。
- **干基与根系**：干基形态（膨大？常态？）。

9. **slot-0 锚 = 开阔中龄狭圆柱型 ~8 m**（三整树槽谱系中位偏上 + 身份读向最强型 + NC State 窄冠域）：树高 ~8 m / 冠幅比 ~0.28 / 干高比 ~0.15 / 干基 ×1.15；8 槽主轴 = 树高 4–10 × 冠形双型（狭圆柱/卵圆）× 冠幅 0.2–0.6 × 干高 0.1–0.25 × 年龄轴（幼尖塔→中龄定型→老树阔卵）× 刺叶比例轴（幼态多刺→鳞绝对主导）。
10. Unknown 留档（Step 2/4 探针）：散生挂点连续冠的 M25 冠带绿落带（密实块状冠 vs 终值带关系）；绳状卡中距可辨性（细密纹理读向）；刺叶 minority 近景贡献（M8）；果点中距可见性（6–8 mm 亚像素——近景位为主中距点彩预期）；层位字段退化消费 vs 散生模式位的实现路径（Step 2 判定）。
