# T018.2 PMREM / IBL

> 归属：[T018 真实程序化天空与环境光照](018-real-sky-environment.md) ｜ 状态：**done（2026-09-23——park-shader-agent 显示强度 + threejs-runtime-agent PMREM 管线两步串行 + 主代理审查/复验/增量视觉验证）** ｜ 前置：018.1 done（SkyCore 双实例就绪——`bakeScene` 只含 bakeSky / showSunDisc 常闭 / 含云参数；三写入口 `applyAtmosphere/patchAtmosphere/setSunDirection` 即 PMREM 触发清单挂点，见 018.1 完成记录移交节）

## Goal

`bakeScene → PMREMGenerator.fromScene → scene.environment` IBL 全链落地：全仓 MeshStandardMaterial 资产（三树叶皮/路灯/Ground/GLB）**零材质改动自动获得环境光照与反射**；事务提交（新 RT 就绪 → 替换 → 旧 RT 释放）+ 自维护 owned/live counter；PMREM 触发清单锁定（**仅环境状态变化**）；IBL 侧旋钮 `scene.environmentIntensity` + 显示侧强度 Sky 材质 uniform 双落地（D29.13）。**Hemi 过渡态保留**（018.3 删——Hemi+IBL 叠加偏亮为已知中间态，不作本子任务视觉失败判据）。

## Requirements

- **PMREM 管线**：新增 runtime environment PMREM 模块——PMREMGenerator 实例挂 Renderer 生命周期（惰性构造一次，`clearEnvironment`/`dispose` 链释放）；`fromScene(sky.bakeScene)`（**禁止 fromScene(主 Scene)**——职责分离 D29.12）→ `scene.environment`；**虚拟相机 near/far 必须覆盖天空盒**（SKY_BOX_SCALE 9000 → 半边 4500 / 对角 ≈7794；`fromScene` 缺省 far 100 会把 bakeSky 整盒裁掉——实施 agent 核实并锁定参数记档）；sigma 取值记档（0 或小值压烘焙噪声）。
- **云参与烘焙**（D29.11/12）：bakeSky 含 cloud 参数（018.1 已就绪）——单测断言 bakeScene 内 Sky uniforms 云四参与 displaySky 同源 + `showSunDisc` 常闭；阴天参数下重烘 env 含云影响（单测/探针口径）。
- **事务提交**：新 RT 就绪 → `scene.environment` 替换 → 旧 RT dispose（epic 验收第 4 条确定性依据——自维护 counter 口径 owned/live 自定，测试可读）。
- **触发清单**：`applyEnvironment`（预设整组重建）内 bake 一次；SkyCore 三写入口变更 → 重烘（回调挂接 Renderer，018.4 DEV 面消费路径本子任务打通）；`cloudSpeed=0` 下 time 不构成触发源；**相机移动 / 模型变化 / LOD 切换禁止触发**——结构断言渲染循环（renderFrame 路径）零 PMREM 调用。
- **IBL 旋钮**：`scene.environmentIntensity`（three r163+ 内建）；初值常量默认 1.0（预设差异化终值 018.3/018.5）。
- **显示侧强度（D29.13）**：正式路径**禁止 `scene.backgroundIntensity`**（Sky 是 ENV_LAYER 网格非 background）；Sky 材质**仅 displaySky 实例**注入显示强度 uniform——默认 1.0 观感零变化，**bakeSky 不注入**（显示调暗不得连带 IBL 变暗）；注入点在 tonemapping/colorspace 片元块之前（辐射域调强度）；写入口挂 SkyCore（`setDisplayIntensity` 类，018.4/018.5 消费）；legacy fallback 场景级旋钮归 018.3。
- **过渡态边界**：Hemi 暂存（018.3 删）；本子任务不做 fallback 分支（初始化失败完整 legacy 回退归 018.3 事务式单一开关）。
- **dispose 全释放**：Renderer.dispose → PMREM RT（含旧 RT）+ PMREMGenerator.dispose + `scene.environment = null`，沿 clearEnvironment 现有链挂入；StrictMode 双挂载零泄漏（复用 environmentDisposal.test 循环计数模式）。
