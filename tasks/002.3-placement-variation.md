# T002.3 放置 + 烘焙式变体

> 归属：[T002 Procedural Assets](002-procedural-assets.md) ｜ 状态：**done（2026-09-16）** ｜ 前置：T002.1、T002.2

## Goal

程序化资产放置全链路 + 烘焙式实例变体（D6）：选中 → Ghost 预览 → 点击放置 → 连续批次 → 撤销重做；放置瞬间 seed 掷骰，变体烘进 transform / 实例色并随场景落盘。

## Requirements

- **源接入**：程序化源 provider 并列于 GLB 加载器注入实例化管线（Ghost 与正式放置同源）；Ghost 异步生成时占位先行（复用既有策略）
- **放置链路**：与 GLB 资产完全同语义——点击放置、连续批次合并撤销、删除、跨资产换绑
- **烘焙式变体（D6）**：放置时生成 seed → 按 meta 变体声明掷骰——缩放/旋转抖动**写进 transform**（Gizmo 所见即所编）、色相微差写 **instanceColor**（实例化池最小扩展暴露 setColorAt 通路）、seed 存 `ModelObject.asset.seed`
- **序列化**：`asset.seed` 可选字段增量放行，场景往返无损；同 seed 同结果（确定性掷骰）
- **变体 UI 最小面**：Inspector 不做变体编辑（seed 只读可见即可）

## Scope

- 预期触碰：实例化管线 provider 注入、PreviewManager Ghost 源分派、放置工具（seed 注入）、ModelObject 类型与序列化、实例池 instanceColor 通路
- 明确不做：变体参数编辑 UI、散布（T003）、LOD

## Acceptance

- 冒烟资产放置/移动/删除/撤销重做全通；Ghost 正常
- 同资产连放 20 实例：draw call 不随实例数线性增长（合批生效）
- 变体肉眼可辨（大小/朝向/色相微差）；同 seed 撤销重做后逐位一致
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 实例化池保持「源无关」：变体数据活在对象侧，池只消费矩阵与颜色槽
- three 只允许 `src/runtime` / `src/app`；渲染实现派发 `threejs-expert` 子代理
