# T010.3 LOD 声明规范固化

> 归属：[T010 程序化资产公共能力与规范](010-asset-capability.md) ｜ 状态：**not-started** ｜ 前置：T010.1（可与 010.4 并行）

## Goal

程序化资产 LOD 声明与接入方式固化为规范（T009.6 落地能力的规范面）：统一 Asset Runtime 能力 + 家族预算制。

## Requirements

- **声明/消费契约文档化**：levels 按 meta 声明、level 独立缓存维度、sourceKey 形态身份不变口径
- **家族预算表规范**：T006.1 旧预算（粗 ≤300 / 中 ≤800 / 细 ≤2000，旧小植物尺度）按「家族分级」重写的依据与格式——每家族各档预算区间 + 实测锁定流程
- **T006 接缝文档**：资产侧（档位声明与几何交付）vs Runtime 侧（距离切换 / 分块消费）职责边界

## Scope

- 只产出规范文档与（如需的）类型注释；不改运行时行为

## Acceptance

- 规范可指导 T006.1 重写预算表与新资产声明 LOD；`npm test` / `check:layers` / `typecheck` 全绿
