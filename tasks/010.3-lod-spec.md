# T010.3 LOD 声明规范固化

> 归属：[T010 程序化资产公共能力与规范](010-asset-capability.md) ｜ 状态：**done**（2026-09-19） ｜ 前置：T010.1（与 010.2 / 010.4 可并行）

## Goal

程序化资产 LOD 声明与接入方式固化为规范（T009.6 落地能力的规范面）：统一 Asset Runtime 能力 + 家族预算制。

## Requirements

- **声明/消费契约文档化**：levels 按 meta 声明（Profile 首版最小化、不加无消费者字段，D27.12）、level 独立缓存维度、sourceKey 形态身份不变口径；**类型枚举三值 `'high' | 'mid' | 'low'` 定死**（D27.7）
- **Representation 语义集规范（D27.3）**：六档语义全集（High/Mid/Low/Proxy/Impostor/Culled）+ 不完整链支持；Proxy/Impostor 为规范预留位——不进类型枚举、未实装未验证（GLB Proxy 语义收录但标注「未经验证」）；Culled = 调度结果非声明档位
- **选档语义规范（D27.2/D27.5）**：归一化视距（张角）度量、正交退化口径、chunk 代表距离/scale 保守口径、hysteresis、选档评估器 domain 纯函数分层、档位每帧派生态（D27.6）
- **家族预算表规范**：旧口径（粗 ≤300 / 中 ≤800 / 细 ≤2000，003.4 旧小植物尺度，D23.3 已废）按「家族分级」重写的依据与格式——每家族各档预算区间 + 实测锁定流程
- **T006 接缝文档**：资产侧（档位声明与几何交付）vs Runtime 侧（选档/切换/分块消费/批次控制）职责边界；**真相源声明：本任务产出为 LOD 规范唯一真相源，`docs/lod-reference.md` 为归档输入材料（D27）**

## Scope

- 只产出规范文档与（如需的）类型注释；不改运行时行为
- 输入材料：`docs/lod-reference.md`（归档，D27）+ D27 裁定 + T009.6/006.2 落地事实

## Acceptance

- 规范可指导家族预算表落地与新资产（T011+ 各族）声明 LOD，T006 调度侧实施有据可依；`npm test` / `check:layers` / `typecheck` 全绿
