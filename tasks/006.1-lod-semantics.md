# T006.1 LOD 公共语义层

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**not-started** ｜ 前置：T009.6（level 契约与首个多档资产）

## Goal

LOD 公共语义层落地（D27.5/D27.12）：Profile 声明契约最小化口径 + 选档评估器 domain 纯函数 + Runtime 全局策略常量与 LOD 总开关语义。本任务不接渲染链（接链 = 006.3）。

## Requirements

- **Profile 最小契约（D27.12）**：沿用 `levels: [{id}]` 声明形态；不引入 screenSize / maxDistance / triangleBudget / castShadow / pickable 等无实际消费者的字段；调度阈值归 Runtime 全局策略常量，不进资产 Profile
- **选档评估器纯函数（D27.5）**：输入 = 纯数据（相机位姿 / fovY / 正交标志 + 资产包围球半径或 chunk 代表距离与代表 scale），输出 = representation 档位；落 `src/domain` 零 THREE（check:layers 强制），node 可测；支持不完整 LOD 链（资产只声明 High/Low 时跳档正确取最近已声明档）
- **度量语义（D27.2）**：归一化视距 d/r（张角）为主口径；正交退化口径（几何尺寸 / 正交视高）；阈值常量以候选值落地并显式标注「实测锁定前为候选」（D27 候选栏）
- **hysteresis**：档位切换阈值带迟滞，相机在边界附近来回不抖动换档
- **LOD 总开关语义**：全局开关（关 = 全 High）在本层定义，消费在 006.3
- **档位派生态纪律（D27.6）**：评估器无状态、结果每帧可重算，不缓存进持久状态

## Acceptance

- 评估器纯函数单测覆盖：透视/正交、迟滞环、不完整链跳档、开关语义、代表 scale 参与归一化
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 本任务不接渲染链、不改任何 Runtime 渲染行为；实现按 AGENTS.md「多 Agent 按 Step 派遣」执行（domain 纯函数属通用实现）
