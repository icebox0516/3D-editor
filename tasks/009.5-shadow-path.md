# T009.5 程序化资产公共 Shadow 能力

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**not-started** ｜ 前置：无 epic 内硬前置（可与 009.1–009.4 并行；汇入 009.7 验收）

## Goal

补当前真实缺口——**ProceduralSourceCache → InstanceSource → InstancedAssetPool → 正式场景**的生产 Shadow 路径：公共契约扩展 + 正式放置对象投影与叶形裁切。夏栎为第一个实际验证该公共能力的 Procedural Asset。

## Requirements

- **契约扩展**：InstanceSource 增可选 `customDepthMaterial?`（`customDistanceMaterial?` 仅类型位、零实装零消费，点光源影需求出现时再立项）
- **核心链接入**：InstancedAssetPool 4 处建网格（split 亮网格 / 单实例退化 / 主 InstancedMesh / 锚点装饰）挂载深度材质与 castShadow；dispose 语义同步（ProceduralSourceCache / ThumbnailCache / tree3aStage，防泄漏——「池不 dispose 共享模板」原则不破）
- **分口径（不绑成一个验收项）**：
  - **正式放置对象 = 必须支持 Shadow**（投影 + 叶形裁切）
  - **Ghost / Preview = 必须不破坏 Shadow 契约、不要求投影**（预览态不强求 castShadow，避免预览与编辑场景产生额外阴影干扰）
  - **ScatterChunkManager = 仅契约兼容验证**（类型通过、无行为破坏），不做新 Scatter 功能
  - **AssetLoader（GLB 端）= 类型兼容、零行为变化**（回归项非接入项）
- **aSeed 契约兼容实测**：aSeed 共享几何在散布 / Ghost 路径的实际渲染行为验证，修正 InstancedAssetPool 类头「其他网格材质不声明 aSeed」过时断言
- **池类头纪律（D23.6）**：修正过时断言时遵循「稳定契约留类头、实现事实落任务完成记录」——类头只保留 aSeed 必须 geometry 绑定 / 池不 dispose Source / Ghost 不走本池等稳定契约，不借机向类头堆新规则
- **夏栎首验**：tree3a 叶片 SDF 深度材质（现有 `createTree3aLeafDepthMaterial`）接入正式路径——DEV 预览 = 正式场景

## Scope

- 预期触碰：InstanceSource 类型定义、InstancedAssetPool（建网格 + 类头断言修正）、ProceduralSourceCache dispose、ThumbnailCache、AssetLoader 类型兼容、ScatterChunkManager 契约兼容行、tree3aMaterials / tree3aStage 挂载
- 不碰：散布功能开发（T003 冻结）、GLB 行为、散布侧 aSeed 同相位修复（留 T003 解冻后独立任务）

## Acceptance

- 正式场景（产品放置路径）夏栎投影正确 + 叶形裁切正确；DEV 出图面与正式场景影裁切一致
- Ghost 存在时 Shadow 契约无破坏（无投影要求，分开验收）
- GLB / 设施资产回归逐位不变；资源泄漏检查过（dispose 链完整）
- renderer.info 取证（Shadow pass 开销、draw call 变化）；`npm test` / `check:layers` / `typecheck` 全绿
