# T008.1 契约增量 + uTime 基建

> 归属：[T008 程序化树木](008-procedural-tree.md) ｜ 状态：**done 2026-09-17** ｜ 前置：无（本任务即 T008 地基）

## Goal

落 D19.2–7 契约增量与 uTime 全局服务——**纯基础设施，不生成任何树几何**；008.2 起直接假定基建可用，几何任务不得夹杂资产系统修改。

## Requirements

- **build 签名**：`ProceduralBuild = (params?: { seed?: number; preset?: string }) => InstanceSource`——旧资产 `build()` 天然兼容零改动（类型层面验证 + 全量存量资产测试不动即证明）；`preset` 仅协议扩展位，v1 无消费方；**`params.seed` 语义 = Source/形态 seed（morphSeed），绝非对象 `asset.seed`**（见下条契约第一锁）
- **meta 增量**：`ProceduralAssetMeta` 扩 `shapeFamily?: { size: number }`——类型不写死常量（size 是资产配置；asset_tree_3a 的 8 由 008.2 声明）；不建 enabled/performance 推测字段
- **三流域派生纯函数**（落 domain，零 THREE；mulberry32/hashString 已在 core/random）：`shapeSlotOf(seed, size)`、`morphRngOf(assetId, slot)`、`instanceRngOf(seed)`——域分离常量 `'shape'` / `'morph'` / `'instance'` 隔开，三流互不复用
- **sourceKey 与缓存**：`sourceKey = assetId[:preset]:slot-N` 组装纯函数（domain）；`ProceduralSourceCache.load(assetId, { seed?, preset? })` 的 `seed` 形参 = 对象 seed（仅供内部槽路由定 sourceKey），按 sourceKey 缓存；无参调用（无 shapeFamily 声明的资产）回退现状 `assetId` 键、行为逐位不变；缓存不淘汰
- **morphSeed 调用契约（契约第一锁）**：`asset.seed` 仅用于对象级派生（shapeSlot 路由 + instanceRng），**永不直接参与 Source Geometry 生成**——构建 Source 时由 `assetId + shapeSlot` 派生 `morphSeed = hash32(assetId ∥ shapeSlot ∥ 'morph')`（即 morphRng 的种子，D19.3），一律以 `build({ seed: morphSeed, preset })` 调用；不同对象即使 `asset.seed` 不同，只要 `sourceKey` 相同，传入 build 的 `morphSeed` 必须完全相同，因此 Geometry/Material 必须共享。链条：`asset.seed → shapeSlot → sourceKey ⇔ morphSeed → build({ seed: morphSeed }) → 唯一 Source`
- **路由层**：`AssetSourceRouter.provideInstanceSource` 带对象 seed → 槽路由到 sourceKey；Ghost 按 sourceKey 借缓存 Source、**不 dispose 契约原样保留**
- **池分桶**：`InstancedAssetPool` 池键从 assetId 升级 sourceKey（未声明 shapeFamily 的资产 sourceKey 退化为 assetId，行为不变）；**aSeed 实例属性**：对象存在 asset.seed 时写入桶 InstancedMesh 的 `aSeed` float 实例属性（GLB/旧资产不写或恒等值，材质未声明该 attribute 时零影响）——精度处理：种子哈希折算 [0,1) 再传
- **uTime 最小服务**（D12 拉前）：渲染循环维护单一全局时钟 + 广播——材质 uniforms 声明 `uTime` 即自动驱动；一期 `shader_test` 预设成为第二消费者验证；不做局部时钟、不做 JS 逐实例 tick
- **测试用参数化资产**：附一个极简参数化资产（如 seed 驱动的堆叠方块/锥，DEV 分类不入产品栏）验管线贯通——同 morphSeed 逐位同结果、异 morphSeed 异形态（build 级 seed 语义，不验对象 seed）、缓存共享

## Scope

## Acceptance

- 存量 9 程序化资产 + GLB 全量测试不动即绿（零破坏证明）
- 派生确定性：同 seed 三流结果逐位一致；`shapeSlot` 只随 seed 与 size 变、`morphRng` 只随 (assetId, slot) 变、`instanceRng` 只随 seed 变——交叉独立性单测锁定
- sourceKey 缓存：同 (assetId, slot) 二次 load 命中同实例；无声明资产回退 assetId 键
- **不同对象 seed → 同 sourceKey → 同 Source（硬测试，本契约核心证明）**：S1 ≠ S2 但均路由到同一 slot 时——sourceKey 相同、morphSeed 逐位相同、build 仅执行一次（第二次起走缓存）、Geometry 与 Material 同引用
- 池分桶：同 sourceKey 多实例一个桶；aSeed 逐实例写入且材质可读
- uTime：声明 uTime 的材质数值随帧推进；不声明者零开销
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- three 分层约束（派生/sourceKey 纯函数零 THREE）；派发 threejs-expert；主代理审查
- StrictMode 双挂载安全（缓存会话私有惯例沿 D17.4）
