- **Step 3 几何（procedural-asset-agent）**：`tree/camphor/camphorGeometry.ts`——方法复制 + 香樟算法细节（干形/冠形/枝姿/树皮起伏按 Spec 与 profile）；LOD 三档同流（同 rng 流 / Mid⊂High 掩码 / Low 簇位壳卡）；入口 `assets/asset_tree_camphor.asset.ts`（meta：taxonomy broadleaf / shapeFamily 8 / levels 三档 / triangleCount = slot-0 High 实数 / proceduralProfile 全槽实测带；build slot→profile 路由 + level 透传 + customDepthMaterial 契约通道）。

- **Step 4 视觉验证（主代理）**：固定机位取证（SOP §3 全机位 + LOD 档间 + 风动双帧 + macro 三机位 + 前例对照帧）+ 十项检查单逐项结论 + 像素判定（风动三证据）；取证落 `docs/acceptance/t011/011.2/`。视觉核验通道沿 011.1 记档：远程视觉模型不可用时走 Browser Use IAB 内联直验（占位帧三重校验）。
