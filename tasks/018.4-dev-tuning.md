## Goal

`__sky` DEV 调参面落地：Sky 四大气参数 / Cloud 四参数（**cloudSpeed 恒不暴露**——静态云语义锁定）/ 太阳角 / IBL 强度 / 显示侧旋钮实时调 + **PMREM debounce**（D29 裁决 Q6：禁止逐参数变化连续重烘）——为 018.5 视觉验收终调（四预设 provisional 值定稿、day/tech 过曝显示域压缩路径实操）提供工作台。DEV 面是浏览器控制台 API（bootstrap DEV 守卫，生产零痕迹），非 UI 面板（不承诺 UI，018.1 Scope 先例）。

## Requirements

- **PMREM debounce（D29 Q6，epic 验收第 5 条组成部分）**：debounce 层包在 **onParamsChanged 回调上游**（018.2 移交口径——传给 SkyCore 的回调即 debounced 版本；SkyCore 本层不感知，skyCore.ts 回调注已预留）；连续写入口调用（逐参/拖动场景）合并为**停手后恰一次重烘**；displaySky/bakeSky uniforms 由写入口即时同步（天空观感实时变，env 反射延迟一步——可接受且更流畅）；**调度器可注入**（node 单测同步口径，沿 LazyPmremBackend 工厂注入先例；生产 = setTimeout/clearTimeout）；**clearEnvironment / 环境切换取消 pending timer**（不跨环境触发——旧 pmrem 已 dispose 时 bake 短路安全，显式取消是确定性记档口径；句柄从 setupSkyEnvironment sky 模式结果带出，具体形态实施 agent 定）；「写入口变更后恰一次重烘」既有单测语义保持（同步调度器注入时立即执行——测试改注入面不改断言语义）。
- **Renderer 环境调参访问面**：sky 模式暴露最小调参端口（SkyCore 写入口代理 + 太阳角三一致封装 + IBL 强度写路径 + 强制重烘入口）；**太阳直射灯从 applyEnvironment 局部变量提升为 Renderer 字段**（`sunLight`——DEV 面调太阳角后同步灯位 = sunDirection × LEGACY_SUN_DISTANCE，三一致封装在 Renderer 不散到 DEV 面；释放链不变，灯仍在 envGroup 内经 disposeEnvironmentObjectTree）；**legacy/fallback 模式端口为 null**（单一开关不变式不破坏——fallback 态无 DEV 调参，D29.5）。
- **IBL 强度刷新路径（018.2/018.3 移交）**：DEV 面 setIblIntensity = 直写 `scene.environmentIntensity` + **触发 debounced 重烘**（three 0.186 直写不重传材质 uniform 的已知限制——environment 纹理引用变化触发 setProgram refreshMaterial 顺带重传 intensity；烘焙内容不变，重烘纯为刷新，单次 ~30ms DEV 可接受，记档模块注）。
- **`__sky` DEV 守卫**（bootstrap，`import.meta.env.DEV` 守卫 + 无 Renderer 不挂，沿 `__envProbe` 装配/卸载前例）：
  - 读：`params()`（atmosphere 8 参 + 太阳角 + displayIntensity + iblIntensity + 当前 preset 名）/ `pmremStats()`（owned/live/baked/retired——epic 验收第 4 条口径只读）/ `mode`（sky | legacy）
  - 写：`patchAtmosphere(partial)`（8 参逐项）/ `setSunAngles(elevationDeg, azimuthDeg)`（三一致：SkyCore + 双实例 sunPosition + 灯位）/ `setIblIntensity(v)`（上述刷新路径）/ `setDisplayIntensity(v)`（display-only 单侧——displaySky 即时生效零重烘，D29.13）/ `rebake()`（强制立即重烘，flush 语义——018.5 终调工具）
  - **接口无 cloudSpeed 键**（结构断言锁定——不暴露动态云入口，D29.11）；非法值显式抛错（setDisplayIntensity 既有 RangeError 语义透传）
  - 卸载清理（bootstrap unmount 段 `delete window.__sky` 前例）
- **DEV 调参不进任何持久化**：不触碰 SceneData / undo-redo / 预设表——调参结果为会话态，preset 切换（整组重建）即重置（预期语义，任务书记档即可）。
- **018.3 移交输入处置边界——day/tech 过曝**：本子任务**不裁 tone mapping**（D29.3 修订须用户裁定记 DECISIONS——ACES 实证 56% 画面改善证据在 `docs/acceptance/t018/018.3/README.md`，非本子任务决策面）；DEV 面的 displayIntensity/iblIntensity 旋钮即**显示域压缩路径的工具面**（uDisplayIntensity 已于 018.2 交付）——本子任务只保证旋钮可用可调，预设数值终调与过曝处置方案归 018.5。

## Acceptance

- debounce 单测（注入同步调度器）：连续 N 次写入口调用 → 恰一次重烘；pending 取消（环境切换后旧 timer 不触发新环境重烘）；setDisplayIntensity 零重烘（display-only 单侧）；同步调度器下「写入口变更后恰一次重烘」既有断言语义保持。
- 三一致单测：setSunAngles → SkyCore 状态 + 双实例 sunPosition uniforms + sunLight.position（= sunDirection × LEGACY_SUN_DISTANCE）同步断言。
- IBL 强度：setIblIntensity 直写值在读口径可见 + 触发 debounced 重烘（行为断言）；legacy 模式端口 null（单一开关不变式不破坏）。
- `__sky` 守卫：DEV 装配 / 生产零痕迹 / 卸载清理断言（bootstrap 前例口径）；接口结构断言无 cloudSpeed 键。
- Renderer 既有行为零回归：skyCore / pmremEnvironment / environmentSetup / environmentDisposal 既有测试全绿（允许注入面机械调整，语义断言不放松）。
- 三门槛全绿（`npm test` / `check:layers` / `typecheck`；基线 3997 / 597 / 零错）。
- 主代理增量视觉验证（取证 `docs/acceptance/t018/018.4/`）：DEV 面浏览器实测——快速连续写参数（模拟拖动）重烘次数 = debounce 合并口径（`pmremStats()` 证据）；day displayIntensity 压暗即时生效且 env 反射不随动（显示域压缩工具面可用性实证——018.3 移交验证点）；setIblIntensity 后画面实际变化（刷新路径实证）；太阳角调整天空太阳位 / 直射光向 / 影向三一致视觉核验。

## Constraints

- 派遣（D29.9 + AGENTS 路由）：**threejs-runtime-agent** 单步主力（Renderer / debounce / 生命周期 / bootstrap 装配 / 测试）；无 Shader 注入类改动（uDisplayIntensity 已交付，本子任务纯消费）→ 无需 park-shader-agent；主代理拆分派遣审查验收，不直接写渲染实现。
- Renderer 硬规则：dispose 无 forceContextLoss；每帧连续渲染不改；**PMREM 严禁进帧路径**（debounce 不得引入帧路径触发源——触发清单仍 = applyEnvironment 初烘 + 写入口 debounced 重烘 + setIblIntensity 借道 + rebake() 强制入口）。
- @types/three 滞后口径同 018.1–018.3：禁 any 扩散（D29.14）。
- `__sky` 为 DEV-only 取证/调参工具：不进 `src/ui`、不进产品状态流；接口注释注明 018.5 终调消费口径。
- 测试新面优先落 `tests/runtime/environment/`（debounce/端口）；bootstrap 守卫断言落 `tests/app/`（既有 bootstrap.test.ts 扩充）。
