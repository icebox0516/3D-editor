# T011.1 朴树全链（首树）

> 归属：[T011 第一批阔叶乔木](011-broadleaf-trees.md) ｜ 状态：**done（2026-09-19）** ｜ 前置：T010 5/5 + T006 5/5（epic 级前置，见 epic 头）

## Goal

朴树（Celtis sinensis，榆科朴属）生产资产 `asset_tree_celtis`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → 固定机位视觉验证。作为阔叶家族**第二实例（方法复制首跑）**，发现并记档家族契约缺口（增量修订归 011.5，本任务不修订契约）。

## Research Gate 判定（D26，开工前留痕）

- **判定：强制调研**。命中不得豁免六情形之：①高真实要求（SOP §2 树种辨识度以 Spec 身份/识别特征节为判据）；②类型显著影响形态（朴树 vs 夏栎：叶形卵形三出脉 vs 倒卵形裂片、干皮与冠形语言均异——换色复用 prohibited，SOP Step 0）；⑤资产将成同类生产基准（阔叶家族第二实例，后续树种照此复制）。
- **执行**：通用子代理加载 asset-research 技能 → `docs/research/celtis-reference.md`；主代理硬数值独立抽查 + 照片终审（008.6 返修规程：候选照片 URL 自 API JSON 提权威扩展名、两次独立视觉提问一致方定名）。
- **Spec Version 锚点：1.0**——开发 Agent 开工前校验任务书引用版本与 Spec 顶部一致。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节（`.zcode/skills/asset-research/references/plant-schema.md` v0.2）；关键事实两轴标注（Form / Evidence Status）；结构尺度 → 植物志（FRPS/FOC 优先），形态材质变体 → 真实照片直接视觉证据；Unknown 显式留档（影响生产决策的关键 Unknown 不得静默）。
- **Step 1 结构分析**：Spec → 夏栎方法基线对照表——算法可直接继承项 / 需按朴树改写项 / Spec Unknown 项（新资产无「现状」，以夏栎复制基线为参照系）；每条改写映射实现面（几何/参数/材质）。
- **Step 2 参数化**：`tree/celtis/celtisShapeProfile.ts`——BroadleafShapeProfile 全字段填朴树数值，逐字段 Spec 依据 + Evidence Status + 共性标注（【家族共性候选】沿用 /【朴树特有】新证据）；工程设定无现实基准的明确标注不编造；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量展开（009.3 语法）。
- **Step 3 几何（procedural-asset-agent）**：`tree/celtis/celtisGeometry.ts`——夏栎方法复制 + 朴树算法细节（干形/冠形/枝姿/树皮起伏按 Spec 与 profile）；LOD 三档同流派生（同 rng 流 / Mid⊂High 掩码口径 / Low 簇位壳卡）；入口 `assets/asset_tree_celtis.asset.ts`（meta：taxonomy broadleaf / shapeFamily size 8 / levels 三档 / triangleCount = slot-0 High 实数 / proceduralProfile 全槽实测带；build slot→profile 路由 + level 透传 + customDepthMaterial 契约通道）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/celtis/celtisMaterials.ts`——朴树叶 SDF（卵形 + 三出脉基部 + 叶缘齿——以 Spec 叶形节为准）+ 叶色双面区分 + 背光透射 + 风动两层（aSeed/aBend 契约字段沿用）+ 树皮配方（朴树皮型按 Spec，与橡树脊沟语言分化）+ 深度材质同源 GLSL + 9 键分档（customProgramCacheKey 档位唯一，High/Mid/Low × 皮/叶/深度）。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/celtis/celtisStage.ts`——mountSlots / view / mountLevels 同构夏栎（import.meta.env.DEV 守卫，生产零痕迹）。
- **Step 4 视觉验证（主代理）**：固定机位取证（SOP §3：N12/M25/F50/B25/BS22/SC15/L35/C7/T26/P42 按检查单适用项取用）+ 十项检查单逐项结论 + 视觉模型核验关键帧 + LOD 档间连续（三档 32m 全景 + 60m 远距）；取证落 `docs/acceptance/t011/011.1/`。
- **测试**：对称 tree3a 测试组织（tests/runtime/procedural/tree/celtis*）——结构（皮面数/rng 消费恒等/贴地）、LOD（三档不变量/预算带/掩码⊂）、Materials（SDF/分档键/深度同源）、ShapeSlots（8 槽差异/计数恒等）、Stage（DEV 守卫）；入口 meta/路由测试。
- **验收基线**：预算 = 家族行 High ≤40000 / Mid 6000–10000 / Low 1500–3000 实测带落带内；夏栎/GLB/旧资产零变化（既有测试全绿即证）。
