# T006.6 LOD 选档稳定基准（High 档派生）

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**in-progress 2026-09-20**（D28 收官后追加；Step 1 测试先行本会话执行，Step 2/3 排 T011 族建设后） ｜ 前置：T006.5（done）；Step 2/3 排期前置 = T011 完成后

## 背景（D28，2026-09-20 grilling 会话裁定）

用户检查 LOD 系统提出两项疑点，经事实探查 + 五题逐题裁定（DECISIONS.md D28）：

1. **选档基准现状 = 当前档位几何包围球**：两链一致——放置链 `InstancedAssetPool.frameLod` 取当前桶源 `pool.source` 的 `geometry.boundingSphere`（随迁档换源）；散布链 `ScatterChunkManager.frame` 按当前档位键取 `assetStates` 缓存半径。三档几何 bounds 实际不等（档间轮廓连续性容差 ≤0.4m，折算半径差 ~2-5%）——迁档后半径换源、m 读数平移的反馈环存在，但被 15% 迟滞带吸收，无观察病症（定性卫生债）。
2. **演进方向 = High 档派生的稳定资产级半径**（D28.2）：Runtime 在源解析时一次计算并缓存，两链恒用；**剔除不跟随**（逐桶视锥剔除继续用各档真实几何球——剔除用真实包围是正确语义）。
3. **测试先行（D28.6，Step 1）**：`InstancedAssetPool.lod.test.ts` 此前给三档硬 pin 同一 boundingSphere——假前提，不修则本任务改造无可证明的验收面。

## Goal

选档基准与当前渲染档位解耦：同一实例在任意档位下选档度量恒定，消除「迁档→半径换源→读数平移」反馈环；档间 bounds 差异不再影响选档。

## Requirements

- **Step 1 测试先行（本会话执行，验收见完成记录）**：假前提修复（三档真实差异化 bounds）+ 现状语义不变量锁定（档间半径差被迟滞带吸收、迁档半径换源不触发反向换档）；检查散布链测试是否存在同款假前提。
- **Step 2 稳定基准实装（threejs-runtime-agent）**：High 档派生半径缓存（资产级、源解析时一次计算）；两链选档输入切换到稳定半径；剔除路径不动；散布链 chunk 代表口径（最近点 + maxScale，D27.3）不变；新增断言「同一实例任意档位选档度量恒定」。
- **Step 3 A/B 实测记档 + 阈值重锁判定**：统一到 High 半径后有效换档点整体平移 ≤~5%（m=d/r 反比），处于迟滞带内；按 006.5 常量纪律带 A/B 对照（选档分布对比即可，不需完整七项报表），判定 LOD_THRESHOLDS 6/16/60/0.15 是否触发重锁；结论记档本文件与 lod-spec §4.1。

## Acceptance

- 稳定基准下：同一实例任意档位选档度量恒定（断言锁定）；真实差异化 bounds 下既有选档/迁档/迟滞断言全过。
- Step 3 记档完成（平移量实测 + 重锁判定结论）。
- `npm test` / `check:layers` / `typecheck` 全绿。

## Constraints

- 稳定基准 = Runtime 从 High 档几何**派生的缓存值**，不是资产声明字段（D28.4——不违反 D27.12「调度阈值归 Runtime 全局策略常量」；`proceduralProfile` h/w 保持 T016 浏览语义不进选档）。
- 剔除不跟随（D28.2）；`sourceKey` 形态身份语义零触碰（D23.2）；桶键、迟滞、批次控制语义零变化。
- 派发 threejs-runtime-agent（AGENTS.md「多 Agent 按 Step 派遣」）；排期 = T011 族建设后（D28.2，不阻塞当前 epic）。

**③ 新增不变量 +6（每链 3 条，本步核心价值）**：
- **(a) 半径差被 15% 迟滞带吸收**：跨线降档 → 同机位下一帧读数平移 +4.2% 零换档 → 读数在名义线 ±3%（≥ 半径差量级）来回跨线 6 次全部保持 mid、桶集/源请求零 churn → 决定性越升档线单次回 high；
- **(b) high→mid 迁档半径换源整链**：判别机位读数 5.2 ∈ [升档线 5.1, 名义线 6) 停留 mid——若下一帧仍用旧 high 半径评估读数 = 5.2×1.92/2 = 4.99 < 5.1 会立即升回 high；停留 mid = 「下一帧读数已用新档半径」+「平移不触发反向换档」双证据；
- **(c) mid→low 读数回缩方向**（Low 半径 > Mid，平移朝升档线的不利方向）：同机位回读 15.72 名义回 mid 带（< 16）但 > 升档线 13.6 不回弹——整链在平移两个方向都锁定。
