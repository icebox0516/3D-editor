# T002.1 注册与生成契约

> 归属：[T002 Procedural Assets](002-procedural-assets.md) ｜ 状态：**done（2026-09-16）** ｜ 前置：**grill 拷问门（已过，2026-09-16 裁定见下）**

## 前置 grill 门（2026-09-16 裁定，全部收敛 → DECISIONS.md D17）

契约是二期地基——002.3 变体、003.4 植物 generator、005.2 风摆相位、006.1 levels 全吃这份契约。逐项裁定结果：

1. **扫描机制 = Vite `import.meta.glob` eager**：扫描 `src/runtime/procedural/assets/**/*.asset.ts`，模块副作用注册 + `collectProceduralAssetMetas()` 收割口完全复刻 styles/routes.ts 模式（vitest 原生支持 glob，先例已被 routes.test.ts 锁定）；meta 经 bootstrap 灌入 AssetRegistry，build 函数留在 runtime 侧
2. **`build` 形态 = 无参同步 `build(): {geometry, material}`，缓存键 `assetId`**：变体按 D6 烘 transform/instanceColor 不碰 geometry、风摆按 D12 走 shader uTime；LOD（T006）届时扩展 `build(level)` 或 levels 数组，今天不留 params；异步包装（对齐 `InstanceSourceProvider` Promise 形态）是 provider 层（002.3 接线）的事
3. **jitter 语义 = 最大偏离半宽**（统一心智模型「jitter 值 = 围绕标称值的最大偏离（均匀分布半宽）」）：`scaleJitter: 0.15` → ×U[0.85, 1.15]（相对/乘性）；`rotationJitter: 15` → 绕 Y ±15°（度/绝对）；`hueJitter: 8` → 色相 ±8°（度）
4. **dispose = 会话私有缓存 + 模块级 meta 注册表**：build 缓存由组合根创建、随 `Renderer.dispose` 链在 assetLoader.dispose() 相邻位置释放，**绝不模块级单例**（StrictMode 双挂载 A→dispose(A)→B 互不伤害）；meta 注册表纯代码身份幂等无 GPU 资源，模块级安全；全程不碰 `forceContextLoss`
5. **meta/目录 = 打包裁定**：目录 `src/runtime/procedural/assets/`（glob `**/*.asset.ts`，平铺/分组自便，**分类不靠目录推导**，category 是 meta 显式字段）；meta 字段 `id`（显式声明、与 GLB 共享全库命名空间、重复即拒）+ `name` + `category`（值域对齐 manifest 英文小写，冒烟资产 `facility`）+ `tags` + `defaultScale` + `defaultRotation` + `variants?{scaleJitter?, rotationJitter?, hueJitter?}`（可选默认 0，本期只定义形态不消费）；注册表统一为可辨识联合 `AssetDescriptor = {kind:'file', asset: ModelAsset} | {kind:'procedural', asset: ProceduralAssetMeta}`；不设 `file`/`thumbnail` 字段（缩略图 002.2 离屏快照管线）
6. **撒点算法（003.1 顺风车）= 抖动网格为 v1 唯一采样器**：密度直控（点/m²）、网格与 chunk 对齐天然支持局部重算与跨块确定性、聚簇=簇心+簇内二次撒点、边缘衰减=密度场调制；泊松盘记后续可选增强（留 sampler 抽象位）——已回写 003.1 任务书

## Goal

程序化资产的代码自描述注册与生成契约（D7）：`*.asset.ts` 同文件导出 `{meta, build}`、启动自动扫描、注册表统一 AssetDescriptor、`build → InstanceSource` 契约与缓存；交付 1 个冒烟资产验证全契约。

## Requirements

- **模块形态**：`{meta, build}` 同文件导出；目录约定（建议 `src/runtime/procedural/assets/`）+ 自动扫描（glob 或等价机制）；新增资产文件 = 新增注册，零注册代码
- **统一描述符**：注册表层 `AssetDescriptor{kind: 'file' | 'procedural'}`；GLB（manifest 灌注）与程序化（代码扫描）同库共存；重复 id 显式报错
- **生成契约**：`build(params?) → {geometry, material}`（单 Mesh 天然形态）；同 assetId 结果缓存复用；dispose 语义明确（缓存随渲染器释放）
- **变体范围声明位**：meta 预留变体声明（如 `scaleJitter / rotationJitter / hueJitter`），本任务只定义形态不消费（002.3 消费）
- **冒烟资产**：垃圾桶（最简几何：圆柱身 + 盖 + 投口），meta 齐全（名称/分类=设施/标签/默认变换）
- **单测**：扫描注册、描述符合并、重复 id 拒绝、build 缓存命中与释放

## Scope

- 新建：程序化资产模块目录 + 冒烟资产 + 扫描注册装配；扩展：资产注册表（统一描述符）
- 明确不做：ContentBrowser UI 显示（002.2）、放置链路（002.3）、美术打磨（002.4）

## Acceptance

- 冒烟资产注册进注册表可按 id/kind 查询；GLB 条目回归零变化
- 重复 id 注册被拒并有明确错误；build 二次调用命中缓存
- `npm test` / `check:layers` / `typecheck` 全绿（新增测试覆盖上述）

## Constraints

- three 只允许 `src/runtime` / `src/app`；本任务不动实例化池与加载器（保持源无关）
- 不新增重量级依赖
