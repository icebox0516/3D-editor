# T009.4 树皮近景微起伏

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**not-started** ｜ 前置：排序于 T009.3 后——串行原因仅为 broadleafGeometry.ts 冲突规避，非功能依赖

## Goal

解决近距离观察时树干仍像「光滑圆柱」的问题：少量低频顶点扰动 / 局部几何微起伏，让近景轮廓开始具有真实树皮微起伏。

## Requirements

- **三层距离目标**：远景 = 颜色 + 粗糙度（现状即可）；中景 = Shader 脊沟结构明显（现状保持）；近景 = 轮廓具有真实树皮微起伏（本任务新增）
- **只加低频**：少量低频顶点扰动或局部结构，不制造明显高频 displacement；Shader 侧不加新 fragment noise（现有脊沟/节疤/苔痕结构维持）
- **量级挂钩**：微起伏量级与枝干半径/层级挂钩（主干强、末梢弱）

## Scope

- 预期触碰：`broadleafGeometry.ts` emitTube 顶点域；`tree3aMaterials.ts` 仅在必要时微调匹配
- 不碰：契约层、叶簇逻辑

## Acceptance

- 近景轮廓起伏可辨；中景/远景无观感回归；性能无感知退化
- 三距离取证对比（与 009.3 完成态基线对照）；`npm test` / `check:layers` / `typecheck` 全绿
