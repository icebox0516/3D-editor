# T009.4 树皮近景微起伏

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**done（2026-09-18）** ｜ 前置：排序于 T009.3 后——串行原因仅为 broadleafGeometry.ts 冲突规避，非功能依赖

## Goal

解决近距离观察时树干仍像「光滑圆柱」的问题：少量低频顶点扰动 / 局部几何微起伏，让近景轮廓开始具有真实树皮微起伏。

## Requirements

- **三层距离目标**：远景 = 颜色 + 粗糙度（现状即可）；中景 = Shader 脊沟结构明显（现状保持）；近景 = 轮廓具有真实树皮微起伏（本任务新增）
- **只加低频**：少量低频顶点扰动或局部结构，不制造明显高频 displacement；Shader 侧不加新 fragment noise（现有脊沟/节疤/苔痕结构维持）
- **量级挂钩**：微起伏量级与枝干半径/层级挂钩（主干强、末梢弱）

## Scope

- 预期触碰：`broadleafGeometry.ts` emitTube 顶点域；`tree3aMaterials.ts` 仅在必要时微调匹配
- 不碰：契约层、叶簇逻辑

## Acceptance

- 近景轮廓起伏可辨；中景/远景无观感回归；性能无感知退化
- 三距离取证对比（与 009.3 完成态基线对照）；`npm test` / `check:layers` / `typecheck` 全绿

**实现**（`broadleafGeometry.ts` emitTube 顶点域 + `tree3aShapeProfile.ts` 参数面）：
- **起伏数学**：d(θ,s) = A·Σₘ wₘ(s)·cos(kₘθ + φₘ(s))，整数谐波 k∈{3,4,5}（≤ 主干 radial 12 奈奎斯特域）；A = amplitudeRatio(0.033) × 局部半径（比例式量级挂钩——主干强末梢弱）；φₘ(s) = ψₘ + driftₘ·s + 0.5·sin(1.6s + χₘ)（轴向游走），wₘ(s) = baseWₘ·(1 + 0.3·sin(2.4s + ωₘ))（脊深呼吸）；相位源 = 管起点位置 + 起径的 sin 散列——**纯确定性函数，零 rng 消费**（消费计数锁 177234 与 T009.3 前逐位一致）
- **法线解析修正**：n ∝ e − (d_θ/R)·ē − d_s·T（参数面导数推；量纲：θ 米制弧长 = R·dθ → 环向坡度除 R，s 已是米 → 轴向坡度不除；锥度项沿既有约定忽略）——平滑外向、uv/拓扑/绕序全不变
- **环级共享预算**：每环 ReliefRing（位移 + 导数 + cos/sin）一次预算、相邻四边形与 wrap 位（j=radial−1 的 th1 取 j=0 预算值）复用——环向浮点级无缝（实测 wrap 顶点差恰为 0）
- **亚视觉幅度地板**：管起径 × 幅度比 < 1.5mm → 整管按 0 起伏发射（L3 以下细枝典型域——亚毫米层近景不可辨，兼免低径向段混叠计算；实测 L5 首环极差 1e-7m 级圆管）
- **参数面**：`barkRelief: { amplitudeRatio 0.033, harmonics [3,4,5], drift 0.85 }`（Tree3aBarkRelief，逐字段 Spec 依据 + Evidence Status + 共性标注——幅度∝半径挂钩/脊游走机制 =【阔叶共性候选】，绝对值/纵沟窄脊谐波原型 =【夏栎特有】；现实定性 = bark_relief/bark_archetype Inferred/Verified，幅度数值工程设定）；slot-0 定义、slot-1…7 spread 继承逐位恒等（测试锁）
- **emitBaseCapTri 不动**（独立性说明落调用点注释：盖沿与管壁首环 ≤1.3cm 环形错位由贴地遮挡，近地视角不可见）

**实测（slot-0/规范种子）**：主干 14 环极差 7.3–23.9mm（3.7–6.6% 环均径，全部落 [2%,10%] 量级带——基环厘米级、成熟较弱浮雕端）；L1 首环极差 4.78mm（4.4%）> L5 首环 ≈0.0001mm；法线与径向夹角 ≤8.62°（dot ≥0.9887；修复后值——见下方返工记档）；轴向相邻环剖面相关 0.94–1.00（脊沿轴伸展）vs 首末环 −0.93（游走开——非箍纹非静态贴图）；皮面数 20724 恒等；构建时长 32.11 → 31.80ms（−1.0%，环预算复用 + 免逐四边形 Vector3 分配抵消谐波计算——<5% 要求内）
