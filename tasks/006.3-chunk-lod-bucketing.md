# T006.3 块×档分桶 + 换档

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**done 2026-09-19** ｜ 前置：T006.1、T009.6、T003.2

## Goal

选档接入两条渲染链（D27.4/D27.5/D27.6）：张角选档消费 + level 维度桶 + 换档。

## Requirements

- **选档接入**：散布 = 块粒度（chunk 代表距离 = 块最近点到相机、代表 scale = 块内 max，保守偏高档）；放置 = 逐对象评估（对象包围球 × 实例 scale）；两链统一走 006.1 评估器，不复制选档逻辑
- **桶形态（D27.4）**：散布 = chunk × source × level；放置 = source × level；换档复用既有机制——散布 = 确定性重撒重建、放置 = 实例跨桶迁移（池既有跨池迁移）；不引入「桶内换 Source」机制；geometry + material 随 sourceKey + level 的 InstanceSource 整体成套
- **帧内时序（D27.6）**：块剔除之后、render 之前评估档位；档位不进 Scene、不进 Command、不缓存进持久状态
- **hysteresis 防抖 + 换档平滑**：相机在阈值带附近不抖动换档；换档点无 pop/闪烁
- **拾取跨档一致**：任意档位实例拾取映射回同一业务对象/区域（渲染表示变化不改业务身份）
- **LOD 总开关**：关 = 全 High（回退对比与兜底）
- **验证分工（D27.8）**：散布链验证 chunk × level 桶机制（当前散布单 source 限制接受）；多 source × level 交叉桶（夏栎 8 槽 × 3 档）在放置链验证

## Acceptance

- 连续相机移动（近→远→近）截图序列机器 diff 无跳变/无抖动换档 + 换档点前后帧人工复核（D23.7 例外，D27.10）
- 拾取一致；开关切换正确回退；块生命周期单测扩展全绿；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 渲染实现按 AGENTS.md「多 Agent 按 Step 派遣」执行；换档验证必须截图像素取证

### 交付面

- **两链选档接入（统一走 006.1 评估器，零选档逻辑复制）**：
  - 共享口径翻译 `src/runtime/instancing/lodView.ts`（THREE 相机 → LodView：透视
    fov 度→弧度 + 世界位；正交 top−bottom；THREE→domain 唯一边界）；
  - 散布链 `ScatterChunkManager.frame(camera, lodEnabled)`：块视锥剔除后逐
    (块×资产) 评估——subject = { 块 AABB 最近点 clampPoint, 当档源几何包围球半径,
    块内 max scale }（§4.3 候选保守策略）；
  - 放置链 `InstancedAssetPool.frameLod(camera, lodEnabled)`：逐对象评估——
    subject = { 实例矩阵作用后的包围球球心, 源几何半径, 矩阵三轴最大 scale }。
- **桶形态（D27.4）**：散布 MeshEntry 携带 level（chunk×source×level，换档 = 拆旧桶
  确定性重撒重建，同 seed 同实例集）；放置池键 `${sourceKey}::${level}`
  （source×level，换档 = entry 跨桶迁移，矩阵/颜色/seed/迟滞态整体随迁、锚点身份
  不变、双池 reconcile 收敛）；两链均不做「桶内换 Source」；geometry+material+
  customDepthMaterial 随 sourceKey::level 成套（消费 ProceduralSourceCache.load
  ({level}) 既有 API——AssetSourceRouter opts 增 level 机械透传，load 键规则未动）。
- **帧内时序（D27.6）**：Renderer.renderFrame 在 controls 后、render 前——
  scatter.frame（块剔除+选档）→ instancedPool.frameLod（选档+迁移）→ render；
  档位不进 Scene/Command；迟滞 current 由 runtime 持有逐帧传入（散布 = ChunkLodState
  .current、放置 = PoolEntry.currentLod，随 chunk/entry 生命周期生灭）。
- **换档无 pop**：源就绪即同步迁移/重建；冷源微任务到达回调（在途登记
  pendingLevel/lod.pending，旧档持续渲染）。新对象/新块 high 起步、首帧评估即校正
  （冷档首载有一帧过渡，已记档）。
- **拾取跨档一致**：散布 meshOwners 与放置 pools 反查天然档位无关；补 culled 网格
  拾取挡板（r186 raycaster 不跳 visible=false——mesh.visible 守卫）；culled 放置
  实例零缩放不可命中。
- **culled**：散布 = (块×资产) 网格 visible=false（桶保留）；放置 = 槽写零缩放
  （复用隐藏实例机制，entry.matrix 真值保留）/ 单例 Mesh visible=false。
- **总开关**：Renderer.lodEnabled + setLodEnabled/isLodEnabled（渲染派生态）+
  URL `?lod=0/off/false`（bootstrap 读一次）；off = 全 High（跨桶迁移/重建回
  high）+ culled 旁路，可逆。
