# T006.3 块×档分桶 + 换档

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**not-started** ｜ 前置：T006.1、T009.6、T003.2

## Goal

选档接入两条渲染链（D27.4/D27.5/D27.6）：张角选档消费 + level 维度桶 + 换档。

## Requirements

- **选档接入**：散布 = 块粒度（chunk 代表距离 = 块最近点到相机、代表 scale = 块内 max，保守偏高档）；放置 = 逐对象评估（对象包围球 × 实例 scale）；两链统一走 006.1 评估器，不复制选档逻辑
- **桶形态（D27.4）**：散布 = chunk × source × level；放置 = source × level；换档复用既有机制——散布 = 确定性重撒重建、放置 = 实例跨桶迁移（池既有跨池迁移）；不引入「桶内换 Source」机制；geometry + material 随 sourceKey + level 的 InstanceSource 整体成套
- **帧内时序（D27.6）**：块剔除之后、render 之前评估档位；档位不进 Scene、不进 Command、不缓存进持久状态
- **hysteresis 防抖 + 换档平滑**：相机在阈值带附近不抖动换档；换档点无 pop/闪烁
- **拾取跨档一致**：任意档位实例拾取映射回同一业务对象/区域（渲染表示变化不改业务身份）
- **LOD 总开关**：关 = 全 High（回退对比与兜底）
- **验证分工（D27.8）**：散布链验证 chunk × level 桶机制（当前散布单 source 限制接受）；多 source × level 交叉桶（夏栎 8 槽 × 3 档）在放置链验证

## Acceptance

- 连续相机移动（近→远→近）截图序列机器 diff 无跳变/无抖动换档 + 换档点前后帧人工复核（D23.7 例外，D27.10）
- 拾取一致；开关切换正确回退；块生命周期单测扩展全绿；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 渲染实现按 AGENTS.md「多 Agent 按 Step 派遣」执行；换档验证必须截图像素取证
