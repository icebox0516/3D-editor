## Goal

白蜡树（Fraxinus chinensis，木犀科梣属）生产资产 `asset_tree_fraxinus`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证。**奇数羽状复叶（一回）——复叶第四型实例**（011.6 二回羽状/011.8 三出/011.9 国槐直接羽状后的第二直接羽状实例——复叶表达路径沿 011.6 先例结论由 Step 1 判定沿承 or 分化，与国槐形成同型不同数值对照）+ 大叶对生语言候选（梣属小叶对生——与既有互生系挂点语言的分化点，以 Spec 确认）+ 翅果（倒披针形翅果序——生长季可见性以 Spec 定，参照先例账目法）。D33 点名候选。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外 D31.2）。

- **判定：强制调研**。命中情形：①高真实要求（羽状复叶+翅果+对生小叶为白蜡树身份）；②类型显著影响形态（复叶第四型 + 对生叶序语言 + 冠形枝姿分化）；⑤资产将成同类生产基准（复叶三型收官、D33 点名）。
- **执行**：通用子代理加载 asset-research 技能 → `docs/research/fraxinus-reference.md`；主代理硬数值独立抽查（≥12 条对照 iplant/FOC 原句）+ 照片终审（008.6 返修规程：候选照片 URL 自 API JSON 提权威扩展名、两次独立视觉提问一致方定名）；分歧取中庸、终审记档追加于 Spec 文末。
- **Spec Version 锚点：1.0**——开发 Agent 开工前校验一致。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 61:30（自行复核原句）/ FOC Vol.15（卷页由调研确认——Fraxinus FOC 归置核实；近缘种复杂：白蜡树 F. chinensis vs 苦枥木/尖萼梣等分合口径，长江流域公园语境种定名判定并记档）；形态材质变体 → 真实照片直接视觉证据。重点调研面：种定名（F. chinensis 广义/狭义与近缘分合——公园语境主力确认）；**奇数羽状复叶**（小叶数枚范围（5-7?）、**对生 or 互生**（梣属典型对生——与国槐互生小叶的对照轴）、小叶形态〔卵状披针形/披针形？〕长宽 cm、缘锐锯齿？、先端渐尖？、脉型）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；卵圆形冠？大枝开展/轮生？）；**枝姿**（大枝角度、小枝/芽——梣属对生芽序候选）；**树皮**（灰褐色、纵裂/交叉深裂？——vs 先例语言定位）；**花**（圆锥花序侧生/顶生？花杂性无瓣或小？、花期、生长季可见性 → 建模判定）；**翅果**（倒披针形、长 cm、翅占比例、果期、簇生状、夏末可见性 → 建模判定记档）；叶色（正/背面色差——白蜡叶背常灰绿「蜡」感来源考）；秋色黄（记档不建模）。
- **Step 1 结构分析**：Spec → 先例方法基线对照（011.6/011.8/011.9 复叶先例结论重点对照）——可继承 / 改写 / Unknown；**一回羽状复叶表达路径判定**（沿先例路径 or 分化——对生小叶序的实现面）；翅果表达路径判定（若做——先例账目法）；经济用途注记（形态锚定城市绿化个体）。
- **Step 2 参数化**：`tree/fraxinus/fraxinusShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量。
- **Step 3 几何（procedural-asset-agent）**：`tree/fraxinus/fraxinusGeometry.ts`——方法复制 + 白蜡树算法细节（羽状复叶挂点按 Step 1 判定路径/翅果若做按先例/冠形枝姿按 Spec）；LOD 三档同流；入口 `assets/asset_tree_fraxinus.asset.ts`（meta 同契约）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/fraxinus/fraxinusMaterials.ts`——小叶 SDF（卵状披针形域内 or 最小扩展）+ 缘锐锯齿载波 + 羽状脉 + 叶色（面绿/背灰绿蜡感）+ 背光透射 + 风动两层 + 翅果材质（若做：绿→褐翅果串）+ 树皮配方（按 Spec 定位）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/fraxinus/fraxinusStage.ts` 同构 + bootstrap `window.__fraxinus`；VIEW_TARGET_Y 几何实测定档；缺口 D 评估。
- **Step 4 视觉验证（主代理，D30 增量口径）**：三必做（①身份判定：羽状复叶读出（近距对生小叶排布/中距羽叶剪影）+ 冠形 + 树皮 + 翅果若做可见性；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.10/`；③缺口记档归 011.13）+ 疑点触发（对生叶序近读（vs 国槐互生横向对照）/翅果若做可见性/风动三证据/console/LOD 档间）；校准默认一轮、两轮封顶。
