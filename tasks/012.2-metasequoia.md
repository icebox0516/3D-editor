## 重点调研面

- **种定名与身份**：Metasequoia glyptostroboides 中名口径「水杉」+ 科属口径（柏科 vs 杉科分类变动）；公园语境混淆面（落羽杉/池杉同域落叶针叶——定名判据）。
- **对生枝序（姿态核心承重）**：大枝对生/近对生结构 vs 雪松轮生层状；枝角域（斜展/上举）；主干通直性；枝层数（若分层）或连续分枝判定——草案层状字段消费判定输入。
- **脱落性小枝（表达路径承重）**：侧生小枝对生排成二列、冬季与叶整体脱落——「叶卡」挂点单位是小枝系统还是单叶；小枝长度/下垂姿态。
- **尖塔冠与体量**：幼树尖塔 → 中龄/成树冠形变化（塔形维持 or 广椭圆？）；树高/冠幅/干高（≈15–25m 立项假设锚定）；冠幅比（尖塔窄冠预期）；中龄公园典型个体判定。
- **条形叶**：长度/宽度；对生假二列着生；色相（鲜绿/淡绿？）；**两面色差有无**（vs 雪松无两面差——族内差异判定）；中脉读向。
- **落叶性与秋色（presets 承重）**：落叶时窗（主语境 9–10 月 = 秋色前/中？）；秋色色相与演替（绿→黄褐→棕红？）；autumn 卡建卡证据锚（epic：落叶杉类按 Spec 证据定）。
- **球果**：下垂着生位置/大小/形态；当年成熟时窗（主语境可见性）；中龄公园个体宿存量级（显著性判定——vs 雪松如烛正向 / bischofia 不做反向，两轴对照）；雄球花花期可见性。
- **树皮**：长条片/浅裂剥落色相（红褐/灰褐？）——阔叶 14 语言 + 雪松第 14 后的谱系定位（第 15 语言候选）。
- **干基与湿地习性**：干基膨大（板根状）公园旱地栽植常见态判定——干形字段输入。
- **风动读向**：密尖塔冠 + 对生枝系统的摆动特性（整冠摇/末级小枝颤——风动成分参数档位输入）。

**Step 1 判定记档（2026-09-29 主代理——依据 Spec 1.0 终审后口径；先例读取深度 = conifer 索引 full-read + Spec 摘要区 full-read，原任务书零回读——判定级决策索引摘要足够）**：

1. **骨架 = 层位量化挂点法「对生 + 不规则轮生」改写**：cedrus 近轮生成层机制直接复用（FoC「irregularly whorled」+ s01/s05b tier 化观感）；差异 = 层内**对生成对**主律（±180° 方位对 + 层间交错，vs cedrus 层内近轮任意方位）+ 层距密（水杉密尖塔预期 8–12 层 vs 雪松 6–8 疏层——Step 2 探针）+ **枝角梯度直接继承**（终审精化下部近水平 70–85°→上部 30–50°——与 cedrus 实测 81→44° 同型读向，层状骨架语言家族第一横向证据）。
2. **叶表达 = 羽状小枝卡（新形态语言）**：「叶」单位 = 侧生小枝系统（3–7 × 1.5–4 cm 卵状椭圆、对生二列条形叶）——1 卡 = 1 羽状小枝 SDF（中轴 + 两列对生条形叶羽列轮廓）；挂点 = 末级枝**对生叶序**（vs cedrus 长短枝双挂点）。**中距浓密板三杠杆选择性继承**：交叉双卡 ✓（单面卡无角度覆盖为几何普适）+ 挂点前移 ✓；「卡尺度 ≥0.3m」**不适用**（羽卡 = 多叶聚合单元自带轮廓，尺度 3–7cm——细质地 Fine 身份，中距读向 = 密集羽列软质感 s03，非大卡面质量）。
3. **冠形 = 密尖塔连续锥**（vs cedrus 层叠尖塔带隙）：ginkgo 角度梯度 + cedrus 锥形收顶复用；**无层隙观感带**（冠连续密实——层隙密度场字段消费差异 → 转正素材）；窄冠 0.15–0.25 + 顶部细长收尖。
4. **末级下垂 = 垂帘机制轻度版**：branchlets pendulous + 脱落枝下垂轮廓——salix/cedrus 负链机制可继承、幅度远小于 salix；**顶梢专路不消费**（leader 通直无点头——转正素材）。
5. **球果账目：做（改写 = 下垂柄 + 未熟绿果）**：主语境 9–10 月 = 绿色近成熟体（当年 10–11 月熟）+ **雄花序枯序第二器官**（s04 实证 3–5cm 下垂枯穗——default 卡近景身份细节）；显著性 = 零星-少量（介于雪松正向与 bischofia 无果之间偏轻——密度档低）；posHash 零 rng 账目（koelreuteria 法）+ 下垂姿态；宿存中轴类不消费（水杉熟果整果脱落非宿存中轴）。
6. **树皮第 15 语言：纵长条片-纤维剥落**：红褐/桂皮棕基调 + 脊:沟 2–3:1 深索浮雕 + 长纤维条翘边 + 幼淡橙褐→老暗红褐株内梯度（vs 第 14 鳞状方块片——同科两语言轴）。
7. **叶材质 = 羽卡 SDF + 两面温和色差（族内差异轴）**：上深下浅温和差（vs 雪松无两面差——两面色差语言回归阔叶式消费、幅度参数化）；受光色差 ramp 同源；**presets 双卡** = default 亮黄绿（9 月末时点）+ autumn 锈橙-红褐（四源文献 + s10/s04 双照片）。
8. **风动 = 两成分**（整冠低频小幅 + 末级羽枝高频细颤〔主成分〕）；顶梢成分不消费（转正素材：顶梢 = 雪松特有 or 家族可选位）；树高锚换 18–25m 同步轮。
9. **干基膨大 ×1.5–2.0：干形新消费点**——契约若无基部收放字段则转正轻量路径增字段（水杉真实需求）。
10. **slot-0 锚 = 开阔孤立中龄型**：树高 ~20m（域 18–25 中段）/ 冠幅比 ~0.25 / 干高比 ~0.40 / 膨大 ×1.6；8 槽主轴 = 树高 15–25 × 冠幅 0.20–0.32 × 干高 0.35–0.50 × 膨大 1.3–2.0 × 年龄轴（幼树极窄长叶→中龄密尖塔→老树阔圆锥）。
11. Unknown 留档（Step 2/4 探针）：层计数绝对值、雄序枯穗近景显著性（M8 判读）、密冠透天比例预期（vs 雪松层隙透天——探针定档）、羽卡中距可辨性（细质地卡密度策略验证）。

改写映射实现面：几何 = 对生轮生层位挂点 + 枝角梯度 + 密连续锥冠 + 羽卡对生挂点 + 末级轻垂 + 下垂绿果/枯序双器官账目 + 干基膨大；参数 = 契约消费差异逐字段记档（层隙/顶梢/垂帘幅度/两面差/干基字段）；材质 = 羽卡 SDF + 两面温和差 + 双卡色相 + 第 15 树皮 + 果/序材质 + 风动两成分。
