## Goal

形态族扩展至 8 槽 + T008 epic 验收门：全链路验收、**同 sourceKey 共享验证**（本契约设计的核心价值证明）、取证存档。

## Requirements

- **扩 8 槽**：`shapeFamily.size = 8` 全量生效——8 槽形态生成、跨槽差异可见且自然（同种树的不同个体，不是 8 个物种）；槽间质量对齐锚点定稿基准；缩略图不增（资产级一张）
- **全链路验收**：入库 → 放置 → 重掷（重掷结果在 8 个 shapeSlot 上呈统计分布即可；不要求单次重掷必然切换槽位——同槽重掷合法）→ 复制孪生 → undo/redo → 存档往返逐位一致 → Gizmo 编辑
- **同 sourceKey 多实例一致性验证（核心项）**：随机放置 ≥6 棵**同槽**树——确认 Geometry/Material 全程共享（仅一份 Source）、实例间**仅允许 instanceMatrix / instanceColor / aSeed 存在实例级差异**（不得通过 per-instance uniform、独立 Geometry、独立 Material 或额外 Mesh 产生形态差异）、桶内保持**单一 InstancedMesh × 2 draw calls**（renderer.info 实证）
- **零错误五拆口径**（代替粗粒度「console 零错误」）：
  1. 运行时无异常
  2. 资源无重复 build（同 sourceKey 二次请求走缓存）
  3. Ghost 不触发 dispose（借缓存契约不破）
  4. 放置/删除/Undo/Redo 全程无资源泄漏（dispose 链 + 内存观察）
  5. 同 sourceKey 不重复创建 Geometry/Material
- **取证存档**：固定机位 + 固定曝光/环境光 + 固定相机距离（锚点门同款纪律）；近/中/远 + 8 槽全景 + 合批证据（draw call 数）存 `docs/acceptance/t008/`
- **收尾**：完成记录 + TASKS/PROGRESS 同步 + commit；T003 解冻路径提示（恢复入口见 003.3 交接快照——是否立即恢复由用户另定）
