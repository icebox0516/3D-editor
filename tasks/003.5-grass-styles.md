# T003.5 绿地样式 5 种

> 归属：[T003 Scatter Styles](003-scatter-styles.md) ｜ 状态：**not-started** ｜ 前置：T003.3、T003.4

## Goal

D15 绿地全家桶样式交付：表面型 2 种（普通草地 / 修剪草坪）+ 散布型 3 种（花卉绿地 / 灌木绿地 / 自然林地）。

## Requirements

- **表面型 ×2**：程序化纹理 shader（噪声草地 / 修剪条纹），色调与密度参数化（StyleParameter 四控件表达）；无散布段
- **散布型 ×3**：
  - 花卉绿地 = 草表面 + 花卉资产（高密度小尺寸）
  - 灌木绿地 = 草表面 + 灌木资产（中密度聚簇）
  - 自然林地 = 草地/落叶表面 + **多资产配比**（橡树 40% / 松树 20% / 灌木 30% / 花卉 10%）+ 聚簇 + 边缘衰减
- **预设 meta 齐全**：名称/分类/支持形状语义/参数表（缩略图位留给 004.1）；默认参数即出好效果（用户零调参可用）
- 与语义默认绑定：绿地语义默认样式指向「普通草地」

## Acceptance

- 5 样式可应用于任意闭合区域（含圆/椭圆/自由形状）；默认参数观感达标
- 自然林地四资产配比肉眼可辨、边缘渐稀可见
- 换装语义：林地 ↔ 修剪草坪互切正确且可撤销（回归 003.3 链路）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 表面 shader 程序化纹理自写（噪声 GLSL，不用图片文件）；参数解析走既有管线
- 渲染实现派发子代理；观感终验在 003.6
