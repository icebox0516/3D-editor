# T003 Scatter Styles

## Goal

散布型样式——「Style 即完整配方」落地（D3/D4/D5/D8/D9）：画区域 → 应用样式 → 表面材质 + 多资产按配比散布一步生成；换样式整副面孔切换；区域文件保持轻量。

## Requirements

- **Style 配方结构（D4）**：样式预设扩展为完整配方——`表面材质 + 资产配比（assetId × weight）+ 散布参数（密度 / 聚簇程度 / 边缘衰减 / 尺寸范围）`；区域对象只存 `presetId + 参数覆写 + seed`
- **撒点纯函数（D8）**：种子化、确定性（同输入同输出）；算法泊松盘或抖动网格（设计时裁定，可混用）；输出含每实例位置/旋转/缩放/变体 seed；放 domain 层纯函数，单测锁定（含跨块边界、边缘衰减、配比分布统计）
- **分块实例化管线（D9）**：空间分块为基本单元——逐块剔除、跨块编辑只重算受影响块、块内按 assetId 合批渲染；分块尺寸常量可调（T006 将升级为 LOD 分档基础）
- **派生式语义（D5）**：散布实例非场景对象；点树 → 选中所属区域（拾取反查映射回 region）；改密度/配比/种子 → 局部重算；撤销/重做作用于区域对象本身
- **植物资产（D15）**：程序化 generator 4–5 种——橡树 / 松树 / 灌木 / 花卉（复用 T002 注册与生成契约，验收 LOD levels 接口位预留但本任务不实现分档）
- **绿地全家桶样式（D15）**：普通草地 / 修剪草坪（表面型，shader 程序化纹理）+ 花卉绿地 / 灌木绿地 / 自然林地（散布型，多资产配比）共 5 种；「自然林地」须支持多资产混合配比（如橡树40% + 松树20% + 灌木30% + 花10%）
- **序列化**：场景只存 presetId + overrides + seed；加载重建；版本策略增量放行不破坏存量场景

## Scope

- 新建：撒点纯函数（domain）、分块实例化管线（runtime）、散布型样式预设结构、4–5 种植物 generator、5 种绿地样式
- 预期触碰：样式预设契约（配方结构）、区域渲染消费端、拾取反查、Inspector 散布参数组
- 宿主集成事实参考：`docs/architecture-audit/05_STYLE_SYSTEM.md`、`13_EXTENSION_POINTS.md` 方向 A/C

## Acceptance

- 画任意闭合区域 → 应用「自然林地」→ 多资产按配比散布、边缘渐稀、聚簇可见
- 换「修剪草坪」→ 树自动消失、草地浮现，一步完成、可撤销
- 密度调参 → 只重算受影响块（无全局闪烁）；拖动区域顶点 → 边界树跟随重撒
- 园区档验收（D10 交付门槛）：≥ 2 万散布实例、核显 1080p 连续渲染 ≥ 30fps
- 撒点纯函数单测：确定性 / 配比统计 / 边缘衰减 / 跨块覆盖 全锁定
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- three 只允许出现在 `src/runtime` / `src/app`；撒点算法零 THREE 依赖（domain 纯函数）
- 散布实例不进场景对象表 / 不进撤销栈 / 不进大纲（D5）
- WebGPU / compute 不涉及（D8）；LOD 分档留给 T006
- 渲染任务按 AGENTS.md「多 Agent 按 Step 派遣」执行；主代理审查 + 截图视觉验收
