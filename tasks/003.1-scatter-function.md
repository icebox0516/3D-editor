# T003.1 撒点纯函数

> 归属：[T003 Scatter Styles](003-scatter-styles.md) ｜ 状态：**done（2026-09-16）** ｜ 前置：无硬前置（可与 T002 并行；仅依赖 002.1 的资产 id 概念）；撒点算法已于 2026-09-16 随 T002.1 grill 拷问门裁定（见下，DECISIONS.md D17）

## Goal

散布核心算法（D8）：种子化确定性撒点**纯函数**——domain 层、零 THREE、零 DOM，全部逻辑单测锁定。

## Requirements

- **输入**：多边形（XZ 平面点列）/ 密度（每百平米实例数）/ 资产配比表（assetId × weight）/ 聚簇程度 / 边缘衰减 / 尺寸范围 / seed
- **输出**：实例描述列表 `{position, rotation, scale, variantSeed, assetId}`
- **算法（2026-09-16 grill 裁定，D17）**：**抖动网格为 v1 唯一采样器**——密度直控（点/m²，正好是配方参数形态）、网格与 chunk 对齐让局部重算与跨块确定性天然成立、聚簇=簇心+簇内二次撒点、边缘衰减=密度场调制；泊松盘记为后续可选增强（接口层面留 sampler 抽象位，v1 不实现）
- **确定性**：同输入逐位同输出（seed 驱动，无 Math.random / 无时序依赖）
- **语义细节**：配比按权重统计分布；边缘衰减单调（越靠边密度越低）；点全部落在多边形内（含凹多边形）；聚簇 = 簇心 + 簇内散布两层级
- **性能**：2 万点撒点 < 50ms（单测断言）

## Scope

- 新建：domain 层撒点模块（纯函数 + 类型）；不接任何渲染/UI

## Acceptance

- 单测锁定：确定性（同 seed 双跑逐位比对）/ 配比统计（区间断言）/ 边缘衰减单调 / 密度换算误差带 / 凹多边形包含 / 退化输入（零面积、空配比、密度 0）
- 性能断言通过；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 零 THREE 零 DOM（分层检查自然约束 domain 层）；不读场景状态（纯输入输出）

## 完成记录

**done 2026-09-16（+25 测试 → 2168 全绿；三重门槛过）**

- **交付**：`src/domain/scatter/`（`scatterPolygon` 全量 + `scatterChunk` 块级 + `ScatterParams/ScatterInstance/ScatterChunk` 类型）；core 基元两件——`mulberry32` 自 variants.ts 迁移至 `src/core/random.ts` 并新增 `hashCell(seed,i,j)` 整数混合哈希、`core/math` 新增 `pointInPolygon`（射线法，凹多边形通用）。
- **确定性根基**：每网格 cell 随机流 = `mulberry32(hashCell(seed, i, j))`——只依赖 (seed, cell 坐标, 层 salt) 与流内消费顺序，与遍历顺序、跳过的 cell 无关。网格与世界原点对齐（非 bbox 对齐）→ 多边形编辑后未受影响 cell 哈希不变，局部重算天然成立（003.2 分块管线的根基）。
- **块级语义**：均匀层抖动取 cell 内 U[0,h)（点恒在发起 cell 内）→ 块级遍历无需外扩；聚簇层簇内点可越出簇心 cell 达 R → 块级外扩 R+H 后按位置半开 [min,max) 过滤。单测锁定：全量 = 逐块拼接逐位一致（负坐标跨原点 + 两层混合 + 衰减复合场景）、单块重算 = 新参数全量的该块切分。
- **聚簇模型 κ=4**（实现时修正的稀释缺陷）：每簇点数不固定，k0 = κ·d_c·πR²——簇内局部密度恒为标称 4 倍，聚簇观感与密度无关；簇心步长 H = R·√(πκ) 只由簇半径决定。固定 k0 的直觉方案在高密度下会把簇稀释到比背景还稀（d=1 时簇内 0.076/m² ≪ 标称），回归测试锁定 κ 语义。
- **密度单位**：接口为 `densityPerM2`（点/m²）——D17 裁定「密度直控（点/m²，正好是配方参数形态）」，任务书行文「每百平米」为起草口径，以 grill 门裁定为准。
- **边缘衰减**：保留概率 = smoothstep(距边界/带宽)，随距离单调不降；分带密度单调 + 带外恢复标称由单测锁定（±6σ 涨落容差）。
- **性能**：2 万点全量（含聚簇 + 衰减）预热后实测 ~7ms ≪ 50ms 预算。
- **sampler 抽象位**：`ScatterSampler = 'jitter-grid'`（v1 唯一值）；泊松盘后续扩联合类型即可，不留空壳代码。
