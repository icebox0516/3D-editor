# T009.3 8 槽形态向量表

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**done 2026-09-18** ｜ 前置：T009.1 + T009.2

## Goal

在 T009.1 参数面上定义 **8 组完整形态向量**（shapeProfile 预设组合）——每个 Slot 是一个完整形态组合（多维度取值整体），方向名（标准 / 挺拔 / 展开 / 偏冠 / 低冠 / 高冠 / 疏松 / 丰满）仅为标签。以此保证「明显不同、但仍然属于同一树种夏栎」。

## Requirements

- **形态向量表**：8 组 shapeProfile 完整组合，混合使用 crownCenter / crownHeight / crownWidth / mainBranchSpread / asymmetry / canopyDensity / crownTopBias 等维度形成组间差异——**禁止**仅整体缩放、仅旋转、仅轻微随机的伪差异
- **机制延续**：走既有 shapeSlot / morphSeed 机制（不另造随机系统）；sourceKey 语义不变；8 组向量即 config 雏形（夏栎资产内结构配置，非公共契约）
- **批量出图**：tree3aStage 提供 8 槽批量出图面（固定机位）
- **会话策略**：8 Slot 初版**一次生成**，用户裁定**按批次进行**（批量出图 → 分轮裁定），不要求每个 Slot 独立会话；保持 T009 七子任务结构不变

## Scope

- 预期触碰：形态向量表（夏栎资产/几何侧）、参数消费、tree3aStage 出图面
- 不碰：契约层、材质

## Acceptance

- 8 组向量逐槽用户裁定通过（每槽 1–2 轮微调上限）
- 每槽固定机位取证存档（8 槽全景 + 单槽特写）
- 同 seed 逐位复现、同槽同引用延续；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- Shape Slot = 人工筛选的固定形态族，不是随机数展示（D20）
- 向量表为夏栎私有配置；公共形态契约由 T010.1 从真实消费者提炼

**消费语义发现（记档，T010.1 提炼公共契约的重要事实）**：crownCenterRatio / crownHeightRatio / crownTopBias **不动几何**——只进密度场参考系（q 分桶/存活率）调制叶卡分布与数量；冠的垂直摆放实际由 attachMin/Span + 横展角 + upturn + 领导枝链驱动。弱领导枝会翻转树顶决定因素（领导链→骨架链），使树高与冠幅参数耦合缩水。

**已知边缘项（记档不阻塞）**：slot-2/4 顶高 7.28/7.34m 略低于资产声明「总高 7.4–8.5m」下沿 0.06–0.12m（槽 seed 随机域所致，视觉不可辨）；如 009.6 LOD 预算锁定时收紧总高域可一并校。
