# T007 Bake Scatter（后置可选）

## Goal

散布烘焙（D5 的补充操作）：把派生式散布转成与手动放置同构的逐棵活对象——需要精修个别树时的逃生门。**后置可选任务，启动前须过 grill 拷问门（议题见子任务节）。**

## Requirements

- 烘焙入口：选中区域（或框选多区域）→ 执行烘焙 → 散布派生物转为逐棵 ModelObject（asset 引用 + transform + 实例色 + seed，与 T002 手动放置同构）
- 烘焙后原散布派生渲染移除；实例数守恒（N 棵树烘焙后仍是 N 个对象）
- 烘焙经命令整体可撤销（一次撤销回到派生态）
- 大区域烘焙的规模保护：分级烘焙（按块/按选中子集）与上限提示

## Scope

- 预期触碰：散布管线（导出实例表）、命令层（烘焙命令）、大纲（批量对象入组）

## Acceptance

- 烘焙后逐棵可 Gizmo 编辑 / 单删 / 撤销一次回退派生态
- 实例数守恒；烘焙 1000 棵级区域操作流畅（进度反馈）

## Constraints

- 烘焙是单向门（派生 → 对象），UI 须明示；不做「对象回炉派生态」
- `npm test` / `check:layers` / `typecheck` 全绿

## 子任务

不拆（单会话体量）。启动前须过 grill 拷问门（后置可选；2026-09-16 将原「用户确认门」升格为正式拷问），议题：单向门语义在 UI 的明示方式 / 分级烘焙粒度（按块 vs 按选中子集）与规模上限数字 / 烘焙命令撤销粒度（整体一次回退 vs 分批）/ 原派生渲染的移除时机。
