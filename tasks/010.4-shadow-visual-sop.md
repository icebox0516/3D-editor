## Goal

把 T009.5 落地的公共 Shadow 能力与 T009.7 验收口径固化为规范：后续资产按 SOP 生产即达标。

## Requirements

- **Shadow 公共能力规范**：InstanceSource 深度材质通道使用规范（正式放置对象必须支持 / Ghost 不要求投影只要求不破坏契约 / 散布仅契约兼容的口径）、dispose 语义清单
- **十项视觉检查单**：树种辨识度 / 树形自然度 / 枝干结构 / 叶片叶簇结构 / 冠层空隙 / 材质真实度 / 风动自然度 / 阴影 / 形态差异 / 性能
- **固定机位取证规范**：正面 / 侧面 / 45° / 近 / 中 / 远
- **性能验收流程模板**：RTX 2080 Ti 开发档条件、棵数阈值表、资源契约五条、记录指标两档——必测 Frame Time / FPS / Draw Call / CPU 时间 / renderer.info 资源计数；GPU 时间 / 显存仅在可可靠测量时记录、unavailable 如实标注（与 009.7 同口径，不作伪精确指标）
- **新增植物资产 SOP**：Reference Research 前置（每树种独立参考，不得沿用他树）→ 结构分析 → 参数化规则 → 程序化几何 / Shader → 固定机位视觉验证 → 用户/主代理最终裁定
