# T021.6 Broadleaf Canopy Proxy

> 状态：**pending（2026-09-23 立项）** ｜ Epic：[021-lod-representation](021-lod-representation.md) ｜ 前置：021.1（几何面独立，可与 021.2–021.4 并行）

## Goal

统一远景冠层表示：先从 13 个树种几何文件抽出共享冠层场契约（现各文件独立定义、无共享类型），再实现 BroadleafCanopyProxy（几何 + 材质 + 深度材质），首批接入 T011 全部树种。目标不是更低面数的树，而是最低成本保持树冠轮廓、体量、绿色覆盖率与树种级冠形。

## Research Gate

豁免（epic 级记档：非新程序化资产——从现有 T008/T011 族与各树 Reference Spec 派生，现实事实已在既有 Spec 留痕）。

## 待裁决位

- 面数预算 ≤500 / 树，含简化树干预柱（对照 Low 档再压一个量级）；锁定后回写 lod-spec §5.2 预算表 canopy 列
- 必须从现有 ClusterRecord / Low 档壳卡逻辑派生；禁止另建独立树冠生成体系；禁止每树种自写一套远景算法
- 风动契约：同一 uTime 驱动 + 首日声明并消费 aSeed / aBend（与高中档同相位原则一致）；散布几何缺 aSeed 属性时按缺省零——与散布链高中档当前行为逐位一致，D20.4 修复落地后零改动自动获得逐实例相位；禁止坐标哈希等第三套相位机制
- 材质简化受光：主光 lambert + IBL 环境项、树种级冠色 + 内外明暗梯度、共享 T018 envMap / intensity 域；禁止 unlit
- 散布侧按 assetId 粒度派生（散布链本无 shapeSlot 维度；树种级冠形差异即为远景保留目标）
- 保留外密内疏与基本阴影体量；不保留远景不可辨枝条 / 单叶细节 / 叶片 SDF
- Impostor 不实装：Canopy + 园区可见范围不达预算才立项后续子任务

## Scope

- `src/runtime/procedural/tree/` 共享冠层场契约 + BroadleafCanopyProxy 生成模块、13 树种接入点、canopy 材质与深度材质工厂（材质面 park-shader-agent / 几何面 procedural-asset-agent）、`docs/procedural-assets/lod-spec.md` 预算表、`tests/`（面数带 + 风相位一致 + 树种冠形差异 + tree3a 零回退）。
