# T018.1 Sky + Sun + Cloud Core

> 归属：[T018 真实程序化天空与环境光照](018-real-sky-environment.md) ｜ 状态：**done（2026-09-23，含 018.0 前置取证——threejs-runtime-agent 交付 + 主代理审查/复验/增量视觉验证）** ｜ 前置：018.0 Preflight Baseline（同会话先行完成，`docs/acceptance/t018/018.0/`）

## Goal

以官方 Sky（Preetham，r186 内建 Cloud）+ `sunDirectionOf(elevation, azimuth)` 纯函数双消费（Sky.sunPosition + DirectionalLight.position）取代「CanvasTexture 渐变背景 + 固定太阳 (80,120,60)」的天空与太阳核心：displaySky/bakeSky 双实例结构落地（本子任务实装 displaySky 侧与共享参数状态；bakeSky 实例随结构建立，PMREM 消费归 018.2），「天空太阳位 = 光向 = 影向」三一致为核验点。本子任务**不含 PMREM / scene.environment**（018.2）、**不含预设参数面转换与 Hemi 删除**（018.3）——环境光构成暂维持现状（Hemi + 新 DirectionalLight 并存的过渡态在 018.3 收口）。

## Requirements

- **018.0 Preflight Baseline 前置执行**（改渲染代码前，D31.7）：legacy 渐变天空完整参数快照 + day/dusk/night/tech 四预设 × 夏栎/朴树/香樟/路灯/GLB/金属固定机位快照 + frame time p95 基线 + renderer.info 资源账目 + 当前太阳方向记录，落 `docs/acceptance/t018/018.0/`（本会话 018.1 段完成，见完成记录①）。
- **sunDirectionOf 纯函数**：`(elevation°, azimuth°) → 单位方向向量`，node 可测（落点按 D27.5 先例——domain 零 THREE 或 runtime 纯模块，实施 agent 定）；day 首候选 elevation 50.2° / azimuth 53.1°（由现行 (80,120,60) 派生——新旧对比阴影方向零漂移；终值 018.5 视觉验收锁定）。
- **双实例结构（D29.12）**：displaySky 挂 envGroup / ENV_LAYER、受现有 Environment Layer / RenderMode 管理、相机中心跟随（渲染前 `sky.position.copy(camera.position)` 轻量维护，非 Scene 数据）；bakeSky 仅存于独立 environmentBakeScene（本子任务建场景与实例，PMREM 烘焙管线归 018.2）；两实例由同一份参数状态驱动，参数变更同步写双实例 uniforms。
- **内建 Cloud 消费（D29.11）**：直接消费 Sky 自带 `cloudCoverage / cloudDensity / cloudElevation / cloudScale`；第一阶段 **cloudSpeed = 0 静态云**且不接 time 驱动；太阳盘用内建 `showSunDisc`（displaySky 常开 / bakeSky 常闭）。
- **三一致双消费**：Sky.sunPosition 与 DirectionalLight.position 同出 sunDirectionOf——纯函数单测 + 运行时探针取证（天空太阳方位 / 灯位 / 影向同源）。
- **渲染遍兼容**：诊断模式（wireframe/xray/clay/normals）环境遍继续显示天空（ENV_LAYER 网格接替 scene.background 语义）；`renderMode.test.ts` 遍计划断言机械调整（useBackground 语义换口径，预期行为不变）。
- **过渡态边界**：本子任务后 legacy 渐变天空不再出现在正常路径（Sky 网格成为天空正式路径）；Hemi 环境光暂存（018.3 删除）；完整 legacy fallback 开关归 018.3（事务式单一开关），本子任务不做 fallback 分支。
