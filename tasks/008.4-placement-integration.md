# T008.4 放置全链路集成

> 归属：[T008 程序化树木](008-procedural-tree.md) ｜ 状态：**not-started** ｜ 前置：T008.1 + T008.2 + T008.3，**且视觉锚点门已过**（人工阻断门，未过不得启动本任务）

## Goal

`asset_tree_3a` 进产品：入库可浏览、点击放置、撤销/重做、存档往返、Inspector seed 重掷——兑现「点击资产即可在场景中生成一棵完整树木」。

## Requirements

- **入库 + 缩略图**：资产库入列（category = plant）；缩略图一张（slot-0 代表形态，走既有离屏快照机制；008.5 扩槽不增缩略图）
- **点击放置**：点击资产**那刻掷 seed S** → 槽路由（008.1 shapeSlotOf）→ Ghost 借对应 sourceKey 的缓存 Source（**Ghost 预览即最终形态**）→ 确认放置落同一 seed 进 `asset.seed`
- **撤销/重做**：放置/删除走既有 Command 链
- **存档往返**：seed 落盘、加载后 build 同槽重建**逐位一致**（io 序列化校验 + 往返单测）
- **复制定义（D19.8 精确语义）**：复制保留原 assetId + seed → 完全相同形态与实例参数，**仅 transform 可独立编辑**（不自动换 seed）
- **Inspector 最小面**：seed 只读行 + 「重掷」按钮（Dices 图标，模式照抄 T003.3 区域 seed 重掷）——走 Command 可撤销；重掷 = 新 seed 同时重算 shapeSlot + instanceRng（新 seed 允许路由回同一 slot：此时共享同一 Source、仅实例表现变化——正常行为非 bug）；结构参数不进 UI
- **交互闭环**：选资产 → 放置 → 看真实效果 → 重掷换一棵 → Gizmo 调位置姿态

## Scope

- 预期触碰：放置流程 seed 掷骰接入、Ghost 路由、io 序列化（asset.seed 已有范式，预计零 schema 改动）、InspectorPanel / 缩略图管线消费
- 不碰：契约层（008.1 冻结）、几何/材质（锚点已定稿）

## Acceptance

- 端到端：入库可见缩略图 → 点击放置出树（Ghost = 所得）→ 重掷按新 seed 重算（允许落回同槽仅换实例参数）→ 复制得孪生（仅 transform 可调）→ undo/redo 全链复原 → 存档重载逐位一致
- 撤销链作用域正确（重掷/复制/删除皆可撤销）
- `npm test` / `check:layers` / `typecheck` 全绿；浏览器冒烟 console 零错误

## Constraints

- three 分层；UI 遵循 `src/ui/styles/` 设计系统；一切持久变更经 Command（Scene 唯一数据源）
- 主代理主导 + 按需小派发（放置链路多为既有通路复用）
