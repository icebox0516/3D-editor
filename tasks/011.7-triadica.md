## Goal

乌桕（Triadica sebifera，大戟科乌桕属；旧口径 Sapium sebiferum——命名切换记档）生产资产 `asset_tree_triadica`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证。**心形/菱状叶新叶形语言**（第七种叶形——全缘连续轮廓族内再分化）+ **叶柄/叶基腺体**（大戟科身份特征——微观结构表达判定）+ **白果序**（蒴果三裂 + 种子白蜡层宿存——生长季可见性以 Spec 定，建模判定参照悬铃木果序先例账目法）。长江流域乡土树种。**秋色红为身份标志但生长季建模不表达**（记档口径，同 011.6 秋叶纪律）。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外 D31.2）。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 44(3):14（候选池已钉死卷页——旧口径 Sapium sebiferum，自行复核原句）/ FOC Vol.11（候选池强证据锚 widely cultivated，自行复核原句；FRPS 旧属名与 FOC Triadica 口径差异记档）；形态材质变体 → 真实照片直接视觉证据。重点调研面：**命名口径**（Triadica sebifera vs Sapium sebiferum——FOC/APG 现口径与 FRPS 旧口径，锚定现用名记档）；**叶形**（菱状卵形/近心形/卵形哪种为主？长宽 cm、全缘？、先端长尖？、叶柄长 cm 与**顶端 2 腺体**〔位置/尺度/可见性〕、羽状脉中脉显隐）；**秋色红**（色相范围、秋期——记档不建模）；**果序**（蒴果梨状球形径 cm、三棱/三裂、成熟节奏（绿→黑褐）、**种子白蜡层**宿存时间窗、生长季夏末可见性 → 建模判定证据链）；**花**（总状/穗状花序、黄绿色、花期、生长季可见性 → 建模判定）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；冠形）；**树皮**（色与纹理——vs 六先例语言定位）；**枝姿**（大枝角度/小枝细？）；**叶色**（正/背面色差）。

- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/triadica/triadicaMaterials.ts`——**心形/菱状叶 SDF**（最小扩展限定文件内、记缺口候选）+ 全缘 or 细齿载波（按 Spec）+ 脉型 + 叶色（正/背色差）+ 背光透射 + 风动两层 + **腺体材质表达**（若做）+ **果序材质**（若做：绿蒴果→干色、白蜡种子点）+ 树皮配方（按 Spec 定位 vs 六先例）+ 深度材质同源 GLSL + 9 键分档。
