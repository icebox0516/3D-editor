# T011.7 乌桕全链（第七树）

> 归属：[T011 阔叶乔木族生产任务集合](011-broadleaf-trees.md) ｜ 状态：**排产（011.6 done 后新会话启动；标准模式——D35 连续生产轮已终止（D35.1），一会话一子任务）** ｜ 前置：011.6 done；Step 4 按 D30 增量口径

## Goal

乌桕（Triadica sebifera，大戟科乌桕属；旧口径 Sapium sebiferum——命名切换记档）生产资产 `asset_tree_triadica`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证。**心形/菱状叶新叶形语言**（第七种叶形——全缘连续轮廓族内再分化）+ **叶柄/叶基腺体**（大戟科身份特征——微观结构表达判定）+ **白果序**（蒴果三裂 + 种子白蜡层宿存——生长季可见性以 Spec 定，建模判定参照悬铃木果序先例账目法）。长江流域乡土树种。**秋色红为身份标志但生长季建模不表达**（记档口径，同 011.6 秋叶纪律）。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外 D31.2）。

## Research Gate 判定（D26，开工前留痕）

- **判定：强制调研**。命中情形：①高真实要求（叶形+腺体+白果为乌桕独有身份组合）；②类型显著影响形态（心形/菱状叶形语言 + 叶柄腺体微观结构 + 果序第二先例）；⑤资产将成同类生产基准。
- **执行**：通用子代理加载 asset-research 技能 → `docs/research/triadica-reference.md`；主代理硬数值独立抽查（≥12 条对照 iplant/FOC 原句）+ 照片终审（关键照片异系统交叉；判读前确认图片实际加载成功、尺度主张须像素内参照物——D35 轮流程教训并入标准流程）；分歧取中庸、终审记档追加于 Spec 文末。
- **Spec Version 锚点：1.0**——开发 Agent 开工前校验一致。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FOC Vol.11（候选池强证据锚 widely cultivated，自行复核原句）/ FRPS 44(3)?（卷页由调研确认——乌桕旧属 Sapium 在 FRPS 的卷页与 FOC Triadica 口径差异记档）；形态材质变体 → 真实照片（异系统交叉）。重点调研面：**命名口径**（Triadica sebifera vs Sapium sebiferum——FOC/APG 现口径与 FRPS 旧口径，锚定现用名记档）；**叶形**（菱状卵形/近心形/卵形哪种为主？长宽 cm、全缘？、先端长尖？、叶柄长 cm 与**顶端 2 腺体**〔位置/尺度/可见性〕、羽状脉中脉显隐）；**秋色红**（色相范围、秋期——记档不建模）；**果序**（蒴果梨状球形径 cm、三棱/三裂、成熟节奏（绿→黑褐）、**种子白蜡层**宿存时间窗、生长季夏末可见性 → 建模判定证据链）；**花**（总状/穗状花序、黄绿色、花期、生长季可见性 → 建模判定）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；冠形）；**树皮**（色与纹理——vs 六先例语言定位）；**枝姿**（大枝角度/小枝细？）；**叶色**（正/背面色差）。
- **Step 1 结构分析**：Spec → 六先例方法基线对照——可继承 / 改写 / Unknown；**心形/菱状叶 SDF 可行性预判**（现有六叶形语言域内 or 新路径——最小扩展限定文件内）；**腺体表达路径判定**（卡面纹理层 or 几何 or 不做——近景读出价值 vs 预算）；**果序表达路径判定**（若做——悬铃木果序先例：入组 0 + uv 域身份标记 + 账目法）。
- **Step 2 参数化**：`tree/triadica/triadicaShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量。
- **Step 3 几何（procedural-asset-agent）**：`tree/triadica/triadicaGeometry.ts`——方法复制 + 乌桕算法细节（叶挂点密度语言按 Spec/果序若做按先例/冠形枝姿按 Spec）；LOD 三档同流；入口 `assets/asset_tree_triadica.asset.ts`（meta 同契约）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/triadica/triadicaMaterials.ts`——**心形/菱状叶 SDF**（最小扩展限定文件内、记缺口候选）+ 全缘 or 细齿载波（按 Spec）+ 脉型 + 叶色（正/背色差）+ 背光透射 + 风动两层 + **腺体材质表达**（若做）+ **果序材质**（若做：绿蒴果→干色、白蜡种子点）+ 树皮配方（按 Spec 定位 vs 六先例）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/triadica/triadicaStage.ts` 同构 + bootstrap `window.__triadica`；VIEW_TARGET_Y 几何实测定档；缺口 D 评估（树皮门控判定）。
- **Step 4 视觉验证（主代理，D30 增量口径）**：三必做（①身份判定：心形/菱状叶读出 + 冠形 + 树皮 + 果序若做可见性；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.7/`；③缺口记档归 011.13）+ 疑点触发（叶形近景读出/腺体若做近读/果序若做可见性/风动三证据/console/LOD 档间）；校准默认一轮、两轮封顶。
