# T009.1 枝干结构真实性

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**not-started** ｜ 前置：T008.6（参考基准）

## Goal

建立夏栎内部结构参数面（shapeProfile）并升级枝干结构真实性：主枝 > 次枝 > 末枝视觉权重可感知；**冠内空间通透规则显式化**——建立枝干通道、内层密度衰减与局部空腔控制，而非固定挖空。

## Requirements

- **shapeProfile 参数面**：crownCenter / crownHeight / crownWidth / mainBranchSpread / asymmetry / canopyDensity / crownTopBias 等（字段集结合 T008.6 参考分析定稿）；008.2 的 LEVELS / TRUNK / CHILD_PLAN / LEAF 硬编码常量改造为 shapeProfile 消费
- **主次分级**：一级骨架枝与末梢枝的视觉权重拉开（在现有首枝主导 ×1.08 基础上强化层级对比）——所有分枝视觉权重接近即不达标
- **冠内通透**：显式规则替代「叶卡只挂外段」的涌现式空腔——枝干通道（主干大枝进冠不被封死）、内层密度衰减、局部空腔控制
- **slot-0 锚点重校**：以标准组合初值重校 slot-0，锚点基准可辨识（还是那棵夏栎，结构更可信）

## Scope

- 预期触碰：`src/runtime/procedural/tree/broadleafGeometry.ts`、`src/runtime/procedural/assets/asset_tree_3a.asset.ts`（slot → 结构配置路由）
- 不碰：契约层（InstanceSource / sourceKey 语义）、材质（tree3aMaterials 只消费不动）

## Acceptance

- slot-0 过结构验收：主干自然 / 层级清晰 / 粗细递减 / 冠内通透可见（对照 T008.6 参考表「已符合/偏差」项）
- 固定机位取证存档；结构计数测试锁同步更新（同槽确定性原则延续：同 asset + slot + level 生成完全相同 Geometry、同槽重复构建面数恒等；跨 slot 面数差异为 8 槽形态向量的设计预期，受 009.6 LOD 预算约束，不作恒等要求）
- **面数不作硬验收**：记录实际面数，仅在显著超出现有 32K 量级时回落；正式 High/Mid/Low 预算由 009.6 锁定
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- **建立夏栎内部结构参数面，不扩展 ProceduralBuild 公共参数；build 仅负责将 slot 路由到对应结构配置**（防子代理自行发挥扩公共签名）
- D19 契约第一锁不破；同 seed 逐位复现、同槽同引用测试延续
