# T003.2 分块实例化管线

> 归属：[T003 Scatter Styles](003-scatter-styles.md) ｜ 状态：**done（2026-09-16）** ｜ 前置：T003.1（+ T002.1 冒烟资产作测试源）

## Goal

chunk 基础设施（D9）：空间分块为剔除 / 局部重算 / 合批的基本单元——散布渲染的承重墙。

## Requirements

- **chunk 划分**：固定尺寸网格（常量可调，如 32m），区域跨块自动归属
- **实例管理**：撒点输出按块归属；块内按 assetId 合批为 InstancedMesh（每 块×资产 一个批次）
- **逐块视锥剔除**：视锥外块零提交（不可见不渲染不参与拾取）
- **局部重算**：区域编辑（顶点/参数/seed 变更）→ 只重撒受影响块，其余块实例矩阵不动
- **块生命周期**：创建 / 更新 / 销毁 / 复用（块空了回收，区域回来重建）；与场景对象增删同步
- **确定性**：块重撒结果与整片重撒一致（同 seed）

## Scope

- 新建：runtime 分块实例化模块；冒烟集成路径（撒点函数 → 分块 → 渲染可见）
- 明确不做：样式/序列化集成（003.3）、LOD 分档（T006）、拾取映射到区域（003.3）

## Acceptance

- 块生命周期单测全绿（含跨块区域编辑、块回收重建、确定性比对）
- 冒烟：一块区域散冒烟资产渲染可见；相机转出视锥后该块 draw call 归零（renderer 统计断言）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- three 只允许 `src/runtime` / `src/app`；渲染实现派发 `threejs-expert` 子代理
- 散布实例不进场景对象表 / 撤销栈 / 大纲（D5，管线内部数据）

- **合批形态**：每 (源×块×资产) 一个 InstancedMesh 挂块 Group（持块 AABB）挂 manager root；root 挂 `renderer.scene`（contentGroup 兄弟）→ RuntimeViewport 只 raycast contentGroup.children，散布实例天然不参与拾取、不携带 userData.objectId（D5）。容量仿池：翻倍扩容换缓冲不换 mesh 对象、缩容保留容量；(块×资产) 实例归零即拆网格、块整空回收块 Group。异步源仿池：未就绪登记 pending、到达补建网格、失败告警一次不重试。
- **局部重算机制**：recomputeChunks 不触碰未列块（其 instanceMatrix 逐位不动，单测 Float32Array 快照锁定）；被列块与新参数全量重建逐位一致（对照管理器锁定）。computeAffectedChunks = bbox(old)∪bbox(new) 各外扩影响半径（edgeFalloff + clusterRadius + clusterStep，聚簇层关闭时簇项不计）的覆盖块去重升序——多边形逐点相等但全局参数变的情形，外扩并集天然 ⊇ bbox 覆盖 = 全部块；参数完全相等 → []。顶点编辑的受影响集按 bbox 并集保守（未按移动顶点局部化——003.3 可在调用方细化，机制已就位）。
- **剔除盒实现修正**（实现中发现）：块 AABB 不用 `boundingSphere.getBoundingBox`（球的包围盒按对角线膨胀 ~√2，32m 块胖出 ~12m 致边缘块误可见）；改为写矩阵槽时顺带累积逐实例紧致 AABB（逐轴最大绝对角偏移对任意 Y 旋转恒为有效包围，零额外遍历）。`computeBoundingSphere` 仍收尾调用（three 逐对象剔除用，扩容换缓冲后陈旧球会被渲染器误剔除）。
- **逐实例色**：`getAssetVariants` 注入 → hueJitter>0 时 `applyAssetVariants(variants, variantSeed)` 只取 hueOffset → `hueOffsetToMultiplier` 写 instanceColor（同 T002.3 语义；散布不二次掷 scale/rotation——撒点参数已管，注释锁定）；无声明不建颜色缓冲（GLB 零变化）。
