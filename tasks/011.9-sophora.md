## Goal

国槐（Styphnolobium japonicum〔现用名；FRPS 口径 Sophora japonica——命名切换记档〕，豆科）生产资产 `asset_tree_sophora`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证。**奇数羽状复叶（一回）——复叶第三型**（011.6 二回羽状/011.8 三出之后的直接羽状轴系，复叶表达路径沿 011.6 先例结论由 Step 1 判定沿承 or 分化）+ 冠大荫浓伞形/圆形冠（华北乡土庭荫树典型）+ 淡黄白色花（花期生长季可见性以 Spec 定）+ 念珠状荚果（冬宿存——生长季可见性以 Spec 定，参照先例账目法）。D33 点名候选。龙爪槐垂枝栽培变体**记档不建模**（垂枝域归 011.12 垂柳应力位，本树为自然冠）。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外 D31.2）。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 40:92（Sophora japonica 口径，自行复核原句）/ FOC（Styphnolobium 属归置卷页由调研确认）；形态材质变体 → 真实照片（异系统交叉——011.6 教训：拼贴快筛不可承重、判读须逐张原图）。重点调研面：**命名口径**（Styphnolobium japonicum vs Sophora japonica——FOC 拆属与 FRPS 传统口径，锚定现用名记档）；**奇数羽状复叶**（小叶数枚范围、小叶形态〔卵状披针形/卵状长圆形？〕长宽 cm、小叶柄/对生互生、缘全缘？、先端尖？、脉型——豆科羽状脉）；**冠形与体量**（中龄公园个体树高/冠幅/干高——≈8–12m 族量级锚定；圆形/伞形冠？冠大荫浓读向；大枝轮生/螺旋？）；**枝姿**（小枝绿色/棱？——国槐一年生枝绿色为身份特征候选，文献确认；大枝角度）；**树皮**（灰黑色/灰褐色、纵裂/网状裂？——vs 先例语言定位）；**花**（圆锥花序尺度、着生位（顶生/侧生？）、淡黄白色、花期 7–8 月生长季可见性 → 建模判定）；**荚果**（念珠状肉质、长 cm、节数、宿存冬挂、生长季夏末可见性 → 建模判定记档）；叶色（深绿/蓝绿读向？正背色差）；变体（龙爪槐垂枝——记档不建模）。
- **Step 1 结构分析**：Spec → 先例方法基线对照（011.6/011.8 复叶先例结论重点对照）——可继承 / 改写 / Unknown；**一回羽状复叶表达路径判定**（沿 011.6 复叶先例路径 or 分化——直接羽状轴系 vs 011.6 二回结构的裁剪复用，最小扩展限定文件内）；花/荚果表达路径判定（若做——先例账目法）。
- **Step 2 参数化**：`tree/sophora/sophoraShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量。
- **Step 3 几何（procedural-asset-agent）**：`tree/sophora/sophoraGeometry.ts`——方法复制 + 国槐算法细节（羽状复叶挂点按 Step 1 判定路径/花果若做按先例/伞形冠/枝姿按 Spec）；LOD 三档同流；入口 `assets/asset_tree_sophora.asset.ts`（meta 同契约）。
