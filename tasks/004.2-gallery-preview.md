# T004.2 画廊 + 悬停预览

> 归属：[T004 Style Gallery](004-style-gallery.md) ｜ 状态：**not-started** ｜ 前置：T004.1

## Goal

D14 主体交付：样式画廊面板（缩略图卡片网格 / 要素过滤 / 搜索）+ 悬停实时预览 + 点击应用 + 双 Tab 入口。

## Requirements

- **画廊组件**：卡片网格（缩略图 + 名称）、按选中区域语义过滤可用样式 + 通用样式分组、搜索框
- **悬停实时预览**：悬停卡片 → 选中区域**临时**应用该样式（预览态：不经命令、不入历史、移出即恢复）；快速划过多卡片场景一致无泄漏；散布型样式预览含散布内容（允许降采样预览保证流畅）
- **点击应用**：经命令落地（可撤销）；与 Inspector 参数区联动刷新
- **入口**：资产浏览器区域双 Tab（资产 / 样式），状态记忆（会话内）
- **空态**：无选中区域时画廊只读浏览（提示先选区域）

## Acceptance

- 交互全通；快速划过 5+ 卡片后场景状态与原状一致（无泄漏断言）
- 应用经命令可撤销；画廊 ↔ Inspector 一致
- 40+ 预设滚动/过滤/搜索流畅；三重门槛全绿

## Constraints

- UI 先读 frontend-design 技能；设计系统 + lucide-react；预览态严禁旁路命令系统落地持久变更
