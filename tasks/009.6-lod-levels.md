# T009.6 夏栎 LOD 三档

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**not-started** ｜ 前置：T009.2 + T009.3 + T009.4（几何终态）

## Goal

夏栎 High / Mid / Low 三档 build：levels 从占位变实装（夏栎侧），档间身份一致（同一棵树远近都是那棵树）；**预算实测锁定为本任务输出**。

## Requirements

- **三档质量取舍**：Mid 降枝条段数 / 叶簇数量 / 叶卡数量 / Shader 复杂度；Low 只保树冠轮廓 + 颜色层次 + 整体风格（不保持内部枝条）
- **预算锁定**：以候选区间（High 30–40K / Mid 6–10K / Low 1.5–3K 三角形）为初始参考，结合最终结构、性能实测与观感锁定正式预算，写回 asset meta（预算制，D19.8 口径——三档实际面数须符合锁定值）
- **level 契约（防实现者自行设计）**：level 作为 Procedural Build 的可选 Runtime 参数扩展——`build({ seed?, preset?, level? })`；**sourceKey 仍只表达 assetId + preset + shapeSlot**，Runtime Cache 以「sourceKey + level」为档位缓存维度；level 不参与 shapeSlot / morphSeed / sourceKey 计算；旧资产 `build()` 无参调用继续兼容
- **档位缓存**：档位几何独立缓存、独立释放
- **档间一致**：轮廓 / 体量 / 颜色一致，档间切换无身份变化
- **T006 接缝**：距离切换 / 分块消费归 T006（006.1 / 006.2）实装；本任务交付档位声明 + 可按参数强制档位生成验证，不自带切换逻辑

## Scope

- 预期触碰：`broadleafGeometry.ts`（档位参数）、`tree3aMaterials.ts`（Shader 档）、`asset_tree_3a.asset.ts` meta levels、ProceduralSourceCache（level 维度缓存）
- 不碰：T006 的切换/分块实现、契约第一锁

## Acceptance

- 三档可生成、实际面数符合锁定预算、法线健康
- 档间色/形连续（强制档位渲染取证，截图比对辅助）
- 档位独立缓存 / 释放验证；同 seed 逐位复现延续；`npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- **LOD Source 在 Runtime 中增加独立 level 维度；不得改变 D19 sourceKey 的形态身份语义**（不得把 level 掺进形态身份）
- LOD 是统一 Asset Runtime 能力而非「植物 LOD」——不同资产不同预算（D20）
