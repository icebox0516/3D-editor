# T009.7 夏栎四类验收门

## Goal

夏栎生产级四类验收收官（结构 / 视觉 / 变体 / 性能）+ 回归——完成「第一棵标准植物资产」的验收闭环。

## Requirements

- **结构验收**：主干自然 / 枝干层级清晰 / 枝条粗细递减 / 叶簇与枝梢明确关系 / 冠内通透（对照 T008.6 参考表逐项过检）
- **视觉验收**：近 / 中 / 远三距离 × 轮廓 / 枝干 / 叶簇 / 叶片 / 树皮 / 阴影六要素，固定机位取证
- **变体验收**：8 槽明显不同、仍属同一树种（引用 T009.3 取证复核）
- **性能验收**（RTX 2080 Ti 开发档，1920×1080 / DPR=1 / Chromium / WebGL2 / 固定场景相机灯光 / Shadow 开启）：1 / 20 / 100 / 500 / 1000 棵实测，阈值 1/20/100 ≥60 FPS、500 ≥45 FPS、1000 ≥30 FPS；必测 Frame Time / FPS / Draw Call / CPU 时间 / Shadow 成本 / renderer.info 资源计数（geometries/textures 为计数非字节）；GPU 时间、实际显存占用仅在目标环境具备可靠测量手段（如 EXT_disjoint_timer_query_webgl2 且无 disjoint）时记录，否则如实标记 unavailable，不作伪精确指标；资源契约五条逐项验证（同 sourceKey 不重复创建、500/1000 保持 InstancedMesh 路径、不退化逐对象 Mesh、删除无残留、连续 10 次放置删除无持续增长）
- **回归**：GLB 与旧植物/设施资产零变化；`npm test` / `check:layers` / `typecheck` 全绿
- **取证**：全套存 `docs/acceptance/t009/`；性能数据表落档（含机器/浏览器/驱动环境说明；2080 Ti 为开发基准不作全平台承诺）
