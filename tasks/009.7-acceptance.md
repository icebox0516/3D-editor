# T009.7 夏栎四类验收门

> 归属：[T009 夏栎结构真实性与生产化](009-tree-realism.md) ｜ 状态：**not-started** ｜ 前置：T009.1–T009.6 全部

## Goal

夏栎生产级四类验收收官（结构 / 视觉 / 变体 / 性能）+ 回归——完成「第一棵标准植物资产」的验收闭环。

## Requirements

- **结构验收**：主干自然 / 枝干层级清晰 / 枝条粗细递减 / 叶簇与枝梢明确关系 / 冠内通透（对照 T008.6 参考表逐项过检）
- **视觉验收**：近 / 中 / 远三距离 × 轮廓 / 枝干 / 叶簇 / 叶片 / 树皮 / 阴影六要素，固定机位取证
- **变体验收**：8 槽明显不同、仍属同一树种（引用 T009.3 取证复核）
- **性能验收**（RTX 2080 Ti 开发档，1920×1080 / DPR=1 / Chromium / WebGL2 / 固定场景相机灯光 / Shadow 开启）：1 / 20 / 100 / 500 / 1000 棵实测，阈值 1/20/100 ≥60 FPS、500 ≥45 FPS、1000 ≥30 FPS；记录 Draw Call / GPU 时间 / CPU 时间 / 显存 / Shadow 成本 / Frame Time；资源契约五条逐项验证（同 sourceKey 不重复创建、500/1000 保持 InstancedMesh 路径、不退化逐对象 Mesh、删除无残留、连续 10 次放置删除无持续增长）
- **回归**：GLB 与旧植物/设施资产零变化；`npm test` / `check:layers` / `typecheck` 全绿
- **取证**：全套存 `docs/acceptance/t009/`；性能数据表落档（含机器/浏览器/驱动环境说明；2080 Ti 为开发基准不作全平台承诺）

## Scope

- 验收驱动（产品放置路径 + agent-browser/截图 + renderer.info）；无新功能面

## Acceptance

- 四类验收 + 回归全项过 = T009 收官（7/7），T008.5 收官门解锁
- 进程用完即清（dev server / 浏览器标签不留跨会话残留）

## Constraints

- 性能验收走产品放置路径（池）而非仅 DEV 舞台
- 主代理执行验收门；观感裁定归用户
