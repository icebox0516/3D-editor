# T005 Animation Pathway

## Goal

时间维度进编辑器（D12）：轻通路（全局时钟 + uTime 广播）+ 全套表现（水面流动 + 植被风摆）——散布与手动放置的实例统一生效。

## Requirements

- **uTime 广播服务**：渲染循环维护全局时钟；材质声明 uTime uniform 即自动被驱动（注册式广播，非逐实例 JS tick）；连续渲染循环语义不变
- **水面流动**：水面预设接 uTime——流速/波幅参数化（StyleParameter 既有四控件可表达）；示范「轻通路让静态预设活起来」
- **植被风摆**：顶点着色器按实例相位摆动（相位从 T002/T003 落盘的 seed / 实例色派生，零新增数据）；摆幅/频率参数化；散布实例与手放置实例统一生效；远距离摆动可视衰减可选
- **静态零成本**：未声明 uTime 的材质零额外开销；广播服务可全局暂停（截图取证/导出快照时帧稳定）

## Scope

- 新建：时钟服务 + uTime 广播、风摆 shader 注入（程序化植物材质统一挂载点）
- 预期触碰：渲染循环（时钟推进）、水面预设、植物 generator 材质
- 依赖：T002（植物资产与 seed）、T003（散布实例相位源）

## Acceptance

- 水面持续流动且流速参数实时可调；树摆自然（无同步「集体体操」感，相位各异）
- 暂停广播后连续两帧截图逐字节一致（帧稳定证明）
- 未启用动画的既有 24 套预设行为零变化（回归）
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 不做 JS 逐实例每帧回调（D12 明确排除）
- 渲染循环保持每帧连续渲染（勿改按需渲染）；`Renderer.dispose` 禁 `forceContextLoss`
- 渲染任务按 AGENTS.md 路由派发子代理：uTime 广播服务/渲染循环集成派 `threejs-expert`，水面流动与植被风摆的 shader 实现派 `park-shader-agent`；动画观感必须浏览器截图验收（像素证据不可替代）
