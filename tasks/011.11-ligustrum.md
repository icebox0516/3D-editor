女贞（Ligustrum lucidum，木犀科女贞属）生产资产 `asset_tree_ligustrum`：Research Gate → Reference Spec → 阔叶家族契约实例化 → 几何 / 材质 / 8 槽形态向量 / LOD 三档 / Shadow 通道 → D30 增量视觉验证。**常绿第二例**（香樟后——常绿语义 = 密度参数 + 材质表达，家族无语义位先例沿 011.2 缺口 A 口径）+ **革质光泽叶**（卵形/卵状披针形全缘——革质 specular/envMap 表达沿 011.2 缺口 B 口径）+ 白花圆锥花序/核果（生长季可见性以 Spec 定，建模判定参照先例账目法）。长江以南城市绿化主力。继续发现并记档家族契约缺口（默认零修订、归 011.13；阻塞例外 D31.2）。

## Requirements

- **Step 0 调研落盘**：八节骨架 + plant 域扩展节；两轴标注；结构尺度 → FRPS 61:153（自行复核原句）/ FOC Vol.15（卷页由调研确认）；形态材质变体 → 真实照片（异系统交叉）。重点调研面：种定名（L. lucidum vs 日本女贞 L. japonicum 近缘种判据——叶形/花冠裂片/果形；「大叶女贞」苗市俗名口径记档）；**常绿性表达**（全年绿叶相 + 冠层密度/叶面反光观感——vs 香樟先例的密度参数与材质表达口径）；**革质叶**（卵形/卵状披针形？长宽 cm、全缘？、先端渐尖？、表面光泽（革质 specular 观察）、羽状脉显隐、叶柄长）；**花**（圆锥花序尺度、顶生？、白色、花期、生长季可见性 → 建模判定）；**核果**（肾形/椭圆形、径 cm、成熟色（紫黑？）、果期窗口、夏末可见性 → 建模判定记档）；**冠形与体量**（中龄公园/行道个体树高/冠幅/干高——≈8–12m 族量级锚定；卵圆形冠？；分枝点高低）；**树皮**（色与纹理——vs 先例语言定位）；**枝姿**（大枝角度/小枝）；**叶色**（深绿革质光泽/背面色差）。
- **Step 1 结构分析**：Spec → 先例方法基线对照（香樟常绿先例重点对照）——可继承 / 改写 / Unknown；革质光泽表达路径判定（011.2 缺口 B 口径下限内 or 最小扩展）；花/果表达路径判定（若做——先例账目法）。
- **Step 2 参数化**：`tree/ligustrum/ligustrumShapeProfile.ts`——BroadleafShapeProfile 填值（逐字段 Spec 依据 + Evidence Status + 三标注；证据中档轴弱推断如实标注）；结构计数类跨槽恒等；slot-0 锚点 + 7 槽差量。
- **Step 3 几何（procedural-asset-agent）**：`tree/ligustrum/ligustrumGeometry.ts`——方法复制 + 女贞算法细节（常绿密度语言沿香樟先例/冠形枝姿按 Spec/花果若做按先例）；LOD 三档同流；入口 `assets/asset_tree_ligustrum.asset.ts`（meta 同契约）。
- **Step 3 材质（park-shader-agent，与几何文件集不相交并行）**：`tree/ligustrum/ligustrumMaterials.ts`——卵形/卵状披针形全缘 SDF（现有域内 or 最小扩展）+ 革质光泽（specular 档位 vs 香樟 011.2 校准值口径）+ 脉型 + 叶色深绿 + 背光透射（常绿厚叶低透）+ 风动两层 + 花序材质（若做：白色簇面）+ 核果材质（若做）+ 树皮配方（按 Spec 定位）+ 深度材质同源 GLSL + 9 键分档。
- **Step 3 DEV 出图面（threejs-runtime-agent，合并后）**：`tree/ligustrum/ligustrumStage.ts` 同构 + bootstrap `window.__ligustrum`；VIEW_TARGET_Y 几何实测定档；缺口 D 评估。
- **Step 4 视觉验证（主代理，D30 增量口径）**：三必做（①身份判定：常绿深绿冠 + 革质光泽近读 + 卵形全缘叶 + 冠形；②baseline.png M25 + day + freezeTime 落 `docs/acceptance/t011/011.11/`；③缺口记档归 011.13）+ 疑点触发（光泽读向/密度读向（vs 香樟横向对照）/花果若做可见性/风动三证据/console/LOD 档间）；校准默认一轮、两轮封顶。
