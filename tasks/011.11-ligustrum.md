## 重点调研面（本树特有）

- **种定名**：L. lucidum vs 日本女贞 L. japonicum 近缘种判据（叶形 / 花冠裂片 / 果形）；「大叶女贞」苗市俗名口径记档
- **常绿性表达**：全年绿叶相 + 冠层密度 / 叶面反光观感——vs 香樟先例的密度参数与材质表达口径
- **革质叶**：卵形 / 卵状披针形？长宽 cm、全缘？、先端渐尖？、表面光泽（革质 specular 观察）、羽状脉显隐、叶柄长
- **花**：圆锥花序尺度、顶生？、白色、花期、生长季可见性 → 建模判定｜**核果**：肾形 / 椭圆形、径 cm、成熟色（紫黑？）、果期、夏末可见性 → 建模判定记档
- **冠形与体量**：中龄公园 / 行道个体树高 / 冠幅 / 干高——族量级锚定；卵圆形冠？；分枝点高低
- **树皮**：色与纹理——vs 先例语言谱系定位｜**枝姿**：大枝角度 / 小枝｜**叶色**：深绿革质光泽 / 背面色差

## 待裁决位（Step 1 判定记档，2026-09-22 主代理——依据 Spec 1.0 + 终审修正口径）

1. **核果：做**。先例账目法三判据全过——属相内显著性（FRPS 裁定句直接以果形定种：肾形 vs japonicum 椭圆形，果形 = 种级身份）+ 生长季主语境覆盖（果期 7 月至翌年 5 月完全覆盖 9–10 月主语境；照片四点色序链 9 月绿果→10 月紫黑→12 月冠内→2 月宿存）+ 家族独有性（家族果谱无肾形白粉浆果位）。表达 = **满冠下垂密簇账目**（fraxinus 帘幕带判据同型改写：满冠带 q 阈值 + posHash → STRIDE + 每簇多果；果簇卡入皮组 + uv 果域标记；视觉密度档「数十果/序」——绝对数不承重，终审口径）。
2. **花：不做**（记档）。信号强（盛花覆盖冠面 10–30%）但花期 5–7 月不覆盖 9–10 月主语境（对照栾 7–9 月覆盖而做 / 国槐 7–8 月弱信号不做——时窗错位即不做）；常绿身份由密冠 + 革质光泽 + 果序三信号承托；低频变体档不做（家族无季节变体基础设施，不为此单树扩展）。
3. **革质光泽：沿 011.2 缺口 B 口径下限内**（roughness 档位调参，不引入 envMap / 公共 specular 方案——缺口维持归 011.13）；分化点 = **上面强光泽 + 背面无 glaucous**（「单面镜」vs 樟「亮面+粉背」：背面不提亮偏冷、两面色差取弱档淡绿级）。
4. **常绿密度语言：沿香樟先例数值面**（空隙收束档 5–15% vs 樟 10–15% 同密档；团块 1/6–1/4 冠宽 vs 樟 1/8–1/10——女贞团块略大、冠面更整块，簇参数承载）。
5. **对生单叶挂点：沿 fraxinus decussate 机制直接继承**（对内共享节位 + 90° 交替方位 + 抖动；单叶卡替代复叶卡）——**对生单叶 = 家族首例挂点语言**（叶层面 vs 白蜡复叶层面共享「对生」位）。
6. **叶 SDF：沿 camphor 全缘零齿载波路径改写**（卵形-长卵形-椭圆包络 + 先端锐尖-渐尖变指数域宽于樟 + 全缘平坦零载波；**侧脉细弱不显近零信号 + 无腺窝无离基三出**——叶材质面较樟简化；长宽比域 1.7–2.8）。
7. **树皮第 12 语言**：灰褐基 + 细窄纵脊浅沟**低浮雕**（沟深低于樟深纵裂、脊细于白蜡）+ 干面细纹浅色质感（bark-a「fine maple-like」）——谱系独立位。
8. **小枝两档**：当年生枝黄褐-红调（FRPS「枝黄褐色、灰色或紫红色」+ 照片红铜新梢）vs 老枝灰褐——fraxinus 两档分明先例同法。
9. Unknown 留档：scaffold_count 无照片计数判读——取族典型域并标【工程设定无现实基准】；芽不建模（Spec Unknown，常绿密冠语境信号弱）；骨干枝定量族同缺口。
10. slot-0 锚：**树高 ≈8m**（终审维持——form-d 双系统一致建筑参照 + NC 域 + 族量级锚）；冠幅比 0.75–0.85；干高占比 ≈0.30（form-d 主锚 + bark-b 侧证）。

改写映射实现面：几何 = decussate 挂点 + 卵圆-广卵冠（camphor 广卵法端稍紧）+ 果簇账目 + 密冠参数；参数 = 全部按本 Spec 数值（树高 6–10m 带 / 空隙 5–15% / 团块 1/6–1/4）；材质 = 全缘 SDF 简化版（近零脉信号）+ 强光泽弱色差 + 果域白粉蓝黑 + 树皮第 12 语言 + 小枝两档。
