# T003.4 植物资产 4–5 种

> 归属：[T003 Scatter Styles](003-scatter-styles.md) ｜ 状态：**in-progress**（2026-09-17：代码全量完成 + 门槛绿，**用户裁定观感需优化——返工待做**，未提交） ｜ 前置：T002.1（仅契约层，可并行穿插）

## ⚠️ 用户裁定 + 观感讨论纪要（2026-09-17 会话尾，交接给新会话续谈）

**用户裁定**：植物观感 = 「几何树 / 几根圆柱加几片叶子」；**不止植物，全部程序化资产（含 T002.4 设施 5 种）同病**——不是成品，是 v1 功能基线。返工待做，方向讨论未完（见下分叉）。

**主代理诊断（讨论已达成共识的四根因）**：
1. 面数预算没用满——纪律 ≤2000 面，实交付 136/136/400/688（松/花/灌/橡），子代理把省面当目标而非用足预算换观感；
2. **零顶点形变**——完美球/锥/圆柱原样拼装，缺顶点级噪声扰动与破碎轮廓（「几何感」最大来源）；
3. 材质只能改色不能改形——7 个 shader 配方在原始几何上做颜色调制，救不了剪影；
4. 观感验收是子代理自评——即 T002.5 留档「近观观感待用户过目」的正式裁定落锤。

**优化路径（按性价比排序，讨论产出）**：①用满预算 + 顶点噪声形变（最大单步收益）→ ②冠层结构化（15–20 团碎冠/双层树冠/枝梢探出）→ ③shader 内 SDF 程序化 alpha 叶片卡片（零外部资源合 D13，近观台阶式提升，park-shader-agent 领域）→ ④设施几何细化（倒角/分段/构件拆分，材质体系已就位）→ ⑤LOD 双档（T006 本就要做，现低模天然是中/远档）。

**⏳ 待用户定夺的方向分叉（新会话从这里继续讨论）**：
- **A. 风格化低多边形**（stylized low-poly）：现路线推满（形变+碎冠+色彩），~1 会话量级，与 10 万实例/LOD 目标最契合；
- **B. 半写实**（alpha 叶片卡片 + 高低双档 LOD）：~2–3 会话量级，近观上限高得多。
- 主代理建议：**A 作为 003.5 前返工目标，B 作为 T006 LOD 阶段升级项**；返工必须排在 003.5 之前（否则散布样式验收两遍）。设施资产几何细化可与 A 同批返工。
- 诚实工作量口径：能力投入级返工（植物 1–2 会话/档次，设施同量级），非 bug 修复。

## Goal

D15 植物 generator：橡树 / 松树 / 灌木 / 花卉（+1 可选如银杏）——散布样式的货源，几何 + 材质代码生成，LOD levels 接口位预留（006.1 实装）。

## Requirements

- **每 generator**：参数化（高度 / 冠幅 / 密度档）、变体范围声明（供放置变体与撒点尺寸范围消费）、`levels` 接口位（本任务返回单档占位）
- **观感分级**：远看轮廓正确、中看体量自然、近看无破绽；树干/树冠材质分层
- **面数纪律**：单株细模 ≤ 2000 三角形（LOD 压力线的前提），声明在 meta
- **meta 完整**：分类=植物、标签、默认变换、变体声明
