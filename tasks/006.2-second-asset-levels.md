# T006.2 非植物第二资产档位验证

> 归属：[T006 Asset Runtime LOD](006-lod-chunking.md) ｜ 状态：**done（2026-09-19）** ｜ 前置：T006.1

## Goal

用非植物资产验证 009.6 level 契约跨资产可复用（D20.3 第二消费者原则）：现有设施程序化资产之一实装 High/Low 两档（不完整 LOD 链）。

## Requirements

- **资产选择**：T002.4 设施资产包中挑一个结构简单的小资产（建议路灯或消防栓类）
- **两档内容**：High = 现状几何；Low = 明显降面（轮廓 / 体量 / 颜色一致，内部细节舍弃）；档间身份一致（同 seed 同形态路由，sourceKey 不变）
- **声明与缓存**：meta levels 声明两档；sourceKey + level 双维缓存独立创建 / 独立释放（沿用 009.6 契约，D23.2）
- **GLB 侧语义确认**：GLB 资产 proxy 声明本期不实装，仅在类型注释留语义位（规范面归 010.3，标注「未经验证」，D27.3）

## Acceptance

- 两档可生成、实际面数符合声明、法线健康
- 档间色/形连续（强制档位渲染取证，截图比对辅助）；档位独立缓存/释放验证
- `npm test` / `check:layers` / `typecheck` 全绿

## Constraints

- 禁止把 LOD 做成设施专属机制——一切走 009.6 既有契约，不新增公共字段（D27.12）
- Research Gate：既有资产加档位不触发新调研（形态依据已有，豁免留痕 `Status: waived + Reason`）
