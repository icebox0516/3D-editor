# T004.1 缩略图管线

> 归属：[T004 Style Gallery](004-style-gallery.md) ｜ 状态：**not-started** ｜ 前置：无硬依赖（样式越多越有意义，建议在 003.5 后）

## Goal

样式预设缩略图管线（D14 支撑）：每预设以样例几何离屏快照生成缩略图 + 缓存。

## Requirements

- **样例几何**：按预设 supportedShapes 取样例（面类=样例多边形、线类=样例条带、点=锚点）
- **离屏渲染**：预设构建函数渲染到快照尺寸；环境预设统一（可比性）
- **缓存**：内存 + 持久两级（与资产缩略图同形态）；预设 id + 版本键控失效
- **自动生成**：新增预设零配置生成；失败降级占位图
- **注册表暴露**：preset meta 可查缩略图（供 004.2 画廊消费）

## Acceptance

- 全部既有预设 + 新绿地样式缩略图生成正确、二次打开缓存命中
- 失败降级生效；三重门槛全绿

## Constraints

- 复用既有离屏快照设施，不新增常驻 WebGL 上下文
